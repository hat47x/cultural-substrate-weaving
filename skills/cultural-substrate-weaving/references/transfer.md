# 文化体系を転移として使う

2026-11-10。文化体系の活用を、体系が持つ情報のネットワークを対象領域へ写し、写した構造で判断する作業として扱う手引きです。機械学習の転移学習に似ていますが、似ているのは構造で、学習済みモデルを載せ替える手続きではありません。

どの体系をどの用途で優先するかの詳細は[観点と最初の選定](framework-selection.md)で扱います。この文書は、選んだ体系を対象へ当てるときの扱い方と、適用範囲の見込みをまとめます。

## 四点を写す

写すのは、名前の一覧ではなく、次の四点のつながりです。

1. 何を一つの状態と数えるか（分節。以下、状態と呼びます）。
2. どの状態から、どこへ移れるか（接続）。
3. 移るのに何が要るか。要らなかったものも分けて置ける（条件）。
4. 移ったあと、何が保たれ、何が残るか（残余）。

この四点が写せて、写した先の対象で確かめられるなら、転移は働きます。名前だけを貼り、対応表を埋め、一般語へ言い換えるだけなら、写っていません。合わない構造を無理に当てると、負の転移になります。対象の条件を体系の都合で削らないでください。

状態の数え方は、選んだ体系が決めます。易なら爻の位置、五行なら働きと場の質、セフィロトなら配置のまとまりです。体系を開かずに読む還元の手つきでは、「〜しなくて済んでいる」と言い切れる接触の条件として数えます。両方を混ぜず、どちらの数え方で読んでいるかを、冒頭で一度決めてください。

## 延長に効くと見込むもの

すべての体系が同じように働くとは扱いません。今の資料と技法で、上の四点のネットワークが密で、対象の変化を読めるものは限られます。見込みの順に、次を置きます。

選ぶ前に、**その体系の状態パターンが何に当てはめて表現できるか**を見てください。この範囲は、印象ではなく、原典の記述・成り立ち・由来から類推します。類推の強さは体系ごとに違います。

**易**は、原典自身が適用範囲を明言しています。『易伝』繫辞上第四章は「易與天地準，故能彌綸天地之道」とし、さらに「範圍天地之化而不過，曲成萬物而不遺」と続けます。天地の変化を範囲に収め、万物を成し遂げて遺さない、という自己記述です。第六章にも「以言乎天地之間則備矣」があります。64卦を万物の状態として読む根拠は、この自己記述にあります。

**易**と言うとき、この手引きが指すのは『周易』の体系です。卦辞・爻辞・彖・象を読み、一本の線を変えて之卦を見る、という操作です。

**断易**は、易経を下敷きにしながら、根本の思想も操作体系も異なるものとして扱います。断易の納甲・六親・用神といった仕組みを、周易の読みに混ぜません。同じ「易」の名で呼ばれても、別の体系として区別します。この区別は著者の見立てであり、断易の原典を今回読んで確認したものではありません。

**五行**は、『尚書』洪範に「水曰潤下，火曰炎上，木曰曲直，金曰從革，土爰稼穡」とあり、五つは特定の物の名前ではなく、性質と働きの分類として置かれています。ただし、洪範は「万物に適用する」と明言しているわけではありません。万物・政事・身体への拡張は、後の五行論（『白虎通』など）が担った部分です。適用範囲は、分類の基準が性質と働きにあることから類推します。易より弱い根拠です。

**セフィロトとパス**（この文書では、ゴールデンドーン系の読みを指します）は、使っている資料の主題が人であり、構造の側にも人体との結びつきが強く想起・提起されています。生命の樹を人体へ重ねる読みは、この体系の成り立ちの一部です。実践の側でも、パスと人生の照合が用いられ、タロットは人的領域である占いに活用されています。万物へ適用するという明言は、この範囲の資料にはありません。したがって、人的な問題領域に向くという判断は、資料の主題と構造・実践の側からの類推です。セフェル・イェツィラーなど他の原典を読めば、宇宙の成り立ちを扱う記述も出てくる可能性があり、その場合は判断を読み直します。

もう一つの軸は、**対象の規模**です。易は国家の行く末を占うことに用いられてきたのに対し、タロットはそこまで大規模な用途に用いられる例を聞きません。個人の問いから集団・国家の局面まで扱えるのが易、個人の生と心の局面に向くのがセフィロトとタロット、という分け方です。この規模の差は、原典の用途の歴史からの類推ですが、易の国家規模の占いについては、今回のセッションで一次資料に当たって確認していません。著者の見立てとして置きます。

人体との対応についても、確認した範囲を書きます。生命の樹を人体に重ねる読み（アダム・カドモン）は、カバラーの伝統で知られる主題です（[Adam Kadmon](https://en.wikipedia.org/wiki/Adam_Kadmon)の記事がある）。一方、タロットについては、[Tarot](https://en.wikipedia.org/wiki/Tarot)の記事が、占い・占術に用いられることと、タロットとカバラの結びつきを主張したのが18世紀末のフランスの神秘主義者であり、その歴史・意味についての主張は「精巧だが裏づけがない」と評価されていることを、どちらも記しています。**タロット経由でセフィロトの意味を補わない**のは、このためです。

**五行と五大**は、状態を積極的に観測する道具としてより、**ありのままの配置として知覚する**用途に向くように思われます。ここで言うありのままには、**相生と相剋の遷移関係も含みます。** 五つの相が互いに生み、制する関係は、観測の外へ置かれるのではなく、その場の配置にそのまま現れているものとして読みます。

誤りやすいのは、その関係を、外から当てる因果の物差しに変えることです。何かを測ったり予測したりするために生剋を使い、結果を「だから」で説明すると、前節のジャンクな使い方へ寄ります。分類として置くときは、生剋を、その場に現れた関係として読み、結果を導く因果として押しつけません。読むのは関係までで、そこから先の結論は、対象の具体と側で決めます。

### 五行・五大の使い方

**五行**は、対象を木火土金水の五つへ分類し、それがどれに当たるか、何と何が相生・相剋の関係にあるかを読む。分類があることで、何が対象で、何が対象でないか、どこに働きと制約があるかが見える。分類が無い場合に比べて、関係の見落としが減る。

**五大**は、対象が地水火風空のどれに当たるか、何を象徴するかに加えて、**密度と接地**を読む。

- 濃いか薄いか。その質が場に満ちているか、薄くしか無いか。
- 地に接しているか、地に足がついているか。支えがあるか、浮いているか。
- 空に属しているか、希薄か、遍在しているか。間隔や余地として、どこにでもあるのか、そこだけ薄いのか。

### 25状態の交差表

五行の五つと五大の五つを交差すると、25の状態ができる。これを表にして、**どれが充足され、どれが薄く、どれが抜けているか**を見る。これは状態の一覧ではなく、配置の点検である。メタ分析として使える。

| | 地 | 水 | 火 | 風 | 空 |
|---|---|---|---|---|---|
| 木 | | | | | |
| 火 | | | | | |
| 土 | | | | | |
| 金 | | | | | |
| 水 | | | | | |

使い方は三つ。

1. **埋める。** 対象の具体を、当てはまるセルへ置く。置けるセルだけを置き、全部を埋めない。
2. **薄い・抜けを見る。** 空いたセルは、欠けではなく、その配置に現れていない状態として読む。薄いセルは、その質が弱く現れている状態として読む。
3. **偏りを見る。** 特定の行や列に偏っていれば、その配置がどの質に寄っているかが分かる。一つの行だけが埋まっているときは、五行の側が一つの働きに偏っている。

注意します。

- 25を全部埋めない。埋めることが目的になると、前節のジャンク（対応表を埋める）へ寄る。
- 薄い・抜けは、失敗ではない。**その配置に、その質が現れていないという発見**である。埋めるために具体を足さない。
- 表は点検の道具であり、結論ではない。表から言えるのは、どの質が現れ、どれが現れていないかまでである。良し悪しは対象の側で決める。
- この使い方は著者の運用案であり、実作で確かめたものではない。25の状態の意味は、五行と五大それぞれの伝統の読みに依存し、二つを一つの教義へ合成しない。

表の得手と不得手も、試作で分かっている。

- **得手は、在・不在の解像度。** 「弱く現れている」という第三の値を置くと、「その質は無い」と言えなくなる。行と列の両方から抜けを数えると、同じ字を持つ二つの水が逆向きに出ることも見える（五行の水の行は濃く、五大の水の列は空）。
- **不得手は、移りと関係。** 状態の分節、接続、条件（要ったもの・要らなかったもの）、残余は、表にすると落ちる。表の中で生剋を因果に使わないと決めると、「一つの動きが生む側と抑える側の両方に現れる」という読みも落ちる。
- 対象についての新しい事実は、表からは増えないことが多い。増えるのは配置の区別と不在の内訳である。だから表は、**四点（状態・接続・条件・残余）と併用する**。表で在・不在を点検し、四点で移りと条件を読む。どちらか一方で全体を読まない。

汎用の体系を狭く使うことも、人的な体系を機械的な配置へ当てることもできます。ただし後者は、人の層を読み込まないと写像が痩せます。試作では、ゲームの一瞬にセフィロトを当てたとき、人物が頼っている像を置くことで初めて具体が動きました。一つのパスに狭めても、読んでいたのは人の頼り方でした。

| 体系 | 写せるネットワーク | 適用範囲と根拠 | 崩れやすいところ |
|---|---|---|---|
| 五行×五大の交差 | 生成・制御の関係と、場・身体の質を、二つの軸で重ねる。同じ要素が別の関係で違う働きになる | 五行は万物（類推）。洪範の五つは性質と働きの分類で、対象を限定しない。拡張は後代の五行論。五大は五輪塔と空海の著作を入口にした技法資料の範囲で、感覚と場の質として使う。向くのは観測より、関係も含めたありのままの配置としての知覚 | 五分類の割当、相生の循環のなぞり、二体系の用語の同一視、生剋の因果化 |
| 易の変爻関係 | 局面の位置、爻の意味、変えた線による之卦への移り、移行の中間 | 万物（原典の明言）。繫辞上に「範圍天地之化而不過，曲成萬物而不遺」。対象の規模は、個人から国家の局面まで広げられる。ただし、国家規模の占いの用途史は今回のセッションで一次資料に当たっておらず、著者の見立てである | 線の反転だけで意味も変わったとする、六爻への配役 |
| ゴールデンドーン系のセフィロトとパス | セフィラ間の接続、パスに蓄積された意味、経路ごとの変容 | 人的領域・個人の規模（類推）。書簡15は魂、第32パスは人の像と変容。人体対応とタロットの占いも人的領域の側 | 全パスの対応表、書簡15との混同、感情名の配当 |

この三つは、接続と条件を具体的に読める点で共通します。**有効な体系が限られるのは、体系の価値の差というより、写せるネットワークの密度と、対象側で確かめられるかの差**として読みます。

同じ対象へこの三つを当てると、状態の数え方も、次に開く枝も変わります。ある場面では、五行は「働きが渡れるか」を、変爻は「他の五本が動かないこと」を、セフィロトは「一掌を保つ者」を次へ開きました。三つが同じ結論を出したのではなく、写したネットワークが違ったのです。複数を併用するときも、差を平均せず、どれを採るかを対象で決めてください。

## 適合度は、範囲を狭めることでも作れる

適合度は、体系と領域の相性だけで決まりません。相性が悪そうな対象でも、**使う範囲を狭めれば写像が成立する**ことがあります。ある試作では、ゲームの一瞬にセフィロトを当てる際、全パスではなく一つのパスの一歩だけを借り、接触を経路の到達点にしませんでした。この部分適用では、ジャンクな兆候が出ていません。全段階を当てようとすれば、同じ組み合わせでも対応表へ寄りやすいのです。適合は、対象を選ぶだけでなく、使う範囲を狭めることでも作れます。

ただし、範囲を狭めれば何でも当たるわけではありません。人的な体系を機械的な配置へ当てるときは、人の頼り方や関係の層を残せるかを見てください。その層を落とすと、狭めた範囲の中で一般語だけが残ります。

## いつ使うか — 入口と、最後の一押し

適用の時期にも型があります。

第一は、探索の入口として使う型です。問いがまだ広く、材料も揃っていない段階で、体系の構造を当てて、見えていなかった区別を作る。これまでの節は、主にこの型を扱っています。

第二は、**最後の一押し**として使う型です。問いがほぼ解けていて、あと少しで答えが出そうなときに、体系の構造が、ばらばらの材料を一つの像にまとめます。科学者が日々の思索を続けるなかで、日常の些細な出来事から発想を得たり、夢のなかで物事が整理されて形象として現れたりする、という語られ方をする例があります。ニュートンのリンゴ、ケクレのベンゼン環の蛇が、その例として挙げられます。

この型では、体系は答えを作りません。**すでに集まっている材料に、最後の形を与えます。** 日常の出来事や夢の形象が引き金になり、体系の構造が、その引き金をどの位置へ置くかを決める、という順になります。

使い方は次のとおりです。

1. 問いを、ほぼ解けた形で一度書く。何が決まっていて、何が一点だけ決まらないかを分ける。
2. その一点を、体系の四点のどこに置くかを探す。状態の境界か、接続の欠けか、条件の不足か、残余の読み落としが多い。
3. 日常で起きた些細なこと、ふと浮かんだ形象を、捨てずに置いてみる。体系の構造は、それをどの位置に置くかを与える。
4. 最後の一点に名前を付ける。名前が付いたら、体系は脇へ置く。答えを体系の言葉で説明し続けない。

注意します。ニュートンのリンゴやケクレの蛇は、後から語られた逸話で、出来事そのものの証拠は弱いものです。ここで使うのは、**そうした最後の一押しが起こりうる**という見方であって、逸話の史実性ではありません。また、解けた後に「体系のおかげで解けた」と物語るのは後知恵になりやすい。最後の一押しが効いたかどうかは、その場で確かめられません。記録には、何を置いたら何が決まったかを、後知恵と分けて残してください。

**適用範囲は、いつ使うかでも変わります。** 入口では広い構造が要り、最後の一押しでは一点を決める小さな形が要ります。同じ体系でも、使う時期によって、借りる部分が変わります。

第三の型として、次の二つも置けます。合わせて四つの型になります。

- **ひとつだけ先に進める。** 問い全体を解かず、一つの要素だけを先へ動かす。状態を一つ分ける、接続を一本増やす、条件を一つ確かめる。小さな前進を、体系の形で行う使い方です。
- **無意識の材料にする。** 構造を、気づきの材料の一つとして置いておく。すぐに答えへ使わず、後で別の材料と結びついたときに働く。人間の側では、日常の些細な出来事や夢がこれに当たります。

## 知性のかたちに合わせる

これらの型が働くかどうかは、**その構造を、使い手が暗黙に拾い上げるか**に掛かります。明示的に「この構造で読め」と渡されたときは、指示に従うかどうかの問題になります。渡されていない構造が、別の作業の途中で自然に使われるとき、初めて「拾い上げた」と言えます。

これは知性の特性に依存します。人間の側では、無意識の整理や、日常の出来事からの連想がその働きを担います。生成AIの側では、同じようには働きません。文脈の外にある潜在的な連想、学習に由来する語の結びつき、直前までの作業の形が、近い役割を果たす可能性はありますが、確かめたわけではありません。

したがって、**知性のかたちに合わせたフィッティング**が要ります。

- 暗黙に拾ってほしいときは、構造を指示として書かず、場面や素材の側に埋める。どの程度拾われたかは、後の出力にその構造が現れたかで見る。
- 拾われないまま進むほうがよいときは、構造を明示しない。拾われたかどうかを、出力の一致だけで判断しない。
- 生成AIでは、人間の「無意識」に相当する働きを前提にしない。拾い上げを期待するなら、期待したことを記録に残し、拾えたかを確認する。

拾えたかどうかは、後から確かめにくいです。確かめるには、同じ材料を、構造を埋めた場合と埋めない場合で分け、後の出力に構造の痕跡が出るかを見る、という比較になります。この比較は、まだ行っていません。

## 手つきを獲得し、規則へ組み込む

体系の運用は、教義の説明ではなく、**手つき**として持つと扱いやすい。手つきは、実践で見つかるたびに、次の五つを一行に書いて足します。

1. 入力：何を渡すと働くか。
2. 操作：何をするか。
3. 出力：何が出るか。
4. 崩れ：どこで壊れるか。
5. 確認の問い：出力の後で、自分に何を問うか。

この形にすると、生成AIは教義を理解していなくても、手つきを選んで実行し、出力を点検できます。手つきの目録は[体系の手つき目録](operations.md)に置きました。

獲得できたかを確かめる方法は、**その一行だけを渡した新しい担当に、対象を読ませる**ことです。

- 再現すれば、その行は獲得できている。目録に残す。
- 再現しなければ、記述が足りないか、手つきが働かないかである。記述を直すか、行を落とす。落としたことを、探索の終了理由にしない。

規則への組み込み方は、次の二点に限ります。

- **場面で選ぶ形にする。** 目録の全手順を必須にしない。場面に合う手つきを一つ選び、確認の問いに答える。
- **確認の問いを、出力後の自己点検に置く。** 手つきが働かなかったことを、出力の後で見つけられるようにする。

拡張は、実践で使えた手つきを足すことで行います。使えなかった手つきは落とします。規則は手つきの追加で増やし、必須工程や固定順序では増やさないでください。手つきの数が増えるほど、選ぶ側の判断が要ります。選べる形を保つことが、拡張の条件です。

## 複数の体系を重ねるとき

一つの対象へ、複数の体系を同時に当てることがあります。重ねるときは、次の四つを守ってください。試作で、守らないと役割が混ざり、結論が平均に寄ることが分かっています。

1. **担当範囲を、その体系の手つきに合わせて宣言する。** 「一本だけ」と宣言しながら、動かなかった五本が何を変えなかったかを読むなら、宣言が狭すぎます。変爻の手つきは、動いた一本と、動かなかった五本を一組にしています。宣言は、実際に読む範囲に合わせてください。
2. **一致は、各体系の語彙のままで言う。** 一方の語を他方の語へ訳して「一致した」と書くと、一致は作られます。ある体系が「飲まれない」と言い、別が「理由が渡らない」と言うなら、それは同じ問いへの同じ答えではありません。訳さずに並べ、どこまでが同じで、どこから違うかを書いてください。
3. **足した層は、節ごとに同じ書き方で示す。** 素材にない年数・後任・束などを足したなら、その語が出るたびに「掛けた」と分かるようにしてください。表示が揺れると、掛けた層が素材の事実として読まれます。
4. **採る結論は、その節の語だけで書く。** 採用の根拠に、他の節の語を一つでも混ぜると、採った一つが実は混ざったものになります。採らなかった節は捨てず、別の用途（点検、制約）に残してください。

重ねると、単独では出なかった区別が出ることがあります。試作では、「動かなかった」と「現れなかった」は別であること、反証されないことと採らないことが別であることが、二つの数え方を並べたときにだけ見えました。この種の区別は、結論を平均せずに並べたときに現れます。

## 結果から何を汲むか

試行の結果は、そのままでは知見になりません。何を汲むかを決めてから読んでください。次の観点を順に置きますが、この五つを毎回すべて通す必要はありません。使う観点を場面で選んでください。

### 水準を分ける

一つの結果から汲めることは、少なくとも四つの水準に分かれます。混ぜると、対象についての観察が、方法の効果の主張に化けます。

1. **対象について。** その製品・場面・制度の、何が分かったか。
2. **手つきについて。** 使った体系の操作が、どこで働き、どこで崩れたか。
3. **道具について。** 手引き・目録・表・仕様の形式が、読めて使えたか。
4. **評価について。** 読み手・判定・条件の置き方が、何を捉え、何を捉え損ねたか。

結果を読むときは、まずどの水準の話かを決めます。対象の話を方法の効果として書かない、道具の不具合を手つきの失敗として書かない。

### 検査を通す

結果を採用する前に、三つの検査を通します。

- **反例の検査。** この結果が起きなかった条件は何か。条件を一つ変えたとき、結果が消えるなら、原因はそこにある。
- **代替説明の検査。** 同じ結果を、別の原因で説明できないか。モデルの癖、素材の書き方、依頼文の言い回し、前の回からの持ち越し。説明が二つ以上あるなら、どちらかを選ばずに両方残す。
- **再現の検査。** 同じ結果が、別の対象・別の回・別の読み手で出たか。出ていなければ、単発として扱う。

### 安定度で区分する

- **安定。** 複数の回・対象で同じ向きの結果が出た。規則の候補にできる。
- **単発。** 一回だけ出た。候補として残すが、規則にしない。
- **反証。** 逆向きの結果が出た。前の読みを書き換える材料にする。反証は失敗ではなく、汲み取りの成果である。

### 汲み取りの禁則

- 単発の結果を、規則や一般法則にしない。
- 効果の主張をしない。良くなった・速くなった・深まったは、比較の設計が要る。
- 測っていないことを、無かったことにしない。欠測は欠測として残す。
- 一度の外れを、探索を止める理由にしない。外れは捨てる材料であり、汲み取りの対象でもある。
- 読み手の判定が割れたら、割れたことを結果として残す。多数決で消さない。

### 修正が効いたかを見る

結果から汲んだ知見で文書や手順を直したとき、直した箇所だけを確かめても足りません。試作では、宣言の範囲の漏れを一つの節で閉じたところ、同じ型の漏れが別の節で開きました。

修正の検査は、次の順で行います。

1. **欠陥の型を一文にする。** 「宣言した範囲の外の語を、引用して意味を述べている」のように、場所を含めずに書く。
2. **直した箇所を、型で確かめる。** 一文に戻る。
3. **同じ型を、文書全体で探す。** 直した箇所の近くだけを見ない。語の一覧、節の一覧、見出しの一覧を機械的に走査する。
4. **出てきた箇所を、直した箇所と同じ扱いで直す。**
5. **直した箇所と、新たに見つけた箇所を、記録に並べる。** 修正が一件で済んだのか、別の箇所へ移ったのかが分かる。

型は、前の試作で見つかったものを使えます。

- 宣言した範囲と、実際に読む範囲のずれ（節の外の語を引いて意味を述べる）。
- 事実を書く列が二つ以上ある（どちらが現物を指すか決まっていない）。
- 一方の語を他方へ訳して、一致を作る。
- 同じ語が二つの節にまたがり、片方の節の語として扱われている。
- 印やラベルが、途中で別の言い方に変わる。
- **二つの記述が両立しない。** それぞれの節では一貫しているのに、並べると矛盾する。型の走査では拾いにくく、二つの節を突き合わせる必要がある。
- **印の付いていない、足した層。** 素材にない語を足したと宣言しながら、その語の一部に印が付いていない。宣言した語だけを走査すると、同じ層を指す言い換え（年数、建物の別、案の中身）が抜ける。

七つ目の型は、宣言した語の一覧ではなく、**足した層を指す言い換えの一覧**を作ってから走査します。宣言した語に印を付けても、言い換えには付かないことがあります。

七つ目の型には、細部があります。**事実の欄の見出しの下に置いた文は、読解でも事実として読まれます。** 「要らなかったもの」「条件」「残余」といった見出しの直後に、読みを平叙で置くと、見出しが読みを事実の形にします。読解を置くときは、「と読める」「私の読みでは」を添えてください。添えないと、走査でも突き合わせでも拾えません。

六つ目の型は、走査ではなく突き合わせで見つかります。二つの節を並べ、同じ対象について反対のことを言っていないかを確かめてください。数（「二つの型」と「四つ」）、有無（「読まない」と「読んだ」）、強さ（「原典の明言」と「未確認」）の三つが、突き合わせで見つかりやすいです。

この検査は、文書だけでなく、手順やコードの修正にも使えます。型を一文にできない修正は、検査もできません。型にできないときは、そのことを記録に残してください。

### 二つの結果が一致したとき

二つの体系や二つの条件で、同じ結論が出たときは、一致の由来を確かめてから、収束と呼んでください。試作では、同じ対象を易と五行×五大で読んで同じ構想が出ましたが、その一致は独立した条件の一致として確認できませんでした。条件を独立させ、節立ての指定も外して同じ対象を読み直すと、**構想は違うものになりました**。

- 最初の二稿は、同じ依頼文、同じ事実の六点、同じ節立て、同じ見出しで書かれていた。**逐字一致は、入力と雛形の一致でもあった。**
- 五行の条件は、易の稿の全文を入力として受けていた可能性がある。独立が崩れていた。
- 独立条件では、易は「移りは名と名の間にある／名ごとに閉じた時間が並ぶ」、五行は「この層は蓄積に厚く渡りに細い」と、**構想の型そのものが分かれた**（変化の所在／層の濃淡）。
- それでも一致したのは、事実に近い読み（旧版が終わらず今の版へ引き上げられずに並ぶ）と、崩れの場所（旧版の再生）だった。

一致を言う前に、次を確かめてください。

1. **条件を独立させる。** 互いの稿を見せず、別のセッションで走らせる。
2. **逐字一致を根拠から外す。** 事実欄・節立て・見出しが同じことは、構想の一致ではない。節立ての指定を外すと、逐字一致は消える。
3. **半句ごとに突き合わせる。** 六点のうち、両稿で最も薄く読まれた半句（「診断用に」など）を比べると、構想の一致の内訳が見える。
4. **一致したものの種類を見る。** 事実の言い換え（六点の列挙）は、構想の一致ではない。独自の読みとして一致したものだけを、収束として数える。

## ジャンクを見分ける

体系の大部分は、執筆や構想の役に立ちません。無思慮に使うと、名前を借りた一般論が増えます。次の兆候がある当て方は、そのまま採用しません。

- 名前と分類だけがあり、接続・条件・残余が読めない。
- 対応表を埋めることが目的になり、埋めた先の問いが生まれない。
- 対象の具体を削って、体系の数へ合わせる。
- 原典・注釈へ戻れず、モデルの記憶で意味を補っている。
- どの対象にも同じ結論が出る（「バランスが大事」「循環している」）。
- 時代や社会の前提を、そのまま現在の価値判断へ持ち込む。

ただし、**ジャンクな結果そのものは実害になりません。** 探索の途中で出たものは、後続の工程で除去するか、使わない材料として捨てられます。費やしたトークンは、探索の費用です。ジャンクを出したことは、方法の失敗でも、探索を終える理由でもありません。

**問題なのは、ジャンクを理由に探索を打ち切ることです。** 一度の当て方が外れたことを、体系が使えない証拠にしたり、その後の発掘を止める理由にしたりしないでください。外れたら、当て方を変える、対象を変える、使う範囲を狭める、別の体系へ移る。止めるかどうかは、ジャンクの有無ではなく、発掘したい価値が尽きたかで決めます。

実際に観測された兆候を、もう少し具体的に置きます。同じ素材に五行と五大を当て、注意を外した試作では、次の使い方が現れました。

- 同じ語を二つの体系で兼用する。雨を五行の水としても五大の水としても読み、別の伝統の語であることを断らない。
- 物や役割を要素へ固定する。机は金、台は土、井守は金の仕事、と読む。
- 生剋を「だから」で因果化する。木が火を生まないから議題にならない、と素材の具体を説明へ置き換える。
- 禁止された直接適用。六大の識を、本文の構成にそのまま使う。
- 後半で抽象語へ移る。空き、響き、場、認識のあり方で閉じる。

同じ指示でも、冒頭で禁止を列挙し、四点を節として分けた試作では、これらの兆候は出ませんでした。**ジャンクかどうかは、体系の名前より、扱い方の側で決まります。**

境界例もあります。変爻を四段続けた試作では、毎段、六爻を場面の要素へ割り当てる表を置き、「作者の規約」と明示しました。技法は、そのことが分かるようにするなら作者側の構成を認めています。それでも、表が説明の大半を占め、場面より表が前景に出る段がありました。**開示しても、表が説明を埋めれば、写像より表が前に出ます。**

この緊張は、表を外すことで避けられる場合があります。別の試作では、配役の表を置かず、動いた線の爻辞、之卦の卦辞・象、動かなかった五本が何を変えなかったか、の三点だけで読みました。升の九二を変えて謙へ移り、「足りる」と「量って配る」の側へ読む案が出て、変爻は成立しています。**配役の表は、写像に必須ではありません。** 表を使うかどうかは、対象と目的で決めてください。開示して表を使う場合、そのこと自体は技法の範囲にあります。崩れとして扱うのは、表が説明の大半を占め、場面より表が前に出るときです。

ジャンクと判定しても、捨てる必要はありません。別の対象、別の深さ、別の資料では働くことがあります。判定は体系全体の価値ではなく、**この対象・この用途での写像の可否**として置きます。

## ジャンクは教義の側に溜まる

ジャンクは、体系そのものではなく、**教義の側に溜まりやすい。** 保留としてきた体系でも、蒸留された操作は働くことがあります。マヤ暦は、現在の技法が一般的な操作へ寄っているとして保留されてきましたが、その一行の操作（二つの周期と現在位置を別々に置き、一方だけが戻る場面と両方が揃う場面を比べる）を、規律つきで場面へ当てると、具体的な読みが出ました。周期の実名・日数・日名を足さず、作者が置く二つの目盛りとして使ったため、未確認の内容を持ち込まずに済んでいます。

つまり、**有効な体系を数えるより、使える蒸留操作を取り出すほうが正確です。** 三つの体系は良い出発点ですが、閉じたリストではありません。逆に、教義の厚い体系でも、蒸留操作が取り出せなければ、その用途では使えません。

## 適用したあと、どこまで広げるか

体系を当てたあとの自由な発散は、体系の外の連想に見えて、体系が持つ問題解決の型を含むことがあります。五行なら「何が養い、何が抑えるか」、変爻なら「どこを変えると局面が移るか」、パスなら「この接続を経ると何が残るか」という型です。

広げるときは、次の順で扱います。

1. どの型を借りたかを、一言で残す。自由連想の全部にラベルを貼る必要はない。
2. 広げた先が、元の対象の具体と合うかを確かめる。合わない連想は、体系へ戻して意味を補わない。
3. 写像が崩れた箇所を、対象側の条件として読む。体系の例外ではなく、対象の未見の条件として扱う。
4. 広がった連想のうち、別の体系でも同じ型が出るものを、還元の候補にする。共通する型は、体系名を外して手つきとして残せる。

還元の例として、この四点ネットワークそのものを置けます。状態・接続・条件・残余は、易の変爻、五行の生剋、セフィロトのパスに共通して現れます。ただし、この共通性は三つの体系の教義が同じだという主張ではありません。写像の手続きとして共通する、という整理です。

## 還元した四点を、体系名なしで使う

体系を開かず、四点だけで読むこともできます。この数え方は、体系名を使わない場合のものです。体系を当てるときは、その体系の状態の単位に従ってください。試作では、次の数え方で、対象の具体を保ったまま読めました。

- 状態は「〜しなくて済んでいる」と言い切れる接触の条件として数える。人か物かで分けない。一つの出来事が複数の状態に数えられてよい。
- 接続は、素材に書かれた移りだけを辺にする。書かれていない移りは辺にしない。働かなかった辺も残す。
- 条件は、移るのに要ったものと、要らなかったものを分ける。満たされない条件を、不足として埋めない。空白のまま残す。
- 残余は、保たれるもの、移らなかったもの、残るものに分ける。小さな不具合を直さずに残してよい。

この試作では、「理由が分からないままでいること」が、説明を足すのではなく位置を動かす移りを可能にする条件として読めました。体系の語を一つも使わずに出た区別であり、還元した手つきが、体系名を借りずに働く例です。別の対象（ゲームの一瞬）でも、体系名なしで読めました。ただし、各一回の試作で、他の対象での再現は未確認です。

## 自由な発散に残る型

体系を当てたあと、用語を外して自由に連想しても、その体系の型は消えにくいです。変爻を当てた試作では、用語を禁じた連想に、次の三案が出ました。

- 浅い台を一つ置き、動かしてよいのは位置だけにする案。寸法、札の文、紙の中身、訪問者の態度は変えない。
- 案内の一枚に、並べ替えの権限だけを渡す案。本文も宛先も用途も変えない。
- 改装で全部を入れ替え、紙の位置だけを前の机から写す案。動く側と動かない側が逆になる。

最初の二案は、一つのものが動き、他が動かないことで局面が変わる型を含みます。第三案は逆で、型をそのまま当てると外れます。**型は案の性質ではなく、どこを一つのものと読むかに掛かります。** 自由連想を型から確かめるときは、どの案が型を含み、どこで外れるかまで見てください。外れた案は失敗ではなく、型の境界を示す例として残せます。

## 限界

- ここに置いた知見は、2026-11-09〜10の私的な試作に基づく。各条件一回、単一の素材、単一のモデルが多い。
- 原典の新規照合をしていない試作を含む。扱った意味は、技法資料と公開転記の範囲に限る。
- ジャンクの兆候と、適合の判断は、主担当の基準による。条件名を伏せた読み手による判定を一部で行ったが、すべてではない。
- ここでの「有効」「適合」は、写像が具体的に読めたかで見ている。面白さ、実装可能性、利用者の評価ではない。
- 適用範囲の根拠の強さは一様でない。易は原典の明言、五行とセフィロトは資料の主題からの類推である。五行の拡張は後代の五行論に支えられ、セフィロトは他の原典（セフェル・イェツィラーなど）を読めば判断が変わりうる。
- 人体対応は、アダム・カドモンの項目が存在することまでを確認した。原典の該当箇所と、日本語の二次資料は読んでいない。
- 易の国家規模の占いと、五行×五大の「ありのままの配置として知覚する」向きは、著者の見立てであり、今回のセッションで一次資料に当たって確認していない。ありのままには相生・相剋の関係も含む、という整理も、同じ見立ての側にある。
