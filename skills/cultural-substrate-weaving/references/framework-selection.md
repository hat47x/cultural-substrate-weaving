# 文化体系を蒸留する — 観点と最初の選定

2026-10-20。Issue [#593](https://github.com/hat47x/cultural-substrate-weaving/issues/593)に沿い、既存の資料と具体的技法を読み直した最初の検討です。執筆に向けた定性的な選定であり、著者が実作で効果を確かめた報告ではありません。

今回、旧版の35件のプロフィールの見出し・用途を棚卸しし、現在の参考本文にある16体系の記述と技法案を比較しました。そのうち易、五行、五大、セフィロト、華厳、ラサ論は、下記の原資料・伝統内の解説へ戻って検討しました。他の体系についての判断は、現在の記述と旧資料から見える範囲に限ります。旧候補の全原典を通読したものではありません。

2026-10-24追記：以下の選定は、現在の参考テキストから使い始めるための案内です。最近の議論を踏まえ、体系や仮説の探索可能性と、今回の作品への採否を分けて読みます。「優先」「用途限定」「保留」は、この時点の資料と技法の具体化状況を示します。探索では、モデルの知識や検索から新たな体系を開き、既知の体系も異なる深さ・経路・組合せで展開できます。候補の生成と、採否・反証の検討は、それぞれの目的に沿って行います。

## まず何を選ぶか

体系の指定がない場合は、**易、五行、華厳、ラサ論のうち、今の執筆課題に働く部分**から選びます。四つを常に併用するという意味ではありません。伝統に蓄積された意味から、操作と執筆への具体化までを現在の資料で辿りやすく、異なる種類の知を比較できるためです。

セフィロトは『タニヤ』書簡15の関係と、別資料であるフォーチュンの第32パス、五大は作者側の感覚表と空海の五大／六大からの限定読解など、具体化できた範囲へ用途を限ります。五大の注釈の精査と著者による実作、別のパスや経路の比較は、引き続き深める部分として残します。

体系名を指定された場合や、作品世界に固有の文化を扱う場合は、この順序に合わせる必要はありません。

## 観点を深める — 何が知として保持されているか

状態・位置・経路の形式に、どの意味が結びついているかを読む。そこから何を展開できるかを動かしてみて、作品の具体や著者の理解へ返す。このつながりを保つことを、次の観点に共通する読み方とします。

| 観点 | とくに汲み取るもの | 読みが浅くなるところ |
|---|---|---|
| 分節と状態の意味 | 何を一つと数え、なぜその違いを分け、各状態が全体で何を担うか | 数の一致だけで対象を切り、分類名を付けて止まる |
| 遷移・経路・変容 | 移行の条件、途中の経験、到達後に残る差、戻ることの意味 | 線を動かすことと、変化を読むことを同一視する |
| 時機・周期・熟成 | 同じ行為が時によって働きを変えること、反復と累積の違い | 季節名を配るだけ、周期の長さを計算するだけになる |
| 生成・成立条件 | ある状態が何に養われ、何の組合せで成立し、何を次へ渡すか | 現象を既成の一方向の因果へ訳して、生成の意味を落とす |
| 対立・相補・抑制 | 二つの力が互いを消さずに、別の働き方を可能にする関係 | 均等配分や善悪の対立へ置き換える |
| 全体・部分・層 | どの全体に属するかで部分のあり方が変わり、違いが全体を成立させること | 「全部つながっている」という説明で具体的な役割差を消す |
| 空間・境界・接近 | 位置ごとの意味、門や媒介の役割、移動に伴う参加状態の変化 | どの図にもある中心・外周・入口だけを借りる |
| 身体・感覚・注意 | 何を感じ分け、どんな条件や構えから経験が立つか | 感覚語を増やすことと、伝統の知を汲むことを混同する |
| 認識・視点・否定 | 見る位置や述語が現象をどう切り、何を捉え損なうか | 観察と解釈を分ける一般論だけで止まる |
| 役割・関係・受け渡し | 同じ内容や所作が、誰との関係で違う働きになるか | 人物を固定した役や性格へ配当する |
| 価値・構え・実践 | ある局面で何を守り、何を控え、どう応じるかという知 | 作品を一般的な善さや、作者が選んでいない結論へ誘導する |
| 象徴・表現・受容 | 具体像の意味の重なり、表現が経験へ変わる組成、反復で生じる差 | 対応表を完成させたり、人物の感情と読者の経験を同じにしたりする |

観点を全て埋めることはしません。たとえば華厳の六相に状態遷移を作り足す必要はなく、ラサ論の構成と受容の関係には、感情分類の一覧とは別の厚みがあります。遷移のない観点でも、体系の意味から具体的な問いや構成が生まれるなら、深める対象になります。

## 「豊かさ」と「有望性」を見分ける

**体系に何があるか**は、原典の区別・意味・関係へ戻して読む。**現在使えるか**は、それを動かす技法と、執筆へ返す出口から考える。**著者に役立ったか**は、実際の採否・訂正・改稿・理解・再利用から受け取る。三つを一つの評価にしません。

今回の蒸留では、次のように読み分けました。

- 一つの同じ意味や関係を、状況に応じて違う具体へ展開できるか。万能な一般語を繰り返すことと区別する。
- 対応を付けた後に、読むべき条件、次の問い、構成の選択が生じるか。単に作品を体系語で説明できるだけで終わらないか。
- ある読みが合わないとき、どの部分を変えると別の読みになるか。何にでも当たる説明へ逃げないか。
- 作者が補った部分を取り除いても、なお原典に辿れる意味の核があるか。補った量が大きい場合は、その手順を作者側の技法として扱う。
- 今回の場面だけでなく、別の原稿や問いでも、その核を保った読み替えができそうか。

これらは採点項目ではなく、今回の選定理由を言葉にするための問いです。通常の方法でも同じ結果を表現できることだけで除外しません。体系との接触がその問いへ注意を向けたことや、読みを繰り返し展開する足場になることも見ます。

## 六つの体系を深く比べた結果

### 易 — 意味を持つ局面と、そこへ至る道を優先する

『周易』井の九三・六四・九五では、使える源、修めること、使われることを分けて読めます。同じ資源があることと、そこへ届く関係があることを区別できる。既存の工房の作例以外にも、エッセイで「記録が保存されている」と「今の問いから使い直せる」を分ける構成へ展開できると考えます。これは今回の応用案です。

八卦の性質、上下卦、卦辞・爻辞、中間卦へ戻れるため、構造の操作と意味の読解を接続しやすい。優先するのはこの接続です。六つの任意の条件を0/1で配置して反転するだけの技法は、それ自体を易の知を汲んだ成果として推薦しません。

次に深めるのは、爻の位置・時機・応じ方を、具体的な卦の原文と注釈から読むことです。64卦を同じ深さで説明することを、使用開始の条件にはしません。

### 五行 — 各相のあり方と、養う・制する関係を併せて残す

『尚書』洪範にある各相の性質と、『白虎通』五行の生成・相勝の関係を、出典の層を分けて読みます。後者は生成の循環だけでなく、各相が他を制する理由や、土が諸相へ働く説明を含みます。社会的な序列の比喩も含む資料なので、その価値を作品へそのまま採らず、今回どの意味を受け取るかを定めます。

優先する技法は、一つの働きを増やす案と、その働きを生む条件を整える案を読み分けること、同じ要素が別の相との関係では異なる働きを持つと読むことです。人物を五つの役へ固定することや、五つの像を置くことは推薦しません。

旧版では自動スケーリングの分析で通常の制御・因果分析と重なることが降格理由でした。その特定用途の比較を、文化的な意味を使う執筆での無益さへ広げません。一方、相生・相剋の名前だけを借りた一般的な因果図も、現在の主技法にはしません。

### 華厳 — 差異を保って全体を成立させる知を優先する

法蔵『華嚴一乘教義分齊章』巻4の六相と、垂木・建物の問答へ戻りました。全体と部分の相互の成立、共同の働きと各部分の違いを併せて読むところが、作品へ展開する核になります。

工房以外では、同じ遺品を「個人の所有物」「家族の暮らしの一部」「手放す際の記憶の媒介」として読み直す案を考えられます。物の象徴を追加する前に、どの全体の中で何として働くかを変える。家族全員の理解を一致させず、一つの行為が成立する構成も試せます。これは今回の応用案です。

2026-10-24には、[具体的な技法](writing-techniques.md)へ、父娘が板を切る二稿と六相からの読み直しを追加しました。気持ちを揃える稿と、異なる手つきで作業が成立する稿を比べ、手が全体の中で何として働くかまで具体化しています。著者による採否は未確認です。

「六つの段階で物語を進める」「全員の差を超えて一つになる」という使い方は推薦しません。六相の違いをそのまま保てるため、状態遷移以外を深める優先候補にします。

### ラサ論 — 感情名より、経験を成立させる組合せを優先する

『ナーティヤ・シャーストラ』第6章のラサの生成に関する説明と、第7章の情動状態の説明へ戻りました。状況や対象としてのヴィバーヴァ、表れとしてのアヌバーヴァ、移ろう状態としてのヴィヤビチャーリ・バーヴァ、その組合せと持続的な情動との関係を、読解の入口にできます。語の訳し方は参照する翻訳と注釈に沿って扱います。

これは「意図と受け取りは違う」という一般論より先へ進める資源です。場面に何が置かれ、それがどんな所作として現れ、途中にどんな揺れを伴うと、ある味わいが成立するのかを読める。舞台の構成を小説の語りへ移す部分は作者側の技法です。

別れの場面なら、悲しいと書き足す代わりに、別れを生む状況、残る手の動き、一瞬別のものへ向く注意を分け、それらをどう組むかを検討する。感情の因果説明とは別に、読者が味わえる形へ構成する案です。[具体的な技法](writing-techniques.md)には同じ別れの状況を保ち、歩きだすことと手を下ろすことの関係を変えた二稿を加えています。どの稿を選ぶかを、場面の狙いから説明できる形です。実際の読者の経験はまだ確認していません。九感情のチェック表へ縮めず、組成の技法を優先します。

### セフィロト — 書簡15と、第32パスの限定例を分けて残す

『タニヤ』書簡15の本文と解説では、与える働き、制限する働き、両者を含む働きと、父が子へ知性を結びつける比喩を辿れます。同じ説明を渡すことと、相手へ届く関係を作ることを区別する執筆の技法には、現在の資料で戻れる核があります。

この範囲は、人物の関係や、教える側も相手の応答から変わる場面に限って残します。各セフィラを感情名へ配ることや、書簡の説明順を生命の樹のパスとして扱うことは推薦しません。

2026-10-24の追加読解では、ディオン・フォーチュンの近代西洋秘教の記述から、マルクト→イェソドの第32パスを選びました。[具体的な技法](writing-techniques.md)には、人物が頼る像を生活の条件との接触へ返し、抵抗と足場を読む操作と、退職・遺品整理の二つの仮想構成例を加えています。経路に蓄積された意味から、単なる位置づけを越えて人物の変容を展開できる点を、有望とする理由にしました。

書簡15の説明とこのパスを同じ伝統の一図へまとめず、今回の意味づけと出典を分けます。これは一つのパスの技法案であり、全パスの説明や、著者にとっての効果を確認したものではありません。第32パスの逆向き、別パス、別の体系との比較は今後の検討として残します。

### 五大 — 感覚の補助表と、空海の響き・六大の読みを分ける

高野山金剛峯寺の五輪塔案内から、「重さ・接触・温度・息・余地」という**作者側の感覚表**をそのまま導くことはできません。この境界は維持します。

追加して確かめた空海の『声字実相義』（[仏教伝道協会英訳、p. 90](https://www.bdk.or.jp/document/dgtl-dl/dBET_ShingonTexts_2004.pdf)）は、地・水・火・風・空を**響き／声・文字・実相**の関係から読みます。『即身成仏義』（同英訳pp. 68–73）では、五大に**識**を加え、六大が互いを妨げない関係として語られます。[真言宗の寺院による解説](https://www.fudouin.or.jp/zen_odaishisama_10.html)でもこの区別を確認でき、[苫米地誠一（2020）](https://www.jstage.jst.go.jp/article/chisangakuho/69/0/69_51/_article/-char/ja/)の公開抄録は、五字・五大・識大の典拠関係が精査を要することを示します。

これを踏まえ、[具体的な技法](writing-techniques.md)に、**一場面の接触・響き・注意・次の行動を関係として読む**工房の改稿候補を加えました。これは教義の直接の創作法ではなくCSWの応用です。五つの感覚語を増やすだけの手順と違い、「場で生じた音が、届いた相手の行動と関係をどう変えるか」を問えます。ただし**著者が実作で有用と判断した証拠はなく**、現時点では用途限定を維持します。

五行の循環を五大へ写したり、地→水→火→風→空を伝統共通の成長段階にしたり、観想・真言や身体への五字配置を出典なしに執筆へ取り込んだりしません。参照する原典のより詳細な校訂・注釈と、別場面での実作は未了です。

## 現行16体系の使いどころを選び直す

この表の「判断」は、現在の記述と技法の使いどころについての判断です。体系全体の優劣ではありません。「保留」は、指定があっても使わないという意味ではなく、体系の指定がないときの最初の推薦から外すという意味です。

| 体系・現在の範囲 | 主に読む観点 | 今回の判断と理由 | 次に推薦を広げるために読むもの |
|---|---|---|---|
| 易・八卦／六十四卦 | 分節、遷移、時機、実践、象徴 | 優先。卦・爻の意味と具体的操作を繋げられる | 特定の卦の爻位と時機を原文・注釈で深める |
| 五行 | 生成、制約、時機、各相の意味 | 優先。各相のあり方と二つの関係を併せて読める | 相の対応と場面の具体を複数の例で精密にする |
| 華厳・法蔵の六相 | 全体と部分、成立、差異、視点 | 優先。差を消さずに関係と全体を組み替えられる | 同じ具体が別の全体で働く作例を深める |
| ラサ論・第6／7章 | 生成、身体、表現と受容 | 優先。経験の組成まで読み下せる | 舞台の表現操作を語りへ移す技法を精密にする |
| セフィロト・書簡15／フォーチュン第32パス | 相補、関係、受け渡し、経路、変容 | 二つの資料を分けて用途限定。第32パスから二つの構成例を追加 | 別パス・逆方向の比較、著者との実作 |
| 五大・真言密教の五大／六大 | 身体、感覚、空間、表現 | 用途限定。空海の五大と響き・六大の識を参照して一場面へ戻す作例を追加。感覚表は作者案 | 原典・注釈の精査、別場面と実作での採否確認 |
| 儒家の役割・礼 | 役割、反復、価値と行為 | 関係位置や所作を扱う場面に限定。一般的なマナー論へ縮めない | 一つの原典上のやり取りと、役割が変わる場面を繋ぐ |
| 四句分別 | 認識、述語、対立 | 二者択一の問い直しに限定。四つの結論を選ぶ表にはしない | 特定の論者・原文の否定の働きへ戻る |
| 古典修辞学の争点論 | 問い、役割、対話 | 対話・論述のすれ違いを読むときに限定 | 参照する著者の区別と、台詞の応答を繋ぐ |
| ニヤーヤ五支論証 | 推論、例証、適用 | 理由の橋を読む場面に限定。人物一般の変容には広げない | 特定の例証と、対象へ適用できない条件を深める |
| マヤ暦 | 周期、複数時間 | 最初の推薦は保留。現在の技法は周期の結合計算へ寄っている | 特定の暦の意味・生活・儀礼と作品上の経験の接続 |
| サーンキヤ | 生成、観察位置、認識 | 最初の推薦は保留。現在の例は一般的な観察／解釈の区別が中心 | 古典の生成系列と混合の意味から、一般論を超える読みを作る |
| ルルスの後期アルス | 分節、組合せ、問い | 最初の推薦は保留。現状は人物×相手×場所の任意の組合せに寄る | 原典の定義・規則と組合せを一緒に動かす具体例 |
| マーシャル諸島の波航海術 | 身体、手掛かり、経路 | 最初の推薦は保留。現状は予想と現場のずれという一般的な案 | 公開された関係の読みを保った、身体と経路の緻密な展開 |
| 神社参拝の境界・清め | 境界、準備、行為 | 一般的な執筆への最初の推薦は保留。入口と準備だけでは薄い | 具体的な実践の意味と、作品内の状態・所作の違い |
| チベット仏教マンダラ | 空間、層、接近 | 最初の推薦は保留。現在の作例は中心と周縁の一般的な配置へ寄る | 一つの資料に描かれた配置・関係の意味からの具体化 |

観点の広さを埋めるために、保留したものを直ちに別の体系で補充しません。たとえば時機はまず易の読解、身体と表現の関係はラサ論から深められます。五大やセフィロトの未了部分は、上の優先調査として扱います。

## 外れを減らすため、今すぐ変える案内

- 体系一覧を、どれも同じように使える推薦リストとして読ませない。
- ビット反転、周期の結合、任意の組合せ、中心と周縁の配置だけで、伝統の意味を汲んだことにしない。
- 原典から導いていない感覚表は、作者側の補助として示す。
- 明示された意味を持つ状態から、大胆に仮説を展開する働きは残す。精査を、事前に全対応を証明しなければ使えない制度へ変えない。
- 「体系に知が乏しい」「資料がない」「技法が粗い」「場面に合わない」を分ける。今回の保留理由の多くは、現在の資料や技法の限界である。
