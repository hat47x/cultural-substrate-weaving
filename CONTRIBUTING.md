# Contributing

[日本語](CONTRIBUTING.ja.md) | [English](CONTRIBUTING.md)

1. Discuss method-level changes in an issue before a large pull request.
2. Edit `src/ja-JP/` for canonical method changes.
3. Update `src/en-US/` and translation metadata when the canonical source changes.
4. Edit `adapters/` for platform-specific behavior.
5. Run `make check`.
6. Describe semantic, activation, translation, and token-budget impacts in the pull request.

A translation should preserve functions, conditions, exceptions, and stopping rules, not merely word correspondence.
