# Cultural Substrate Weaving — 日本語

文章・設計・分析・アーキテクチャの構造レビュー。接続の欠落、反作用、時間差、不可逆な選択を洗い出し、各所見を対象に照合してから報告します。

Version {{VERSION}} · MIT · [リポジトリ](https://github.com/hat47x/cultural-substrate-weaving)

## インストール

Claude Code:

```bash
claude plugin marketplace add hat47x/cultural-substrate-weaving
```

```bash
claude plugin install csw-method-ja@cultural-substrate-weaving
```

Codexは同じプラグインディレクトリを読みます:

```bash
codex plugin marketplace add hat47x/cultural-substrate-weaving
```

## 使い方

**明示呼び出し専用**です。自動では起動せず、呼ばない限りトークンを消費しません。

```text
/csw-method-ja:cultural-substrate-weaving-ja <依頼内容>
```

例:

- `この当番運用規程を、引き継ぎの欠落と不可逆なエスカレーションの観点で見てください。`
- `このサービスの責任境界を検査してください。担当チームが変わったとき何が壊れますか。`
- `この章の草稿が平板です。文章ではなく構造に何が欠けているかを探してください。`
- `ポストモーテムに原因が列挙されています。原因どうしの関係で、書かれていないものはどれですか。`

## 実行例

短い問い合わせ当番運用規程（当番は日替わり、エスカレーション後も窓口は当番が維持、対応記録は1行で月末に件数集計）に対して、通常のレビューは明白な穴を返します——時間外の扱いがない、「判断できない」の基準がない、エスカレーション後の期限がない。

構造分析から出て除去検査を通過した所見は次の2件でした。

1. **日替わり当番と単一窓口の約束が構造的に衝突する。** エスカレーション中の案件を担当する当番は翌日には別人で、引き継ぎが定義されていない。
2. **判断が次へ渡る経路が存在しない。** 「判断できない」の線引きは人によって違い、記録は1行、集計は件数のみ。ある当番の判断が次の当番へ届かない。

どちらも基準線には現れず、どちらも体系ではなく規程についての言明です。

## 中身

Markdown 15ファイルとJSONマニフェスト2ファイル。**実行ファイル、MCPサーバー、フック、ネットワークアクセス、同梱バイナリはいずれもありません。** 材料を読んで分析を書く、それだけです。

参照ファイルは分析が必要とした時にだけ読み込まれるため、スキルを使わないセッションではコストがかかりません。

## 仕組みと、主張していないこと

領域固有の通常分析をまず基準線として置き、外部の体系から構造を借りて基準線が取りこぼしたものを探し、候補をすべて対象側の材料で検証します。

文化的・思想的・伝統的体系は、参照ファイルに**構造の供給源の例**として現れます——対象を見る前に定義された位置の集合としてです。**本方法論はそれらが真であるとは主張せず、予言、占い、診断、実在人物についての断定を一切生成しません。**

仮説は、そうした体系が機械学習の転移学習における事前学習表現と同じように振る舞うというものです。単一の対象からは誘導できない構造を運ぶ事前分布であり、その価値は体系自身の正しさではなく結果が改善するかで決まります。方法論はこれを**除去検査**で強制します——体系名、対応表、術語をすべて削除し、なお対象についての言明として成立する所見だけを報告します。反証条件も明示しています：生存所見が基準線を上回らなければ、転移は起きていません。

対応関係の全体は[なぜ外部体系を使うのか](https://github.com/hat47x/cultural-substrate-weaving#なぜ外部体系を使うのか機序の仮説)にあります。
