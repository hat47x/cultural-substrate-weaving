cultural-substrate-weaving — Microsoft 365限定プロファイル

このパッケージは、Microsoft 365 Copilot向けにCSWの実行範囲を絞った、自己完結型の限定アダプター（limited adapter）です。

■ instructions.txt
文化体系の視点による構造読解、発見、帰属保持、対象への返却、具体化を扱う実行指示です。親和図法の材料統合と複数回の継続管理は別スキルへ委ね、内部手順を埋め込みません。利用できる別スキルがなければ、その不足を示します。

■ method-reference/
CSWの詳細を人間が確認するための参照資料です。Agent BuilderやSharePointのKnowledgeへアップロードして、instructions.txtの続きを実行させるためのファイルではありません。

■ Microsoft 365 CopilotのKnowledge
分析対象となる業務資料、調査資料、組織内文書などを、対象側の事実グラウンディングに使う場所です。method-reference/とは役割が異なります。

この限定版は、他の対応プラットフォームとの完全な実行同等性を保証しません。詳細な体系固有の操作、体癖の特例、完全な材料統合や複数回の履歴管理など、instructions.txtに含まれない手順は実行範囲外です。
