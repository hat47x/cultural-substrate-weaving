# 採用済み文化体系ポートフォリオ

このファイルは、CSWが内部に保持する文化体系の索引である。ここで「採用済み」とは体系を正しい説明や自動分類器として認めることではなく、体系固有の構造核を、通常分析とは異なる認知操作を生む触媒として再利用できるだけの資料品質に達したことをいう。

## 読み方

1. 今回ほしい認知操作から体系を選ぶ。
2. 対象へ当てる前に、該当ドシエで体系自身の位置・関係・遷移・実践・異説境界を確認する。
3. 体系にない操作をCSWが補う場合は、体系固有のものと混同しない。
4. ドシエで足りない系譜差や細部だけを外部資料で確認する。採用済み体系まで毎回ゼロから検索し直さない。
5. ドシエにない体系も候補にはできるが、モデル記憶だけで構造を補って採用済みに昇格させない。

## 欲しい認知操作から引く

体系名を先に思い出すのではなく、現在の対象理解で不足している認知操作から候補を引く。近い体系が複数ある場合は、下表の違いを保ったまま一つか二つを選ぶ。

| 不足している見方 | 第一候補 | この体系が特に開くもの |
|---|---|---|
| 配置の一部を変えたときの全体差 | 易 | 位置、組合せ、局所変更と全体状態 |
| 表面から生成層へ遡りたい | サーンキヤ | 生成順序、観察者と生成過程の分離 |
| 二択そのものを疑いたい | 四句分別 | P、非P、両方、どちらでもない |
| 主張へ視点や条件を戻したい | ジャイナ七分法 | 条件付き述定、言表不能な残差 |
| 表現内容と受け手の経験を分けたい | ラサ論 | 表現、構成、受容の生成関係 |
| 複数周期と長い時間尺度を同時に見たい | マヤ暦体系 | 位相差、部分再来、全体再来、長期座標 |
| 部分と全体を相互に規定して見たい | 華厳 | whole-part reciprocity、node視点 |
| 理由から結論への橋を検査したい | ニヤーヤ五支論証 | 理由、例証、適用、結論の接続 |
| 役割名、関係、実際の行動を分けたい | 儒家の役割・礼 | relation-conditioned action、定型的相互作用 |
| 内容と伝達経路を分けたい | ハディースisnād / matn | 本文、伝承鎖、分岐・合流、異同 |
| 地図より局所的な手掛かりで経路を見たい | マーシャル諸島の波航海術 | 相対経路、cue sequence、model / environment return |
| 明示された境界を越える前後の準備を見たい | 神社参拝の境界・清め | threshold、preparation、central act、return |
| 中心・方位・門を持つ空間として見たい | チベット仏教マンダラ | center / periphery、directions、gates、nested boundaries |
| 普段組み合わせない区別を体系的に交差したい | Llullの後期Ars | binary / ternary crossing、rotation、unseen combination |
| 身体反応から観察軸を開きたい | 体癖 | 緊張・弛緩を含む身体論的な観察 |

### 近接体系を混ぜない

- 易とマヤ暦体系はいずれも変化を扱うが、易は配置の変化、マヤ暦体系は複数周期と時間尺度を主に開く。五行は関係循環を開くresearch candidateとして、明示指定時に参照できる。
- 四句分別、ジャイナ七分法、ニヤーヤ、stasis theory、四原因はいずれも議論を組み替えられるが、命題空間、述定条件、推論の橋、争点の種類、説明の種類をそれぞれ別に扱う。
- 華厳と儒家の役割・礼はいずれも関係を扱う。華厳は全体と部分の相互規定を、儒家の役割・礼は具体的な役割・関係・行為の適合を主に見る。
- ハディースisnād / matnは来歴と内容を分ける。来歴が明確であることを内容の真実性へ変換しない。
- マーシャル諸島の波航海術はnetwork一般ではなく、事前モデルと現場の手掛かりを往復する経路探索を主に開く。

一つの体系で対象を説明し切ろうとしない。第一候補で新しい問いが生じた後、別の認知操作が必要になったときだけ第二候補を開く。

## ポートフォリオとしての不足を残す

暦・長周期、whole-part、論証、役割・礼、伝承経路、経路探索は一段厚くなった。中心・周縁・方位を持つ空間構造と、明示的な境界通過・事前準備も一段厚く、未検討の組合せを体系的に開く操作も備える。五行はdiscovery-aware基準で初めて降格を完了した体系であり、通常のfeedback／control analysisがtested capabilityを再現するだけでなく、autoscaler oscillationという対象自体が同じ認知jobをframework contact前に自然に開くことを確認した。一方、華厳は同じ基準でcontext-defined identityのdiscovery contributionが残るためruntimeに保持した。Mīmāṃsā、縁起、古典stasis theory、アリストテレス四原因は旧基準でoperationally demotedのままだが、discovery valueの遡及reviewを残す。いずれも明示指定・比較研究・歴史的対象ではresearch candidateを参照できる。一方、索引付き物語コーパスと、系譜差を保った媒介層はまだ薄い。似た体系の数を埋めるのでなく、現在ない認知操作を優先して増やす。

体系数自体は成功指標ではない。ただし異質な構造へ接触できる母集団が狭ければ「出会う」機能そのものが痩せる。効果検証を急ぐ前に、構造的な重複を抑えながら質と量を増やす。
