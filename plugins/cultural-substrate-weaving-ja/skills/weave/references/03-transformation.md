# 03-transformation

体系内の関係を対象専用の質問・検査・手順へ変換するときに読む。

## 4. 対象専用の手順へ変換する

体系内の関係を、対象で使える動詞、質問、検査項目へ変換する。

関係を移す前に、次の種別を明示する。

- 分類上の対応
- 因果関係
- 時間的推移
- 規範上の優先順位
- 象徴的類似

人や組織の行為を扱う場合は、**観察、反復、機能、意図を分ける。** 何が記録されたか、同種の現象が複数の主体で繰り返されるか、その現象が結果として何を保護し何を抑えているか、その効果を目的として行った直接の資料があるか。**機能は認めてよい。意図は読まない。** ある行為が自己保身に機能していることと、本人が自己保身を意図したことは別である。

要素の対応と、因果・時間順序の対応を分けて検証する。体系内の生成、抑制、階層、周期は、関係種別ごとに対象と照合する。

階層を持つ体系では、段階系列と層の重なりを区別する。また、一要素に見えて、全層の意味を変える原理がある。通常の一要素と、全体の解釈条件を分けて扱う。

欠落を検討する前に、体系の被覆範囲を確認する。

- 閉じた集合か、開いた一覧か
- 排他的か、重複を許すか
- 離散的か、連続的か
- 全要素が今回の対象範囲に関係するか

重複を許す体系では偏りを調べる。連続的な体系では、位置と程度を調べる。

次に、要素自体の欠落と、接続の欠落を区別する。要素が存在し、必要な接続だけが欠けている場合は、接続、順序、責任、情報流を修正する。

要素自体が存在しない場合は、次の四つに分類する。

1. 今回の対象範囲外である。
2. 対象の主要変化構造と両立しない。
3. 意図的に省略されている。
4. 対象の目的に必要だが、まだ扱われていない。

第四の場合に、追加候補を生成する。第二の場合は、対象が使わずに成立させている要素として記録する。

欠落検出と一貫性検査を分ける。

- **欠落検出**：複数単位の集合に対して、閉集合と同種性を条件に未対応要素を探す。
- **一貫性検査**：単一の人物、制度、組織に対して、外部由来の型と振る舞いを比較する。

単一単位には一貫性検査を使う。

深さの異なる層を扱う場合は、個人の身体にある未言語の反応／場所や物に蓄積した共有の経験／局所と全体に反復する同型構造を区別する。**層ごとに別の体系を使い、共通する変化原理で統合する。**

**直交する体系を重ねることは、単独の体系からは出ない構造を生む。積極的に試す。** 一つの体系が位置を与え、別の体系が同じ対象を別の分類原理で切るとき、二つの格子の交点に、どちらの体系も単独では名指せない場所が現れる。

複数体系を組み合わせる場合は、軸の独立性を確認する。各軸には、対象から独立した根拠と、異なる分類原理を持たせる。比較対象群の一つから得た軸を全体の基準にせず、各対象から独立に構造を抽出してから比較する。

連続的な体系同士を交差させた場合は、連続量として扱う。空欄の多いマトリクスが対象に合う場合は、その状態を保持する。

複数体系を使う場合は、次のリスクを確認する。

1. 不採用条件のない体系が、確証を増やし、対象側の検証を弱める。
2. 体系間の一致が、対象由来か、解釈者の変換規則由来かを分けて検査する。
3. 対象の事実や因果関係に結び付かない記号が、既存理解の言い換えを生む。

二つ目以降の体系には、一つ目では扱えない情報種別を担当させる。同じ分類原理の体系を重ねても、確証が増えるだけで新しい交点は生まれない。

小規模で閉じた離散集合を同程度の深さで検討でき、網羅性が必要な場合は、サンプリングより全件検討を優先する。情報量、作業量、後付け適合の余地が増えるため、開始前に適合基準、詳細検討する候補数、停止条件を定義する。

解釈の固定化を外す場合は、対象情報の提示順、グループ化、比較順を変えて結果を比較する。無作為化を使った場合も、解釈者の影響を記録する。
