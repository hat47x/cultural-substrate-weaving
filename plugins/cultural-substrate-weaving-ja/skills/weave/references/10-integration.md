# 10-integration

多数の断片から全体像を立ち上げるときに読む。材料が多く、粒度が不揃いで、既存の枠に収まらない場合に使う。

## 系統

この手順はKJ法に由来する。系統は川喜田二郎『KJ法：渾沌をして語らしめる』（中央公論社、1986年）を主とし、『発想法：創造性開発のために』（中公新書136、1967年）『続・発想法：KJ法の展開と応用』（中公新書210、1970年）を補助とする。KJ法は株式会社川喜田研究所の登録商標である（商標登録第4867036号）。

**別系統は親和図法である。** 1977年にQC手法開発部会がA型図解を品質管理向けに採り、商標を避けて改称した。相違は、KJ法が未知の構造を立ち上げる発想法であるのに対し、親和図法が既知の課題を扱いやすくする整理法へ寄る点にある。**この文書はKJ法の側を採る。** 川喜田は分類整理の手法としてKJ法を考案していない。

**流通量と原型は逆向きである。** 最も読まれているのは新書二冊の簡略形で、最も完全なのは最も読まれていない1986年の総括である。記憶から補うと簡略形へ寄る。

典拠のある実践として、第三者が読める札、分類名ではない表札、A型図解とB型叙述の区別を重視する。**材料を伏せて立てる操作、カード境界、来歴メタデータの設計、戻し検査で見る付加例、および戻し検査の再実行方法には、生成AIでの実践から加えた現代的補正を含む。** 枚数や文字数は意味境界の判定規則にしない。

判断に迷った場合は、この文書から導出せず、上記の一次資料とKJ法の関連技術に当たって補う。**資料に当たれない場合は、その判断を自己申告として記録して進む。** 記憶だけで系統を宣言しない。

## 13. 断片から全体像を立ち上げる

**この手順の主産物は、整理された結論ではなく、そこに無いものの発見である。**

断片を分類の対象ではなく、一人の話者として扱う。母親が幼子の言葉を聴くように、その断片が何に手を伸ばしているかを聴く。

- 話者は自分の意味を十分に表現できていない。文字列を処理せず、何を訴えているかを読む。
- **語彙の多い側が、意味を知っている側ではない。** 分析者の流暢さが材料を上書きする。整った言葉が出たときほど疑う。
- **断片は「違う」と言えない。** その「違う」を分析者が人工的に作る。後述の検査はすべてその代用品である。
- 束が揃う前に表札を書かない。早く言葉になったものほど、分析者が用意していたものである。
- **理由の言えない注意は、理由が言えないまま一枚にする。** 気になる強さと、その読みが当たっている確からしさは別である。後付けの理由で仮説へ格上げせず、説明できないことを理由に捨てもしない。消えてよい。

最も起きやすい失敗は、もっともらしい分類体系を作ることである。分類は既存の枠へ材料を流し込む操作であり、材料は語っていない。

**カードの段階では材料に忠実にする。** 入口で均された材料からは仮説が立たない。渾沌を渾沌のまま入力できることが、この手順が働く条件である。

対立する見方は、統合によって差が消えないよう保持する。異なる話者・証拠状態・評価が切り替わるなら別札にする。一つの体験の中に両義性が不可分に含まれる場合は、その両義性を一枚の自然言語として残してよい。対立を早期に「どちらも同じ」へ均すと、後の図解で拮抗が見えなくなる。

カードを弱める、ぼかす、行為者を落とす、断定を推量へ下げる——**いずれも割当の材料を書き換える操作である。** **集める段階の閾値を、外へ出す段階の閾値に合わせない。** やむを得ず弱める場合は、**変えたことと失われたものをカードの側に書く。** 記録しない弱めは、この手順では行わない。

**カードを切り出すことと、束に表札をつけることと、表札をさらに一つへまとめることは、別々の技法ではない。材料から意味の単位を立てるという一つの操作を、粒度を変えて呼んでいる。** 用途を先に置かない。重複の除去も枚数の圧縮も、この操作の目的ではなく、結果として起きることである。

操作の内側は次の四つ。

1. **境界を決める**：**意味の一体性を守るためには結合し、証拠状態を守るためには分割する。** 一つの体験・判断・因果の運動を成す複数の出来事は、機械的に割らない。観察と解釈、確認と推測など、証拠の状態が切り替わる箇所では分ける。長さでは決めない。
2. **核を抜く**：各材料が何を訴えているかを短く取り出す。何を失えばもう同じ意味ではなくなるかを見る。
3. **伏せて立てる**：**元の材料を一度見えないようにし、抜いた核だけを並べて、そこから一文を立てる。** 材料を見ながら書くと要約になる。論理接続詞でつながず、上位のカテゴリ名へも逃げない。**ただし、伏せて空いた場所は分析者の語彙で埋まる。引き写しは減っても、材料から離れる度合いは減らない。** とくに行為者が落ち、出来事が独りでに起きた形になりやすい。**選んだことを起きたことへ書き換えると、材料が持っていた自責が消え、免責の方向へ寄る。**
4. **戻して照合する**：伏せた材料を開いて突き合わせ、歪みを直す。捨てて書き直すのではなく、直す。**元に無い因果、人物の内面、一般化、評価の方向、確度の変更（推測を断定へ、伝聞を事実へ）を足していないかを見る。これらは頻出する検査観点であり、付加の型はこれらに限らない。** あわせて**意図して落とした差異を書き残す。** 落としたことが記録されていない差異は、後から取り戻せない。

手順は次の五つ。上の操作は、カードを切り出すとき、束を畳んで段を上げるとき、表札を書くときに呼ばれる。

1. **カード化**：材料に対して上の操作を行う。カード単独で何を訴えているか読める自然言語にする。分類名だけで済ませないが、名詞止め・文字数・一文一命題を機械的な禁止にはしない。**意味の一体性を壊す分割をせず、証拠状態を混ぜる結合もしない。**

   標準的な来歴メタデータとして、**出所**（元材料へ戻れる位置）、**発見経路**（投稿に埋め込まれた資料は、資料が出所であって投稿は経路である）、**段階**（材料から直に起こしたものか、束から立てたものか、他のカードから派生したものか）、**採取者と採取時**を保持できる。これらはKJ原典の固定欄ではなく、元材料へ戻るための現代的なresearch hygieneである。

   呼び出し側で識別子、原文位置、ハッシュ、原文言語など追加の来歴・管理情報が必要なら保持してよい。ただし、**意味内容を先に分類し、その分類が後の読みや束ねを決める欄は設けない。** 確度・役割・重要度・感情・種類などが材料の意味に不可欠なら、先験的な分類タグではなくカードの文そのものに残す。

   **同じ値が続く欄は、カード群の側に一度書いて各カードでは省いてよい。** 由来の違うカードが同じ場に混ざるときは、省いた欄を書き戻す。

   **外部の体系から得た問いは、対象へ戻して新しい観察か反証が返るまで、観察事実と同じ階層に置かない。**
2. **束ねる**：訴えの近いものを集める。初期の束を小さく始めることは有効なヒューリスティックだが、枚数・最終束数を成功条件にしない。材料の側が必要とする境界を優先し、数へ合わせて束を割ったり寄せたりしない。**どの束にも入らない断片はそのまま置く**（孤立した一枚が最も重要なことがある）。**出所・話者・立場・種別で束ねない。** これらは束ねた後に、偏りと独立性を検査するために使う。**同じ出来事の転載や、一枚から派生した二枚を、独立した二つの訴えとして数えない。**
3. **表札**：束に対して上の操作を行う。束が言いたいことを一文で代弁する。分類名ではない。
4. **配置**：因果・相互・対立・時間の前後を区別して関係を引く。反対は反対の形で描く。**引かなかった関係も描く**。描く順序は大局から先とし、束の編成と逆にする。
5. **叙述**：図解を読んで語る。図に無い順序で語らない。

検査は次の四つ。

- **表札の可搬性**：別の束にも同じように載るほど一般的なら、分類名へ逃げていないかを点検する。機械的な失格判定ではなく、その束固有の訴えを代弁できているかを見る。
- **戻し検査**：表札を持って各断片へ戻り、これが言いたいことかを当てる。上の検査観点だけでなく、断片の側が「これは自分の言いたいことではない」と返さないかを見る。一枚でも違和感が返れば、表札か束の構成が誤っている。**どちらに問題があるか判別しにくい場合は、同じ材料から表札を別passで立て直す、独立した評価者やモデルに同じ束を渡すなど、独立性を高める方法で戻し検査を再実行する。固定回数を成功条件にしない。表札を変えても同じ断片で同じ型の違和感が反復するなら、束の構成を見直す。**
- **空白の確認**：配置して「ここにあるはずの声や関係が無い」と見える箇所は言語化し、次の探索問いにできる。空白が見えない場合も見落としを点検するが、**空白を作るために欠落を発明しない。**
- **双方向照合**：叙述にあって図解に無いものは根拠がない。図解にあって叙述で落ちたものは、なぜ語れないかを問う。多くはそこに実例が無い。空白として登録する。**差分ゼロは媒体間の追跡可能性を示すだけで、対象の完全性を示さない。**

警告として見る徴候は次のとおり。表札がどの束にも載るほど一般的、最初から大きな分類箱ができる、対立がすべて調和へ溶ける、材料の強さや行為者が消える、出所が追えない、分析者の語彙が元材料より前面に出る、叙述だけが図解より整いすぎる。**これらは失敗そのものではない。材料より作法や分析者の枠が前へ出ていないかを点検する契機である。難航・孤立・空白・書き直しが生じたこと自体も成功条件にしない。**

**検出しても除去できない場合は、除去せず由来を表示して残す。** この手順は押し付けを防がない。可視化するだけである。
