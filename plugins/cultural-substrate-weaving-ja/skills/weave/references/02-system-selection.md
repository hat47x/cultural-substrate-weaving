# 02-system-selection

文化的体系を選び、同種性、不採用条件、限界を確認するときに読む。

## 3. 体系候補を調査する

体系名の列挙ではなく、構造型の違いに基づいて候補を絞る。各体系について、次を確認する。

- 構成要素と分類原理
- 要素間の関係
- 時間、周期、段階
- 生成と抑制
- 本来の適用領域
- 歴史的文脈
- 異説と限界

体系の用途は、次の四つから選ぶ。

1. **構造モデル**：対象全体の関係と配置を検討する。
2. **一貫性モデル**：単一対象の振る舞いを、外部由来の型との比較によって検査する。
3. **時間モデル**：時機、周期、蓄積、回帰、段階変化を検討する。
4. **遷移モデル**：体系を状態機械とみなし、対象の上で遷移を走らせる。到達しない状態、一度も起きない遷移、出たきり戻らない状態を探す。

用途を先に定め、評価基準を明確にする。**遷移モデルは、探索空間を体系の状態で格子状に覆い、格子のどこが埋まりどこが空くかで対象を読む用途である。** 静的な配置ではなく、動きうる先を見るため、構造モデルとは別に宣言する。手続きは`02a-framework-application.md`にある。

**時間モデルと遷移モデルは、静的な配置からは出ない構造を生む。積極的に選ぶ。** 配置図が出すのは、どの要素がどこに居るかまでである。因子ごとに状態の変化を追うと、いつ入っていつ出るか、戻れるか戻れないか、どの順でしか起きないかが出る。**これらは対象の性質であって、配置には現れない。**

欠落や偏りを検出する前に、体系の要素と対象の構造単位が同種かを確認する。同種の場合に限り、体系の要素から対象の欠落や偏りを検討できる。たとえば、外部体系が「類型」を単位とし、対象側が個別事象の集合を単位とするなら、同じ数に見えても異種である。この組合せでは欠落を導かず、類似する関係や問いの候補として扱う。

**同種性は体系の性質ではなく、体系と層の組の性質である。** 同じ体系が、ある層では同種、別の層では異種になる。層を言わずに「この体系は同種」と書かない。**単位の種類が同じでも、分類原理が違えば異種である。** 体系が位置を順序で分け、対象が別の原理で自分を分けているなら、そこから欠落は導けない。

構造単位が異なる場合、全件検討は類似関係の探索として、サンプリングは偶然の一致を確認する試行として扱う。欠落の根拠には使わない。

異種の体系は、次の用途へ切り替える。

- 関係を表す動詞を得る。
- 対比軸を設定する。
- 表現候補を生成する。

体系を採用する前に、不採用とする結果を定義する。どの結果にも適合する体系は、仮説の確証だけを増やすため、探索候補から外す。

**採用を決めた体系は、`02a-framework-application.md`へ進む。割当の手続きと採用後の四つの検査はそちらにある。検査を通していない所見は成果にしない。**
