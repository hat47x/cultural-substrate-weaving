# 03 — Transformation

Read this file when converting relationships inside a framework into target-specific questions, checks, and procedures.

## 4. Transform into a target-specific procedure

Convert framework relationships into verbs, questions, and checks usable on the target.

Before transferring a relationship, state its type. At minimum, distinguish the following relationship types:

- classificatory correspondence;
- causal relationship;
- temporal transition;
- normative priority;
- symbolic analogy.

When the material is the conduct of people or organizations, **separate observation, recurrence, function, and intent**: what was recorded, whether the same kind of thing recurs across several actors, what the pattern protects or suppresses as a result, and whether any direct source shows that effect was the aim.

For intent, **do not collapse directly documented intent, intent inferred from conduct or context, and an intent hypothesis generated by a cultural framework into the same evidence state.** That an act functions to protect someone is not direct evidence that the person intended self-protection. Keep using an inference as exploratory material separate from attributing it as a fact about the person's inner state.

Validate element correspondence separately from causal or temporal correspondence. Compare generation, inhibition, hierarchy, and cycles with the target for each relationship type.

In hierarchical frameworks, distinguish stage sequences from overlapping layers. Some principles look like one element while changing the meaning of every layer. Treat an ordinary element separately from a condition for interpreting the whole.

Before reasoning about absence, examine the framework's coverage:

- closed set or open list;
- mutually exclusive or overlapping;
- discrete or continuous;
- whether every element is relevant to the current scope.

For overlapping frameworks, examine bias. For continuous frameworks, examine position and degree.

Distinguish a missing element from a missing connection. When elements exist but a required connection is absent, generate candidates for modifying connection, sequence, responsibility, or information flow.

When an element itself is absent, distinguish at least the following cases.

1. Outside the current scope.
2. Incompatible with the target's primary change structure.
3. Intentionally omitted.
4. Necessary for the target's purpose but not yet addressed.

In the fourth case, an addition candidate can be generated. In the second case, the element may be recorded as something the target functions without. Whether any candidate enters real work returns to external use conditions or delegated judgment.

Separate absence detection from consistency checking.

- **Absence detection:** For a collection of multiple units, search for unmatched elements only when the framework is closed and the units are compatible.
- **Consistency checking:** For one character, institution, or organization, compare behavior with an externally derived type.

Consistency checking can also be used for a single unit.

Where layers of differing depth are involved, distinguish the unspoken bodily response held by one person, the shared experience accumulated in a place or an object, and the isomorphic structure that recurs locally and across the whole. Different frameworks may be used for different layers, or different layers of one framework may be used. When multiple frameworks are used, preserve not only shared change principles but also partitions on which the frameworks do not agree.

**Layering orthogonal frameworks produces structure no single framework yields. Reach for it.** Where one framework supplies the positions and another cuts the same target by a different classification principle, the intersections of the two grids hold places neither framework can name on its own.

When combining multiple frameworks, verify axis independence. Each axis needs a rationale independent of the target and a distinct classification principle. Do not derive a global axis from one member of the comparison group. Extract structures independently from each target before comparison.

When crossing continuous frameworks, preserve them as continuous quantities. If a sparse matrix fits the target, keep it sparse.

When using multiple frameworks, observable states include:

1. A framework without rejection conditions is increasing confirmation while weakening target-side validation.
2. Agreement among frameworks may originate in the interpreter's conversion rules rather than the target.
3. Symbols not linked to target facts or causal relationships are producing only a rephrasing of existing understanding.

These states do not automatically command reducing multi-framework use. According to external use conditions, treat them as decision material or as entries into further checks.

Do not restrict a second or later framework to information types that the first cannot handle. Even when frameworks address the same information type, an independent classification principle, temporal structure, path structure, or other axis can produce intersections and disagreements from which a third structure emerges. Conversely, do not count agreement produced by the same classification principle as additional independent target evidence.

When a small, closed, discrete set can be examined at comparable depth, complete review is one available method. Whether to sample or enumerate, and what fit criteria, detailed-review count, or delimiting conditions to use, follows external conditions or delegated judgment such as the requested completeness, resources, and purpose. This skill does not impose them uniformly as fixed prerequisites before starting.

To loosen fixed interpretations, vary the order of presentation, grouping, and comparison and compare the results when useful. When using randomization, record the interpreter's influence.
