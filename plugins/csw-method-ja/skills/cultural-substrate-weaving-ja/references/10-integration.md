# 10-integration

多数の断片から全体像を立ち上げるときに読む。材料が多く、粒度が不揃いで、既存の枠に収まらない場合に使う。

## 13. 断片から全体像を立ち上げる

**この手順の主産物は、整理された結論ではなく、そこに無いものの発見である。**

断片を分類の対象ではなく、一人の話者として扱う。母親が幼子の言葉を聴くように、その断片が何に手を伸ばしているかを聴く。

- 話者は自分の意味を十分に表現できていない。文字列を処理せず、何を訴えているかを読む。
- **語彙の多い側が、意味を知っている側ではない。** 分析者の流暢さが材料を上書きする。整った言葉が出たときほど疑う。
- **断片は「違う」と言えない。** その「違う」を分析者が人工的に作る。後述の検査はすべてその代用品である。
- 束が揃う前に表札を書かない。早く言葉になったものほど、分析者が用意していたものである。
- **理由の言えない注意は、理由が言えないまま一枚にする。** 気になる強さと、その読みが当たっている確からしさは別である。後付けの理由で仮説へ格上げせず、説明できないことを理由に捨てもしない。消えてよい。

最も起きやすい失敗は、もっともらしい分類体系を作ることである。分類は既存の枠へ材料を流し込む操作であり、材料は語っていない。

**カードを切り出すことと、束に表札をつけることと、表札をさらに一つへまとめることは、別々の技法ではない。材料から意味の単位を立てるという一つの操作を、粒度を変えて呼んでいる。** 用途を先に置かない。重複の除去も枚数の圧縮も、この操作の目的ではなく、結果として起きることである。

操作の内側は次の四つ。

1. **境界を決める**：**意味の一体性を守るためには結合し、証拠状態を守るためには分割する。** 一つの体験・判断・因果の運動を成す複数の出来事は、機械的に割らない。観察と解釈、確認と推測など、証拠の状態が切り替わる箇所では分ける。長さでは決めない。
2. **核を抜く**：各材料が何を訴えているかを短く取り出す。何を失えばもう同じ意味ではなくなるかを見る。
3. **伏せて立てる**：**元の材料を一度見えないようにし、抜いた核だけを並べて、そこから一文を立てる。** 材料を見ながら書くと要約になる。論理接続詞でつながず、上位のカテゴリ名へも逃げない。**ただし、伏せて空いた場所は分析者の語彙で埋まる。** 引き写しは減っても、材料から離れる度合いは減らない。とくに行為者が落ち、出来事が独りでに起きた形になりやすい。**選んだことを起きたことへ書き換えると、材料が持っていた自責が消え、免責の方向へ寄る。**
4. **戻して照合する**：伏せた材料を開いて突き合わせ、歪みを直す。捨てて書き直すのではなく、直す。**元に無い因果、人物の内面、一般化、評価の方向、確度の変更（推測を断定へ、伝聞を事実へ）を足していないかを見る。足しやすいのはこの五つである。** あわせて**意図して落とした差異を書き残す。** 落としたことが記録されていない差異は、後から取り戻せない。

手順は次の五つ。上の操作は、カードを切り出すとき、束を畳んで段を上げるとき、表札を書くときに呼ばれる。

1. **カード化**：材料に対して上の操作を行う。**名詞止めを禁じ、動詞で終わる文にする**（名詞だけでは何を訴えているか判定できない）。出所を付し、**出所と発見経路を分ける**（投稿に埋め込まれた資料は、資料が出所であって投稿は経路である）。**外部の体系から得た問いは、対象へ戻して新しい観察か反証が返るまで、観察事実と同じ階層に置かない。** **カードに種類の欄を設けない。** 確度も役割も重要度も、カードの文そのものへ書く。種類を先に与えると、以後その札越しにしか断片を見なくなる。
2. **束ねる**：訴えの近いものを集める。1段目は2〜3枚。**どの束にも入らない断片はそのまま置く**（孤立した一枚が最も重要なことがある）。段を重ねて5〜7束、多くて10束まで畳む。**出所・話者・立場・種別で束ねない。** これらは束ねた後に、偏りと独立性を検査するために使う。**同じ出来事の転載や、一枚から派生した二枚を、独立した二つの訴えとして数えない。**
3. **表札**：束に対して上の操作を行う。束が言いたいことを一文で代弁する。分類名ではない。
4. **配置**：因果・相互・対立・時間の前後を区別して関係を引く。反対は反対の形で描く。**引かなかった関係も描く**。描く順序は大局から先とし、束の編成と逆にする。
5. **叙述**：図解を読んで語る。図に無い順序で語らない。

検査は次の四つ。

- **表札の可搬性**：その表札を別の束に載せて成立するなら、分類名である。書き直す。
- **戻し検査**：表札を持って各断片へ戻り、これが言いたいことかを当てる。足しやすい五つに加えて、断片の側が「これは自分の言いたいことではない」と返さないかを見る。一枚でも違和感が返れば、表札か束の構成が誤っている。**どちらかは、独立に二度立てて確かめる。同じ箇所で同じ躓き方をするなら、直すべきは表札ではなく束である。**
- **空白の列挙**：配置して見える「ここに本来あるべき束が無い」箇所を必ず言語化する。**空白ゼロは、材料の完全さではなく探索不足を示す。**
- **双方向照合**：叙述にあって図解に無いものは根拠がない。図解にあって叙述で落ちたものは、なぜ語れないかを問う。多くはそこに実例が無い。空白として登録する。**差分ゼロは媒体間の追跡可能性を示すだけで、対象の完全性を示さない。**

失敗の徴候は次のとおり。表札が別の束に載る。1段目から五枚以上の束を作る。どの束にも入らない断片がゼロ。空白の指摘がゼロ。対立が図に現れない。出所が追えない。表札に分析者の語彙が現れる。畳む過程が無い。叙述が図解より整っている。表札がすらすら書ける。材料を伏せずに表札を書く。表札から行為者が消える。

**検出しても除去できない場合は、除去せず由来を表示して残す。** この手順は押し付けを防がない。可視化するだけである。
