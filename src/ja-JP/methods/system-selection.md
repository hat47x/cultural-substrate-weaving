# 02-system-selection

文化的体系と先行事例を選び、同種性、不採用条件、限界を確認するときに読む。

このファイルの列挙は、対象に応じて選択して使う。対象固有の追加項目は動的層に置く。

## 3. 体系候補を調査する

体系名の列挙ではなく、構造型の違いに基づいて候補を絞る。各体系について、次を確認する。

- 構成要素と分類原理
- 要素間の関係
- 時間、周期、段階
- 生成と抑制
- 本来の適用領域
- 歴史的文脈
- 異説と限界

体系の用途は、次の三つから選ぶ。

1. **構造モデル**：対象全体の関係と配置を検討する。
2. **一貫性モデル**：人物、制度、組織など、一つの単位の振る舞いを検査する。
3. **時間モデル**：時機、周期、蓄積、回帰、段階変化を検討する。

用途を先に定め、評価基準を明確にする。

体系は単一ではなく二つの層を持つ。分類に使えるのは一方だけである。

- **位置の層**：体系があらかじめ持っている、数の決まった置き場所の集合。各位置の意味は対象を見る前に定義されている。五行の五相、易の六爻、五倫の五つの関係、能の役の集合がこれにあたる。閉じている。
- **解釈語の層**：どの対象にも当てはまる部分。卦辞・爻辞、五色や五味の配当表、型に付随する性格記述がこれにあたる。開いている。**有名な部分ほどこちらに属する。**

層は、対象の要素をどの位置に置くか（割当）を決める述語の型で判別する。

- **計数述語**：対象内の語や記述の出現数で決まる。たとえば親族の位置が埋まっているかは、対象に「父」「母」の語が何件現れるかで決まる。位置の層。
- **計算述語**：対象と独立の手続きで決まる。たとえば暦法が日付を節気の区間へ割り当てる。位置の層。
- **類似判断**：分析者が似ていると判定する。たとえば爻辞の語彙と対象の語彙が「重なる」と読む。解釈語の層。

**割当は位置の層で先に確定し、その後に解釈語を使う。解釈語の読みが割当を変えることを禁じる。** 分析者が割当を選べる状態では、体系全体が解釈語の層に落ちる。外部手続きで割当が決まらない体系を分類に使う場合は、対象の観察可能な事実へ一意に対応づける手続きを外部規約として用意する。同じ体系でも、用途によって割当の所在が変わることがある。用途を先に宣言し、その用途での割当の所在で判定する。

解釈語の層は捨てない。判定には使えないが、二次効果の探索（ある位置を強めたとき、どこが過剰化しどこが抑制されるか）、反証仮説の生成（視点を反転した対立仮説）、感度分析（どの一点が変われば全体の性格が変わるか）、検査項目の供給、葛藤構造のひな型として使う。採否は対象の証拠が決める。

欠落や偏りを検出する前に、体系の要素と対象の構造単位が同種かを確認する。同種の場合に限り、体系の要素から対象の欠落や偏りを検討できる。たとえば、元型や物語類型と、個別場面や事実の集合は異なる単位である。この組合せでは、欠落ではなく、類似する関係や表現候補を探す。

構造単位が異なる場合、全件検討は類似関係の探索として、サンプリングは偶然の一致を確認する試行として扱う。欠落の根拠には使わない。

異種の体系は、次の用途へ切り替える。

- 関係を表す動詞を得る。
- 対比軸を設定する。
- 表現候補を生成する。

体系を採用する前に、不採用とする結果を定義する。どの結果にも適合する体系は、仮説の確証だけを増やすため、探索候補から外す。

採用後は次の二つを検査する。

- **反転検査**：その体系から得た主張を、自分で反証しにいく。反証の試みが「実は支持証拠だった」という形に吸収された場合、その体系をその対象に対して棄却する。反例が実在した場合は、吸収せず主張を縮小して残す。
- **代替検査**：別の体系でも同じ欠落が出るなら、その欠落は体系固有ではなく対象由来である。体系の寄与を零と記録する。発見自体は有効である。

先行事例も調査する。体系は関係構造を提供する。先行事例は、その構造を具体化する方法を提供する。技術的課題が同型の事例を選ぶ。

先行事例は、次の二つの立場で確認する。

1. 通常の受け手として確認する。
2. 分析者として確認する。

二つの確認結果の差分から、再利用できる手順を抽出する。

調査には、既存の解法を見つける用途と、未解決であることを確認する用途がある。後者は、課題を未解決問題として再定義する材料になる。

既存モデルが妥当な場合は、その妥当性を保持したまま、適用条件、到達範囲、限界を示す。
