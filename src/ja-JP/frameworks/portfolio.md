# 採用済み文化体系ポートフォリオ

このファイルは、CSWが内部に保持する文化体系の索引である。ここで「採用済み」とは体系を正しい説明や自動分類器として認めることではなく、体系固有の構造核を、通常分析とは異なる認知操作を生む触媒として再利用できるだけの資料品質に達したことをいう。

## 読み方

1. 今回ほしい認知操作から体系を選ぶ。
2. 対象へ当てる前に、該当ドシエで体系自身の位置・関係・遷移・実践・異説境界を確認する。
3. 体系にない操作をCSWが補う場合は、体系固有のものと混同しない。
4. ドシエで足りない系譜差や細部だけを外部資料で確認する。採用済み体系まで毎回ゼロから検索し直さない。
5. ドシエにない体系も候補にはできるが、モデル記憶だけで構造を補って採用済みに昇格させない。

## ポートフォリオとしての不足を残す

暦・長周期はマヤ暦体系で一段厚くなった。一方、空間方位、儀礼的手順、ネットワーク化された象徴体系、非西洋の法・修辞・物語構成などはまだ薄い。似た体系の数を埋めるのでなく、現在ない認知操作を優先して増やす。

体系数自体は成功指標ではない。ただし異質な構造へ接触できる母集団が狭ければ「出会う」機能そのものが痩せる。効果検証を急ぐ前に、構造的な重複を抑えながら質と量を増やす。
