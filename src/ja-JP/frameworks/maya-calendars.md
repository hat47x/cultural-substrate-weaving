# マヤ暦体系（Tzolk’in / Haab / Calendar Round / Long Count）

## 採用する構造核

マヤの暦体系には複数の周期・時間表現があり、CSWではそれらを一つの性格分類や占断表へまとめず、**異なる周期が同時に進み、部分的な再来と全体の再来が異なる**構造として扱う。

Smithsonian National Museum of the American Indian の Living Maya Time が示す主要構造は次である。

- Tzolk’in（Yucatec Maya）／Chol Q’ij（K’iche’ Maya）: 20のday signと1〜13の数の組合せによる260日の周期。
- Haab: 20日からなる18か月と5日のWayebからなる365日の周期。
- Calendar Round: Tzolk’inとHaabを組み合わせ、同じ組合せが18,980日、すなわち52 Haab年後に再来する。
- Long Count: k’in / uinal / tun / katun / baktun等の単位を使い、Calendar Roundを越える歴史的・神話的出来事を長期の時間座標へ置く。

このdossierはcalendar mechanicsを認知構造として採用する。day signごとの人格・運勢・儀礼的意味は別の解釈層であり、自動的には読み込まない。

## CSWで強い認知操作

- coupled-cycle pass: 二つ以上の周期を別々に保ち、現在位置を複合座標として見る。
- partial/full recurrence: 一方の周期だけが再来した状態と、複合状態全体が再来した状態を区別する。
- phase-desynchronization: 一方が似ていて他方が異なる地点を比較し、「同じ時期」という粗いまとめを崩す。
- recurrence-distance: 何がどの間隔で戻るのかを問い、短周期の反復と長期の再来を分ける。
- multi-scale time: 短い循環、結合周期、長期座標を同時に置き、異なる時間尺度で対象の見え方が変わるかを問う。
- cycle/count distinction: 周期的に戻る記述と、出来事を長期系列へ位置づける記述を混同しない。

## 対象へ返す問い

- 「同じことが起きた」とき、どの周期だけが同じで、何がまだ違うか。
- 二つの周期が同時に揃うまで待つと、現在の反復の意味は変わるか。
- 短期では循環に見えるが、長期座標では累積・不可逆な差が残っていないか。
- 一つのdominant cycleだけを見たために、別周期の位相差を落としていないか。
- 全体が再来したと判断するには、対象側でどの複数条件が同時に揃う必要があるか。
- calendar metaphorを外しても、複数周期・再来距離・時間尺度の問いは対象に残るか。

## 薄めてはいけない点

Tzolk’in / Chol Q’ijを単なる260日カウンターとして扱うだけでは、living Maya traditionとしての文脈を失う。一方、その文化的意味を一般対象へそのまま移植することもしない。

特に次を区別する。

- Yucatec MayaでのTzolk’inとK’iche’ MayaでのChol Q’ijという名称・生活文化上の文脈。
- calendar arithmeticとday signの解釈・儀礼・day keeping。
- 古代の暦記録と、現在も行われるMaya communitiesの暦・儀礼。
- 周期上の位置と、対象側で実際に観察される因果。

Living Maya Timeは、K’iche’ MayaのChol Q’ij新年儀礼やday keeper、YucatánのHaabに結びつく農耕儀礼など、現在の実践も示している。CSWはこれを「古代の消滅した暗号体系」としてだけ扱わない。

## 探索と帰属

探索では、複数周期、位相差、部分再来、長期座標を問いの生成器として使える。

対象が実際にTzolk’in / Haabと同じ周期構造を持つと帰属するには、対象側の周期定義と観測が別に必要である。calendar coordinateやday signを、対象の因果・人格・将来予測の根拠にはしない。

## 異説・適用境界

この最小dossierでは次を採用しない。

- day signごとの人格診断。
- 一般化されたfortune telling。
- Maya communities間の解釈差を消した単一の「Maya spirituality」。
- Calendar RoundやLong Countを現代対象へ直接対応させる固定換算。
- 2012年等のpopular prophecyを認知operationとして組み込むこと。

day signの意味や儀礼的実践を使う場合は、community / language / sourceを明示した別層として追加調査する。
