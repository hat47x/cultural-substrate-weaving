# 文化的体系を触媒に発見し、対象へ戻して確かめる

**本スキルは、認知操作、候補構造、来歴、差分を提供する道具であり、価値判断、利用範囲、読み込み深度、停止、採否、公開・行動への反映を独立に決定しない。これらの決定権は、著者の意思決定、またはスキル外で著者が生成AIへ与えた設定・指示・委任に属する。**

## 根幹価値

研究者は、日常のなかで無関係に見える概念に触れ、それを触媒として問いの見え方を組み替えることがある。本スキルは、この発見の体験を生成AIの作業のなかで疑似的に実現する経路である。触媒には、時の試練を経てきた文化的・思想的・伝統的体系を、答えや分類器ではなく一時的な認知場として使う。

体系から主に取り出すのは、世界全体を一つの系として分ける**類型**、状態のあいだの**遷移と位相**、各状態で現実のどこへ注意を向け、どう結びつけるかという**実践知**である。系譜は示すが、文化的な変異や装飾の重要度は一段下げる。

体系の規則は、観察から帰納された要約ではなく、世界を生み出す生成規則として**仮に**扱い、仮定を明示したまま大胆に走らせる。触媒は反応を促すが、生成物の成分にはならない。調査・診断では、体系は発見の触媒であって所見の根拠ではない。

探索では、位置、関係、状態、遷移、周期、象徴を、通常分析とは異なる認知資源として使う。**体系との一致だけでなく、対象が体系を押し返す不一致・抵抗・逆転にも注意し、その緊張から元のどちらにも還元できない第三構造が生じるかを見る。**

## 経路と照明

代表的な動きは、**抱く・出会う・走らせる・交える・降ろす・味わう**である。固定順序ではなく、戻りと反復を許す。詳細は`core/discovery-pathway.md`。

生成物が害をなすのは、多くの場合、内容の大胆さではなく、由来・仮定・射程の印を失ったときである。本スキルは画一的な関門を置かず、動きごとに視点を移して候補を照らす。

文化体系、対象材料、その接触から生じた構造は、由来を区別して追跡できる。`target_supported / framework_generated / cross_field_emergent / unresolved`などのラベルは来歴や状態を記録するためのものであり、それ自体から採用、発話、外部化、停止の可否を導かない。

材料の親和統合や複数roundの差分再開が必要な場合、利用可能なら専用のcompatible realizationへ委ねる。CSWはそれらの内部アルゴリズムを所有しない。

- one-round material synthesis: `affinity-synthesis` またはcompatible Method realization
- multi-round delta / reopen orchestration: `iterative-inquiry-synthesis` またはcompatible Method realization

compatible realizationがない環境でも、CSW自体の文化体系探索、帰属保持、対象側へのverification handoffは行える。ただし、実行していない親和統合やmulti-round orchestrationを実行済みとは称しない。

領域固有知識、品質基準、成果物の価値基準を本スキル自身は定義しない。必要な基準は、著者の指示、スキル外の設定、領域固有スキルや資料から受け取る。

課題の開閉、単純さ、緊急度といった課題種別そのものを、本スキル側の自動的な発動・抑制条件にはしない。**明示指定があれば**、課題の開閉に関わらず、少なくとも限定利用して基準線との差分を確かめる。

## 認知姿勢

対象から自分の読みを修正され得る位置に置く。**最初の見立てを当てることより、対象によって自分の見立てを変えられることを重く見る。** 対象の前では己を空しくし、体系は仮の生成規則として走らせる。二つの構えは両立する。

新しく生じた意味を、元材料が最初から語っていた事実へ書き換えない。詳細は `core/cognitive-stance.md` を読む。

## 最小実行手順

1. **委任を読み、状態を記録する**：著者の依頼、スキル外の設定・指示から、今回委ねられている判断、利用範囲、資源制約を確認する。必要なら`non_activation / limited / exploratory`、文化体系の`not_loaded / probe / preview / full / enacted`を現在状態として記録する。状態名そのものは次の行動を決めない。
2. **抱く**：問い、対象材料、基準線、壊してはならない保持事項を置く。
3. **出会う**：現在の分節から構造的に遠い体系を候補にし、その構造核へ触れる。体系固有構造を汎用語へ早く薄めない。
4. **全体場を開く**：対象への対応付けより先に、体系自身の位置集合、関係網、隣接・対立、周期、境界、遷移、実践、象徴的近傍を可能な範囲で保つ。探索利用で発見増分を広く取る場合は、体系数や読書量ではなく、異なる認知操作をどれだけ開けたかを重視する。
5. **多方向に走らせる**：仮定を明示したまま、配置・空位・補位置だけでなく、場の中の移動、遷移、周期、境界、実践を体系が持つ範囲で順に走らせ、問い・区別・関係候補・遷移候補・反証条件・観察／試行・残差を分けて取り出す。必要なら構造型の異なる第二体系で再分節する。
6. **交える**：対象材料と交差させ、一致と押し返しの両方を見る。多数・異種の材料から構造を立ち上げる必要があれば、`methods/integration.md` の接続契約を通じてcompatible synthesis realizationへ渡す。framework由来候補にgroupingや表札を先決めさせず、由来と判断主体を区別して追える形にする。
7. **体系語を外して降ろし、返す**：候補を対象語の問い、観察、小さな試し、構成、判断へと具体化し、候補、差分、残差、反証、来歴を提示する。採用・停止・公開・行動への反映は外部の決定権へ返す。生成AIに判断が委任されている場合は、その委任の範囲で判断する。第三構造が生じても、対象側の独立supportなしに事実へ昇格させない。
8. **味わう**：実際に起きたことを新しい材料として受け取る。新しいframework contactが旧artifactや残差へ触れるなら、`core/iteration.md` の接続契約からcompatible iterative realizationへ渡す。

文化体系の数、読み込み深度、全文読解の有無、体系固有操作の実行有無は、それ自体では成功・失敗・停止を意味しない。外部の評価基準で必要なら、それらを観測値として利用できる。

## 重要な区別

- **利用状態 ≠ 価値判断**：`not_loaded / probe / preview / full / enacted`は状態を記述する。どの状態が望ましいかは外部の判断である。
- **来歴 ≠ 行動許可**：対象由来・体系由来・接触由来を分けても、それだけで採用・発話・外部化の可否は決まらない。
- **照明 ≠ 関門**：候補を照らして印を見えるようにしても、それだけで合否や削除は決まらない。
- **de-binding ≠ 独立観察**：体系語彙を外して文が成立したことと、対象側に別の観察・資料があることは別の情報である。どちらをどの程度の証拠として扱うかは、外部の証拠基準に従う。
- **探索 ≠ 帰属**：体系から問いを得たことと、対象にその構造があると判断したことを別の出来事として記録できる。
- **対応 ≠ 統合**：体系とのきれいな対応は、それ自体では第三構造ではない。対象と体系の差が保存されたまま新しい区別・関係・問いへ組み替わったかを見る。
- **framework output ≠ synthesis authority**：文化体系から来た候補は、親和統合へ渡す材料にはなれるが、groupingや表札を先に決める権威ではない。

## 読み込み方

一括読み込みを避け、参照順・参照数・文化体系の候補数や深度は、本スキル自身の価値判断では固定しない。

採用済み体系を使う場合は、まずframework portfolioから該当ドシエを読み、毎回モデル記憶やWeb検索だけで構造を再構成しない。外部検索は、ドシエにない系譜差・異説・細部の確認、または未採用体系の新規探索に使う。

- 外部から利用範囲や使用体系が指定されている場合は、その指定に沿って参照する。
- 著者が体系選定や読み込み深度を生成AIへ委ねている場合は、その委任を根拠として候補を想起・検索し、必要な参照へ進む。
- 文化体系、反復分析、Taihekiなどの各参照は、能力・操作を提供する。Routerは、それらを使うべきか否かを課題種別だけから自動決定しない。
- 対象固有の情報は動的材料として扱い、静的な方法記述と区別して参照できる。
