# 発動・読み込み深度・途中終了の判断

本スキルを使う範囲と、文化体系をどこまで読むかを判断するときに読む。

## 0. 二つの判断を分ける

1. **本スキルの発動範囲**：非発動／限定利用／探索利用。
2. **文化体系の読み込み深度**：`not_loaded / probe / preview / full / enacted`。

本スキルを使っても文化体系を毎回読む必要はない。文化体系を読んでも、全文読解や体系固有操作は必須ではない。

## 1. 発動範囲

暗黙発動では、領域固有手法に対して意味のある増分が見込めるかを見る。

- **非発動**：領域固有手法だけで目的を達成する。
- **限定利用**：KJ、来歴、一貫性、時間構造、接続欠落など必要な部分だけを使う。
- **探索利用**：主要構造そのものが未定で、文化体系による探索とKJによる材料統合を往復する。

探索利用の目安は、問題空間が開いており、構造・関係・状態・遷移の探索が中心で、複数次元が相互作用し、対象側へ戻って確かめられることである。

単純な校正・翻訳・計算・形式変換・定型実装・局所修正、または緊急性の高い作業では通常手法を優先する。

判断が拮抗する場合は、割り込みの小さい限定利用から始める。

## 2. 明示指定

本スキルが明示指定された場合は、予測だけで利用を拒まない。ただし明示指定はfull loadや体系固有操作の強制を意味しない。

特定の文化体系が指定された場合も、まず短く開き、対象側に残るものを見る。適合が弱ければ、その弱さを記録して戻ってよい。

## 3. 読み込み深度

- **`not_loaded`**：文化体系を開かない。対象とKJだけで現在の問いを扱える場合の正規経路。
- **`probe`**：対象起点の入口。別の認知場を開く具体的理由があるかを見る。周期、経路、境界、中心／周辺、複数時間尺度、流れ、連続体、反復とずれなど、未処理構造を対象側から探す。
- **`preview`**：候補体系の主要な認知構造と限界へ軽く触れる。対象起点では、probeで立った問いに関係する位置・経路・周期・関係を見る。探索利用では別の入口として、現在の問題設定に合う部分だけへ先に絞り込まず、候補体系自身が何を位置・経路・周期・関係・遷移・境界として区別しているかという全体像を、対象へ対応付ける前に一度見てもよい。
- **`full`**：原典、系譜、象徴、複合構造まで必要な場合に読む。
- **`enacted`**：体系固有の操作が対象側の問いに具体的な意味を持つ場合だけ実行する。

対象起点の経路では、probeで具体的な問いが立たなければ原則として深めない。一方、探索利用で候補体系がすでに明示されている、対象の文化的・歴史的背景から自然に候補がある、または現在の問題設定そのものを別の認知場から揺らすことに意味がある場合は、対象側の問いを先に完成させなくてもpreviewへ入ってよい。

体系起点のpreviewは、体系を採用したこと、対象を全位置へ対応させること、fullやenactedへ進むことを意味しない。そこで生じた問い、対比、調査先、KJへ戻す材料候補は`framework_generated`として対象へ返す。previewで十分ならKJへ戻る。fullまで読んでも操作が不要ならenactedへ進まない。

## 4. 縮小・終了

次のような場合は読み込み深度を縮小し、必要なら本スキルの発動範囲も縮小する。

- 新しい意味単位・関係・問いが立たない。
- 増分が既存内容と重複する。
- 体系語彙だけが増える。
- 操作が対象の事実、境界、不可逆性、証拠状態を薄める。
- 基準線だけで現在の目的を達成した。
- 帰属利用に必要な同種性や検証材料を確保できない。

「十分に文化体系を使った感じ」を得るためだけに進まない。

ここで縮小するのは本方法論または個々の文化体系の利用であり、依頼者から委ねられた課題範囲そのものを勝手に縮めることではない。必要なら領域固有手法へ戻って作業を続ける。

現在必要な成果物・判断・調査方針が得られ、重要な残差と再開条件が保存されていればラウンドを区切ってよい。後から新資料が残差へ触れたら、以前より深い段階で再開できる。

人間側に明示的な資源制約がある場合はそれに従う。外部要因で中断した場合は未解決と再開条件を残す。
