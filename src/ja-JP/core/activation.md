# 利用範囲と読み込み深度の状態

本スキルの利用範囲と、文化体系をどこまで開いているかを表現するときに読む。

**この文書は、利用範囲や深度を決める決定器ではない。** 価値判断、利用範囲、読み込み深度、停止、採否は、著者の意思決定、またはスキル外で著者が生成AIへ与えた設定・指示・委任から受け取る。

著者がこれらの判断を生成AIへ委ねている場合、生成AIはその委任の範囲で判断できる。その判断の根拠はこのモジュール固有の優先規則ではなく、外部から与えられた目的、制約、評価軸、委任である。

## 0. 二つの状態を分ける

1. **本スキルの利用範囲**：`non_activation / limited / exploratory`。
2. **文化体系の読み込み深度**：`not_loaded / probe / preview / full / enacted`。

これらは現在の実行状態を記録する語彙であり、上位・下位、成功・失敗、望ましさを内包しない。

## 1. 利用範囲

- **`non_activation`**：現在の外部判断または委任結果として、本スキルの操作を使っていない状態。
- **`limited`**：KJ、来歴、時間構造、接続、文化体系の一部など、選ばれた操作だけを使っている状態。
- **`exploratory`**：文化体系による探索、KJ、変換など複数の操作を往復している状態。

課題が単純か複雑か、開いているか閉じているか、校正・翻訳・計算・実装・創作のどれに属するかといった課題種別は、状態を記述する材料にはなり得るが、本スキル固有の自動的な発動・抑制条件にはしない。

明示的な指定がある場合も、指定がない場合も、利用範囲はスキル外の意思決定・委任へ戻して扱う。

## 2. 文化体系の読み込み深度

- **`not_loaded`**：文化体系をまだ開いていない状態。
- **`probe`**：対象側の語彙や構造から、体系候補につながる問い・関係・状態・遷移を軽く探索している状態。
- **`preview`**：候補体系の主要な認知構造、位置、関係、周期、境界等へ軽く触れている状態。
- **`full`**：原典、系譜、象徴、複合構造など、より広い体系情報を参照している状態。
- **`enacted`**：体系固有の操作を実際に実行している状態。

`probe`で新しい問いが立たなかったこと、`preview`で既存理解との重複が多かったこと、`full`で体系固有情報が増えたことなどは**観測された差**として記録できる。それ自体を、深める・戻る・止めるという自動トリガーにはしない。

候補体系が明示されている場合、文脈から生じた場合、`methods/system-selection.md`の候補想起アンカーから得た場合など、入口の来歴も記録できる。どの入口を選ぶか、何候補を見るか、どこまで深めるかは外部の委任に従う。

### 深度を認知仕事の面として使う

外部の目的・委任として、文化体系の認知寄与を広く取りに行く場合でも、`probe / preview / full / enacted` を単なる読書量の階段として扱わない。それぞれで開く**認知仕事**を区別する。

| 深度 | 主に開く認知仕事 |
|---|---|
| `probe` | 対象の現在の分節とは異なる問い・関係・状態・遷移が立ち得るかを軽く探り、体系候補と認知機能候補を作る |
| `preview` | 対象へ対応付ける前に、体系の位置集合、関係、周期、境界、遷移、実践などの構造核を全体として捉え、複数のoperation方向を開く |
| `full` | 原典・系譜・複合構造・解釈語・実践の層・重要な異説まで開き、previewでは見えなかった反対位置、例外、前提、別系譜による揺らぎを探索へ加える |
| `enacted` | 体系固有のoperationを実際に走らせ、問い・対比・反証条件・観察・小さな試し等として対象へ返す |

最大活用を目的にしていても、各深度を順番に必ず通る必要はない。重要なのは、深度を上げた結果として**新しい認知operationが開いたか、対象へ返せる差が生じたか**を追えることである。

同じ深度でも、まだ使っていないrelation / transition / practice / boundary等のoperationへ回る方が、単に追加資料を読むより認知寄与が大きいことがある。逆に、`full`まで読んでも体系内部の説明だけが増え、対象側に返せる問い・識別・試行が増えない場合、その状態をそのまま観測として残す。

## 3. 深度変更の判断材料

次のような状態は、利用範囲や読み込み深度を見直す**判断材料**として提示できる。

- 新しい意味単位、関係、問いが増えた／増えなかった。
- 既存内容との重複が増えた。
- 体系語彙や説明量だけが増えた。
- 対象の事実、境界、不可逆性、証拠状態の記述が変わった。
- 基準線と比べて成果物や問いが変わった／変わらなかった。
- 帰属に関する対象側材料がある／ない。
- 作業量、時間、計算量、外部資源の消費が変わった。

この文書は、これらの状態に対して「縮小すべき」「継続すべき」という価値を割り当てない。著者またはスキル外の委任が、これらをどのように評価するかを決める。

## 4. 終了・再開・資源制約

ラウンドをどこで区切るか、残差をどこまで保存するか、後で再開するかは、外部の目的・委任・資源制約に従う。

終了時に必要なら、現在の利用状態、未解決事項、残差、次に開ける参照先を記録できる。これは再開可能性を残すための記録操作であり、終了判断そのものではない。

外部から明示された時間、費用、コンテキスト、プライバシー、その他の資源制約がある場合は、その制約を利用状態とともに記録する。本スキル自身が独自の資源価値を追加して利用を抑制しない。
