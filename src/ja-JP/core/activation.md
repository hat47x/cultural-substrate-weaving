# 発動判定の詳細

発動範囲、暗黙発動、明示指定、途中終了の判断が必要な場合に読む。

## 0. 発動を判定する

発動は、**領域固有の手法に対して有意な増分が見込めるか**で決める。暗黙発動では、無関係な作業へ割り込まないため適合率を優先する。

判断が拮抗する場合は、割り込みの代償が小さい範囲で**限定適用して測る**。試していない手を「増分なし」とみなさない。

発動範囲は三段階とする。

1. **非発動**：領域固有の手法で目的を達成する。
2. **限定適用**：単一対象の一貫性、時間構造、接続欠落、不可逆性、特定の文化体系による比較など、必要な検査だけを使う。
3. **全体適用**：文化的体系による構造探索とKJ法による材料統合を組み合わせ、対象側で検証する。

対象の主要構造が既に定まり、検査する側面を分離できる場合は限定適用とする。主要構造そのものを探索する場合、異種の材料が多数ある場合、複数次元が互いの状態を変える場合は全体適用を検討する。

### 暗黙発動の必須条件

1. **問題空間が開いている**：正解や候補を事前に列挙し尽くせず、到達点を定めること自体が作業の一部である。
2. **構造・関係・状態・遷移の探索または検証が中心である。**
3. **複数の次元が相互作用する。**
4. **対象側で検証できる。**
5. **通常分析を超える問い、関係、反証、調査課題のいずれかを生成できる可能性がある。**

第一条件が要である。閉じた問題空間では通常手法を優先する。

### 通常手法を優先する条件

- 単純な校正、言い換え、短縮、要約、翻訳
- 事実確認、検索、数値計算、形式変換
- 定型実装、依存関係更新、既知手順の実行
- 原因と影響範囲が限定された局所的な修正
- 構造候補の検証材料が不足している作業
- 緊急対応、安全確保、法的期限など、先に領域固有手順を実行すべき作業

発動は依頼文の用語ではなく条件で判定する。

### 明示指定を受けた場合

明示指定は発動判定を差し替える。安全上・権限上の境界を除き、予測だけで発動を拒まない。通常手法で足りると見える場合も限定適用して基準線との差分を測り、増分がなければそう報告する。

### 発動後の停止条件

次のいずれかに該当したら範囲を縮小または終了する。

- 新しい意味単位・関係・問いが立たなくなった。
- 出る増分が既存内容と重複する。
- 体系を変えても基準線と別の場所を指さない。
- 基準線だけで目的を達成した。
- 同種性または対象側の検証材料を確保できない。

コストによる打ち切りは人間側の判断とする。外部要因で中断した場合は、未収束であることを記録する。
