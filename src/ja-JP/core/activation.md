# 利用範囲・読み込み深度・区切りの設定

本スキルをどこまで使うか、文化体系をどこまで読むか、どこで区切るかについて、外側から与えられた条件を実行時の状態へ写すときに読む。

## 0. 決定主体と状態を分ける

本ファイルが提供するのは、利用状態を表す語彙と、その状態で使える操作である。本スキル自身が、課題の価値、優先順位、利用範囲、終了条件を独立に決めるための規則ではない。

利用条件は、依頼者・著者の明示指定、呼び出し側のコンテキスト、上位の設定・指示、またはそれらが実行AIへ明示的に委ねた裁量から受け取る。細部が委ねられている場合、実行AIはその委任範囲で状態を調整できる。

区別する状態は二つある。

1. **本スキルの利用範囲**：非利用／限定利用／探索利用。
2. **文化体系の読み込み深度**：`not_loaded / probe / preview / full / enacted`。

これは能力と進行状態の記述であり、どれを選ぶべきかという価値順位ではない。

## 1. 利用範囲

- **非利用**：今回の作業では本スキルの操作を使わない。
- **限定利用**：KJ、来歴、時間構造、接続欠落など、指定・委任された一部の操作を使う。
- **探索利用**：文化体系による探索とKJによる材料統合を往復し、構造・関係・状態・遷移などを広く扱う。

開いた問題、閉じた問題、校正、翻訳、計算、実装、緊急作業などの課題種別だけから、本スキルが利用可否を決める規則は置かない。課題種別は、依頼者または実行AIが委任範囲で利用方法を考えるための情報にはできる。

本スキルが明示指定された場合は、その指定範囲を利用条件として受け取る。指定が「CSWを使う」のように広く、細部が委ねられている場合は、実行AIが課題に応じて利用範囲と深度を調整する。

## 2. 文化体系の読み込み深度

- **`not_loaded`**：文化体系を開いていない状態。
- **`probe`**：周期、経路、境界、中心／周辺、複数時間尺度、流れ、連続体、反復とずれなどから、別の認知場を開く入口を探っている状態。
- **`preview`**：候補体系の主要な認知構造、位置関係、時間構造、限界へ軽く触れている状態。
- **`full`**：原典、系譜、象徴、複合構造まで読んでいる状態。
- **`enacted`**：体系固有の操作を対象との関係で実行している状態。

`probe`から始める、候補想起アンカーから異なる構造型をpreviewする、特定体系を直接previewする、fullやenactedへ進む、といった経路はいずれも利用可能である。どの経路を採るかは外部利用条件と委任範囲に従う。

探索の際は、`methods/system-selection.md`にある状態格子・時間・経路・方向・流れなどの候補想起アンカーを利用できる。体系起点で生じた問い、対比、調査先、KJへ戻す材料候補は、来歴を失わないよう`framework_generated`等の状態で保持する。

## 3. 観察シグナル

進行中には、次のような状態を観察して記録できる。

- 新しい意味単位・関係・問いが立っているか。
- 増分が既存内容と重複しているか。
- 体系語彙だけが増えているか。
- 対象の事実、境界、不可逆性、証拠状態にどのような変化があるか。
- 基準線との差分がどこにあるか。
- 帰属を主張するための対象側材料がどの程度あるか。
- 現在の成果物、判断、調査方針、残差、再開条件が何か。

これらは、縮小・継続・深掘り・終了を自動的に命令する停止規則ではない。外部利用条件が判断を依頼者へ留保しているなら判断材料として返し、実行AIへ委ねているならその委任範囲で使う。

## 4. 区切りと再開

個々の文化体系の利用を止めること、本スキルの利用範囲を変えること、依頼された課題そのものを終えることを区別する。

ラウンドを区切る場合は、その時点の成果、未解決残差、再開条件を保持する。後から新資料が残差へ触れた場合は、以前の状態から再開できる。

資源制約、期限、公開可否、採否などの価値判断は、外部利用条件に従う。本スキル内の静的規則が、それらを独立に追加しない。
