# 発見を具体化する

文化体系との接触から、現在の理解では出にくい問い・区別・関係・構成を得て、対象の言葉で使える形へ変える。

体系の規則は、「この体系の見方を仮に採るなら」と仮定して大胆に走らせる。生成段階で結論の証明を求めない。生成した候補の由来と、対象側で何が言えるかを分けて扱う。

## 体系固有の操作を使う

体系の全体像を必要な範囲で保ったうえで、今回の問いに働く操作を選ぶ。以下は操作を探すための入口であり、全項目を埋める手順ではない。体系にない操作を加えた場合は、分析者の構成と明示する。

| 体系の資源 | 操作 | 対象へ持ち帰るもの |
|---|---|---|
| 分節・位置 | 同じ対象を別の位置から読み、同じに見えるものを分ける | 区別、比較軸、別の説明 |
| 空位 | 閉集合に空きがある場合、まだ問っていないことへ変える | 質問、追加資料の候補 |
| 対立・補位置 | 現在の読みの反対側や補う側から読む | 隠れていた条件、反対の読み |
| 関係網 | 隣接、生成、抑制、経路などを辿る | 関係候補、中間点、接続への問い |
| 遷移・周期 | 前後、戻り、位相、可逆性を仮に動かす | 変化の条件、別経路、構成順序 |
| 境界・尺度 | 内外、中心と周辺、層、時間尺度を変える | 比較単位の見直し、境界の問い |
| 実践知 | 状態ごとの注意や行為を対象の場面へ読み替える | 注意先、質問、具体案 |

最初のきれいな対応だけで探索を閉じる必要はない。別の操作へ回るときは、何を新たに見ようとしているかを示す。操作数、体系数、読書量を成果とみなさない。

## 接触から生じた差を受け取る

対象と体系の一致に加え、不一致、抵抗、逆転、過剰、相互修正を見る。候補に合わない材料を弱めず、対応そのものを分ける、修正する、保留する。

別の視点で再分節する場合は`methods/perspective-analysis.md`に従う。接触から新しい区別や関係が生じた場合は`methods/transformation.md`の第三構造として扱える。第三構造が生じなかったときは、不一致や未接続をそのまま残す。

## 対象の言葉へ戻す

候補を、体系名や象徴語を知らない人にも使える問い・比較・構成として言い直す。体系語を外すと意味がなくなる候補も、文化固有の構成資源として由来を保てる。

たとえば「補位置が空いている」という着想を得たなら、「誰の立場がまだ記録されていないか」と問える形へ変える。ただし、空位だけから記録不足を事実認定しない。

対象への返却には、既存資料との照合、具体例と例外の読解、専門知識にもとづく判断、依頼者との検討を使える。新しい実証実験や数値評価を一律に要求しない。根拠がまだない事実候補は仮説として残し、そのまま構成案へ使う場合も用途を明示する。

## 成果物に反映する

依頼に応じて、候補を次の出口へ具体化する。

| 出口 | 示す内容 |
|---|---|
| 問い・比較 | 何をどう比べると、今の見方と別の見方を区別できるか |
| 読解・説明 | どの関係や条件が見え直り、何がまだ説明できないか |
| 設計・構成 | 何をどう組み替えるか、保持するもの、選んだ理由 |
| 推奨・判断 | 委ねられた目的と基準に照らして選ぶ案、判断根拠、残る論点 |
| 調査・観察・試行 | 追加の材料が必要なとき、どこから何を得るか |

調査や試行は出口の一つである。依頼が設計や構成を求めており、既存資料と定性的判断で選べるなら、具体案まで進める。領域固有の実行判断や品質基準は、呼び出し側から受け取る。

## 必要な来歴だけを運ぶ

候補の採否に影響する部分について、由来、使った仮定、対象資料の支持や反例、判断者を残す。短い文章でもよく、全候補に同じ記録欄を設ける必要はない。

```text
候補と、対象の言葉での使い道:
体系・部分・操作、または接触からの由来:
今回置いた仮定:
対象側の材料が支える部分と、未判断の部分:
採否または推奨の理由と判断者:
```

候補を親和図法へ渡す場合は`methods/integration.md`、後から届いた材料で再開する場合は`core/iteration.md`の接続契約を使う。親和統合したこと、採用したこと、仮定を文章から外せたことだけで、対象側の支持を付けない。

照明とは、由来・仮定・全体・対象・具体の観点から読み直すことである。合否の関門や必須の記入工程にはしない。対象資料の事実、体系由来の着想、判断として選んだ案を、読み手が区別できる状態にする。
