# Adopted cultural-framework portfolio

This file indexes frameworks that CSW carries internally. Adopted does not mean accepted as true or suitable for automatic classification. It means the framework has enough source-grounded structure to be reused as a cognitive catalyst without reconstructing it from model memory each time.

## Loading rule

1. Select by the cognitive operation missing from the current target view.
2. Open the dossier before mapping the target; preserve native positions, relations, transitions, practice, and variant boundaries.
3. Mark CSW-added operations as analytic additions rather than native framework structure.
4. Use web research for lineage-specific details or gaps, not to rediscover adopted frameworks from scratch.
5. Frameworks outside the library remain valid candidates, but model memory alone does not promote them into the corpus.

### Keep near neighbors distinct

- Yijing, Wuxing, and Maya calendars all address change, but primarily through configuration change, relational cycles, and coupled temporal scales respectively.
- Catuṣkoṭi, Jain predication, Nyāya, stasis theory, and four causes alter reasoning in different places: proposition space, assertion conditions, inferential bridge, dispute state, and explanation type.
- Huayan and Confucian role/li both foreground relations; Huayan works through whole–part reciprocity while role/li focuses on enacted roles, relations, and patterned conduct.
- Hadith isnād/matn separates provenance from content and never turns documented transmission into proof of the proposition.
- Marshallese wave navigation contributes model/environment return and cue-sequence wayfinding rather than generic network representation.

Do not try to explain the whole target with one framework. Open a second framework only when the first pass reveals a different missing cognitive operation.
