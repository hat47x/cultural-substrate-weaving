# CSW — 執筆のための3つのスキル

文化的体系、親和図法、思考の流れを組み合わせ、著者が作品を書き、読み直し、深めるための日本語テキストです。まずは執筆の中で、著者にとって役立つ成果を得ることを目指します。

## 本Workで使う

スキルとして登録する必要はありません。次の本文をAIに読ませ、原稿やメモと、今回進めたいことを渡してください。GitHub上のファイルを読ませる、手元のファイルを指定する、内容を会話に貼る、のいずれでも使えます。

| 本文 | 担当すること |
|---|---|
| [文化的体系](skills/cultural-substrate-weaving/SKILL.md) | 体系固有の区別・関係・変化を借り、作品の見方や表現の候補を生む |
| [親和図法（KJ法に学ぶ）](skills/affinity-synthesis/SKILL.md) | 原稿・メモ・観察からまとまりと関係を立ち上げ、元材料へ戻して確かめる |
| [思考・執筆フロー](skills/writing-flow/SKILL.md) | 今の課題に応じて方法を使い分け、構想・執筆・推敲・振り返りを進める |

たとえば、次のように依頼できます。

> このリポジトリの3つのSKILL.mdを読み、それに従って執筆を手伝ってください。まず添付の原稿とメモを読み、今回進めたいことに合わせて、必要な方法だけ使ってください。分析で終わらず、本文にどう反映するかまで進めてください。

文化体系を詳しく使うときだけ、[文化体系の手掛かり](skills/cultural-substrate-weaving/references/cultural-systems.md)の該当部分も読みます。全体系を一括で読み込む必要はありません。本文を貼って使う場合は、必要な参考部分も一緒に渡してください。

3つは当面分けて育てます。単独でも、組み合わせても使えます。分けることで読む量が減るか、切り替えが負担にならないかを執筆の中で確かめ、まとめるかどうかを改めて考えます。

## 執筆から学ぶ

原稿や私的な記録は、リポジトリの公開対象から外した `work/` などへ置きます。振り返りは短いメモで十分です。

- どの原稿・場面で、何を進めたかったか。
- どの方法を、どの順序で使い、具体的な文・構成・理解がどう変わったか。
- 著者が役立つと感じた点、違和感、採らなかった案、まだ判断できない点。
- 次に試したい使い方や、本文から減らせそうな指示。

AIの解釈と著者自身の評価を分けます。過去の判断を消さず、後から変わった判断を追記します。公開用に知見を戻すときは、原稿や個人情報を持ち込まず、必要な手つきだけをスキル本文へ反映します。実験、採点、数値指標、所定の記録票は利用の条件にしません。

現段階の本文は執筆で使いながら見直す案です。構成を簡単にしたこと自体を、執筆への効果が確認できたこととは扱いません。

## 必要ならZIPにする

利用にリリースは不要です。配るときだけ、`README.md`、`LICENSE`、`skills/` を選んでZIPにしてください。中身はUTF-8のテキストだけです。実行プログラムや追加ライブラリは要りません。

Gitを使う場合は、保存済みの内容から次の一行でも作れます。

```sh
git archive --format=zip --prefix=csw/ -o csw-writing-texts.zip HEAD README.md LICENSE skills/
```

バージョンファイル、生成物、翻訳同期、リリース用ブランチ、タグの作成、自動配布は必要ありません。Gitのコミットで、どの時点のテキストかを辿れます。

## 構成を簡単にした理由

0.2.0から0.5.0にかけて増えた配布・検証・翻訳・研究用の仕組みを外し、本文をそのまま使う構成に整理しました。英語版、CI/CD、ビルド、各環境向けプラグイン、専用の検証ツールや研究パッケージは現行ツリーから取り除いています。旧版と過去の記録はGit履歴に残っています。

文化的体系の生成力、材料主導の統合、差分からの再検討は残し、執筆に必要な手つきとして書き直しました。過去の実験結果を、この新しい本文の有効性の証拠として引き継いではいません。
