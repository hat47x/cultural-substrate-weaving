# 認知姿勢の固定読込回数を監査する

作成日: 2026-09-05

## 1. 対象

`core/cognitive-stance.md` と `ROUTER.md` にある、認知姿勢を「ラウンドの最初に一度読む」「同じラウンドで機械的に繰り返し読み込まない」という固定読込回数を監査する。

監査対象は認知姿勢そのものではない。対象から自分の読みを修正され得る位置へ置くこと、材料へ触れてから強く考えること、仮説と元材料の来歴を分けること、委ねられた判断を過度の自制で返さなくしないことは、本スキルの横断的な認知能力として維持する。

## 2. 導入履歴

### PR #84 の研究

`7fcbc13…` で統合された研究「『己を空しくする』を生成AIの認知姿勢として設計する」は、認知姿勢を静的な上位原理として整理した。

同研究は冒頭で、**「ここでは、プロンプト文言の効果測定は行わない」**と明記している。研究の主眼は、知識・仮説を抑えることではなく、生成した説明を対象によって修正され得る位置に置くことだった。

したがって、この研究は認知姿勢の内容を支えるが、「一ラウンドに一回」という読込回数の有効性を測定したものではない。

同コミットに、一回読込と複数回読込、必要時再読、未読などを比較した記録はない。

### `88265fe…`

`feat: route through the cognitive stance` で Router へ次が追加された。

- 本スキルを使うと決めたら `core/cognitive-stance.md` を最初に一度読む。

ここでは、固定一回と必要時再訪が同時に置かれている。後者は認知姿勢を再び必要とする状態を認めているが、前者の「一度」という回数自体の比較根拠は示されていない。

### `7b856d2…`

変更記録は「Router now loads this stance once when CSW is actually used」と、一回読込を採用した設計として記述した。これは導入済み仕様の記録であり、回数効果の測定ではない。

### 後続変更

`687743c…` は対象の美化と敬意を分けるなど認知姿勢本文を精緻化したが、固定回数は検証せず維持した。英訳・manifest・plugin生成の後続コミットにも、読込回数を比較した実測は確認できない。

## 3. 機能と回数を分ける

認知姿勢には、少なくとも次の機能がある。

- 既存説明を対象より上位へ固定しない。
- 生成能力を弱めず、対象から修正を受けられる状態にする。
- 元材料、推論、文化体系由来、接触から生じた意味の来歴を混同しない。
- 不確定性を保持しつつ、委ねられた判断を責任回避で保留しない。
- 長い作業で既存説明や規則が対象より前へ出たとき、読みの向きを対象へ戻す。

これらは「ちょうど一回読む」こととは別である。

一回で十分な短い作業もあり得る。長い作業や、別資料・別文化体系・再開後の材料によって認知場が大きく変わる作業では、必要箇所へ戻る方が機能に忠実な場合もある。逆に、実行環境が既に同じ姿勢を十分保持しているなら、固定回数を満たすための再読自体に意味がない場合もある。

## 4. 決定権境界との関係

PR #193 以降、本スキルは利用範囲、読み込み深度、停止、採否、公開等を静的規則が独立に決めない方向へ再基準化されている。

認知姿勢モジュールの利用は、本スキル固有能力を成立させるための読込であり、単なる価値判断ではない。しかし、その能力を保つために必要なのは**必要な場面で姿勢へアクセスできること**であって、未検証の固定回数を成功条件にすることではない。

固定一回を外しても、認知姿勢の内容、初期接触時の重要性、長期作業で必要箇所へ戻る能力は保持できる。

## 5. runtime 改定方針

次の最小変更が妥当である。

1. `core/cognitive-stance.md` の「ラウンドの最初に一度読む」を、CSW利用時または既存説明・規則が対象より前へ出ているときに読む、という必要性ベースの案内へ置き換える。
2. Router の「最初に一度」を、認知姿勢を置くために読む、という機能記述へ戻す。
3. 「同じラウンドで機械的に繰り返し読み込まない」という固定反復禁止は削除する。
4. 長い作業で既存説明や規則が前へ出ている兆候があれば必要箇所へ戻る、という既存の再訪契機は維持する。
5. 新しい固定回数、時間間隔、成功条件を追加しない。

## 6. 維持する境界

この監査は、次を弱めるものではない。

- 「己を空しくしてデータをして語らしめる」というKJ由来の認知姿勢。
- 対象と文化体系への二重の忠実性。
- 仮説を恐れず、元材料の事実へ逆輸入しないこと。
- 対象へ戻して読みを修正すること。
- 後から来る材料へ読みを開いておくこと。
- 委ねられた範囲では必要な判断を返すこと。

変更対象は、これらの機能を「一ラウンドに一回」という未検証の回数へ結び付けている部分だけである。
