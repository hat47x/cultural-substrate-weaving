# 作業窓の固定前景化リスト監査

日付: 2026-09-05
対象:
- `src/ja-JP/core/iteration.md`
- `src/ja-JP/governance/governance-and-records.md`
- 対応する en-US

## 対象規則

現在、iteration には次の既定がある。

> 長期履歴を毎回すべて読み直す必要はない。現在のラウンドでは原則として、新材料、今回触れた古い残差、必要なKJ時点記録、必要なprobe／previewだけを前景化する。

governance には、より強く次のように書かれている。

> 文脈を軽くするために、古い材料を削除することを既定の方法にしない。現在のラウンドでは、新材料、今回触れた古い残差、必要なKJ時点記録、必要なprobe／previewだけを前景化する。

「古い材料を削除せず、作業窓だけを選択的にする」という原則と、「前景化対象はこの4種類だけ」という閉じたリストは分けて監査する必要がある。

## 導入履歴

### 2026-08-30 v40統合

`3dc8777491977dd58ab506249a30306769011fbc` が、保存層と現在注意を分ける設計を導入した。

同じコミットで、Routerには

> 保存 ≠ 現在の注意：正本は厚く残し、今回必要な部分だけ前景化する。

という原則が入り、iteration と governance には

- 新材料
- 触れた古い残差
- 必要なKJ時点記録
- 必要な probe / preview

という4種類の作業窓が入った。

このコミットは v40 の production semantics を統合する大きな設計変更であり、この4種類を閉じた集合とする比較実験や外部典拠は示していない。

### 2026-09-01 遅延周回

`4771053cf8bbddbbf43c120a9ec06198345394b9` は、後から届く新資料による再開を正式化し、未解決の問い、孤立した意味単位、保留関係を結論とともに持ち越すことを追加した。

この変更は、前回のまとまりを正解として固定せず、後から届いた材料と残差を同じ材料面へ戻すことを強めている。一方、前景化対象を上記4種類だけに限定すべきことは測定していない。

### 2026-09-05 決定権再基準化との照合

PR #193以降、`core/principles-and-constraints.md` は次を明示している。

- 保存する層と現在前景化する層を分ける。
- 「保存は厚く、現在の注意は選択的にする」。
- 削除、圧縮、分割、遅延読み込み、参照化のどれを採るかは外部利用条件と委任範囲に従う。

したがって、選択的前景化そのものはCSWの認知・記録能力として保持できるが、前景化対象を静的規則で4種類へ閉じることは、現在の決定権境界より強い。

## 保持すべき能力

1. 長期履歴を毎ラウンド全件再読することを必須にしない。
2. 古い材料を削除することを文脈軽量化の既定手段にしない。
3. 正本・残差・KJ時点記録・体系資料を厚く保存できる。
4. 現在の注意だけを選択的にする。
5. 新材料、触れた残差、KJ時点記録、probe / preview を有力な前景化候補として残す。

## 外すべき固定化

- 上記4種類だけを前景化対象の閉じた集合とすること。
- それ以外の材料を、現在の作業に必要でも静的規則だけで背景へ追いやること。

例えば、現在の作業で一次資料本文、以前の反例、採否履歴、特定の文化体系の full 資料、過去の成果物差分が直接必要なら、それを前景化しない理由はない。

## runtime改定案

iteration JA:

> 長期履歴を毎回すべて読み直す必要はない。新材料、触れた残差、KJ時点記録、probe／previewは前景化の例であり、必要な範囲は現在の作業に応じて選ぶ。

iteration EN:

> Do not reread the whole history every round. Use new material, touched residuals, KJ snapshots, probes, and previews as foregrounding examples, not a closed list.

governance JA:

> 文脈を軽くするために古い材料を既定で削除しない。新材料、触れた残差、KJ時点記録、probe／previewは前景化の例であり、必要な範囲は現在の作業に応じて選ぶ。

governance EN:

> Do not delete old material by default to lighten context. Foreground what current work requires; new material, touched residuals, KJ snapshots, probes, and previews are examples.

これにより、作業窓を選択的にする能力と代表的候補は残しつつ、閉じたリストだけを外せる。

## 非目標

- 毎回すべての履歴を読むこと。
- 長期保存を弱めること。
- 残差・KJ時点記録・probe / preview の価値を下げること。
- 文脈量を無制限に増やすこと。
- 新しい固定件数、固定順序、固定停止条件を追加すること。
