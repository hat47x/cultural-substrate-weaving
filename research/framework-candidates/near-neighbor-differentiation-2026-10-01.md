# Near-neighbor framework differentiation — 2026-10-01

Status: research planning / anti-duplication guide / not automatic routing

## 目的

文化体系候補が増えるほど、異なる名前で似た問いを繰り返すだけの「見かけ上の多様性」が増える危険がある。

この文書は、operationが近く見える体系どうしについて、

- 何を動かす体系なのか;
- どこが本質的に異なるのか;
- どの種類の問いを開きたいときに候補になり得るか;
- 何を理由に自動選択してはいけないか;

を整理する。

これはrankingでもrouting tableでもない。対象や利用目的からframeworkを自動決定する規則にしない。

## 1. dependent origination / Huayan

### dependent origination

中心は **成立条件と停止条件** である。

- 何があるとこの現象が生じるか;
- 何を外すと成立しなくなるか;
- 観測された結果から上流条件へ戻れるか.

強いoperation:
condition-chain / upstream-condition / cessation-counterfactual.

### Huayan

中心は **wholeとpartが互いのidentityやroleをどう規定するか** である。

- このpartは別のwholeでも同じpartか;
- nodeを変えると全体像はどう変わるか;
- integrationで消してはいけないdifferenceは何か.

強いoperation:
whole-part-reciprocity / perspective-through-node / context-role-reidentification.

### 差分

dependent originationは「成立に必要な条件」を追う方向が強い。
Huayanは「関係の中でpart/wholeのidentityがどう成立するか」を動かす。

同じ「相互依存」という語で統合しない。

## 2. catuṣkoṭi / Jain sevenfold predication

### catuṣkoṭi

中心は **二値predicateそのものを揺らすこと**。

- P;
- not-P;
- both;
- neither;

を開き、predicateが不適切ではないか、time / layer / actorが混ざっていないかを見る。

### Jain sevenfold predication

中心は **assertionをstandpoint / conditionへ結び直すこと**。

- どの条件では成り立つか;
- opposite claimは別のstandpointでは成立するか;
- 現在の語彙では言い切れないresidualは何か.

### 差分

catuṣkoṭiはframe破壊 / predicate auditが強い。
Jain sevenfold predicationはqualified assertion / perspective-bindingが強い。

「多値だから同じ」と扱わない。

## 3. Aristotle four causes / Nyāya five-member inference / classical stasis theory

三者ともargumentを精密化できるが、動かす場所が異なる。

| framework | 主に動かす場所 | 典型的な問い |
|---|---|---|
| Aristotle four causes | explanationの種類 | なぜ、をmaterial / form / mechanism / purposeへ分けると何が欠けているか |
| Nyāya five-member inference | inferenceの橋 | thesisからreason、general relation、case application、conclusionへの橋は成立しているか |
| classical stasis theory | disputeの争点位置 | 今争っているのはfact / definition / evaluation / procedureのどれか |

### 選び分けの目印

- 一つの「なぜ」に異なる説明タイプが混ざる → Aristotle.
- 理由から結論への橋が暗黙 → Nyāya.
- 議論双方が別の問いに答えている → stasis.

複数を使う場合も、同じカードに三体系を重ねず、explanation / inference / dispute-stateを別々に外在化する。

## 4. Buddhist mandala / Tibetan Buddhist mandala / rites of passage / Shinto threshold-purification

四者ともboundaryやtransitionを開けるが、構造単位が違う。

### Buddhist mandala

中心:
center / direction / nested enclosure / gate.

主な仕事:
空間構造とaccess構造を見直す。

### Tibetan Buddhist mandala

一般mandala候補のsubtypeとして、lineage-specificなouter-to-center traversalやgated accessを深めるための研究候補。

一般mandalaとの差がlineage資料で十分に説明できなければ統合を検討する。

### rites of passage

中心:
separation → liminal transition → incorporation.

主な仕事:
旧状態を離れたことと、新状態に組み込まれたことを分ける。途中状態を保持する。

### Shinto threshold / purification

中心:
marked threshold → approach → preparation/purification → central act → return.

主な仕事:
具体的な境界、事前準備、参加状態の変化を問う。

### 差分

- spatial organizationを見たい → mandala.
- status transitionの未完了を見たい → rites of passage.
- entry protocol / preparationを見たい → Shinto threshold.

「境界」という一語で統合しない。

## 5. Maya calendar systems / Heavenly Stems and Earthly Branches

両方ともcoupled cycleを扱うため、とくに重複監視が必要。

### Maya calendar systems

現在のadopted dossierは、

- Tzolk’in / Chol Q’ij;
- Haab;
- Calendar Round;
- Long Count;

を通して、partial/full recurrenceとmulti-scale time、cycleとlong countの区別まで開く。

### Heavenly Stems / Earthly Branches

10-stemと12-branchの同期pairingによる60-position recurrenceが中心。

強みは、

- coordinate-pair;
- phase-offset;
- 10と12のpartial recurrence;
- joint recurrence.

### 差分

Stems/Branchesがruntimeへ進むには、Maya calendarでは生じにくい独自operationが残る必要がある。

単に「異なる長さの周期を組み合わせる」だけなら、Maya dossierとの重複が大きい。

## 6. Hadith isnād / matn vs generic provenance

CSWにはもともとsource provenanceを保持する規律がある。

Hadith候補が独自であるためには、単に「出典を書く」以上が必要。

独自候補operation:

- contentとtransmission pathを別objectとして持つ;
- multiple chainsのbranch / convergenceを見る;
- chain variationとmatn variationを別々に比較する;
- provenance evidenceとcontent evidenceを非等価として扱う.

これらが実課題でgeneric provenanceより新しい問いを生まないなら、独立frameworkとして採用せず、provenance toolkitへの学習として戻す。

## 7. Mīmāṃsā hermeneutics vs generic close reading

Mīmāṃsā候補の価値は「丁寧に読む」ことではない。

独自候補operation:

- prescriptive unitをどこで切るか;
- purpose unity;
- syntactic expectancy;
- semantic fitness;
- proximity;
- explicit vs context-supplied meaning;
- norm-conflict decomposition.

単なる文脈読解、要約、法務的な一般解釈へ薄まるなら独立frameworkとして残さない。

Bhāṭṭa / Prābhākara等のschool differenceを保てない場合も採用を止める。

## 8. Yijing / Llull Ars

両者ともcombinationを扱うが、目的が違う。

### Yijing

有限のconfigurationとchangeによって、

- state recomposition;
- local change;
- paired / transformed configuration;

を見る。

### Llull Ars

symbolic principlesをsystematically crossし、

- 普段結びつかないdimensionの組合せ;
- bounded combinatorial search;
- unseen combination probe;

を作る。

### 差分

Yijingはstate / transition側。
Llullはsearch-space enumeration / crossing側。

「組合せがある」という表面的共通性で束ねない。

## 9. Confucian role / li / rites of passage / Shinto threshold

ritualという語が共通していても、operationは異なる。

- Confucian role/li: relation-conditioned conduct / role / repeated practice.
- rites of passage: status crossing and liminal state.
- Shinto threshold: entry, preparation, central act, return.

ritualというタグだけで自動routingしない。

## 候補を残すための最低差分

近接候補を独立に残す場合、少なくとも次のいずれかを説明できること。

1. 別のstructural primitiveを持つ。
2. 同じ材料から異なるquestionを生成する。
3. 別のtransition / relationを走らせる。
4. 別のresidualやcounter-viewを残す。
5. de-binding後にも、他候補では置換しにくい認知操作が残る。

説明できなければ、

- research candidateを統合する;
- 一方をhistorical/reference layerへ下げる;
- frameworkではなくtoolkitへの学習として吸収する;

ことを検討する。
