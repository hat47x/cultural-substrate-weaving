# Hadith isnād / matn vs Vedic recitation pathas

Status: runtime requalification / near-neighbor differentiation

## Purpose

Both candidates concern transmission, but they protect different target properties.

This comparison prevents a generic "transmission framework" category from erasing their distinct cognitive jobs.

## Hadith isnād / matn

Primary object:

- substantive content;
- attributed transmission path;
- multiple chains;
- content variants;
- provenance/content non-equivalence.

Primary questions:

- Where did this report come from?
- Are apparently separate paths actually independent?
- Which handoff is asserted, observed, or reconstructed?
- Which wording variants align with which path?
- Does provenance evidence support the content proposition, or only its transmission history?

## Vedic recitation pathas

Primary object:

- an authoritative ordered sequence;
- segmentation;
- adjacency;
- alternate explicit sequence views;
- fidelity across transmission / transformation.

Primary questions:

- Did order survive?
- Did unit boundaries survive?
- Did a transformation skip, duplicate, merge, or reorder units?
- Do alternate sequence views agree?
- Is a checksum or diff the better ordinary tool?

## Same abstract target

Suppose a five-step runbook is repeatedly copied and edited.

### Hadith-inspired pass

Focuses on:

- which copy came from which;
- which copies share a common origin;
- who attributes a step to which source;
- how content variants distribute across branches;
- whether repeated citation is being mistaken for independent evidence.

### Recitation-path pass

Focuses on:

- whether the five-step order survived;
- whether boundaries between steps survived;
- which adjacency changed;
- whether alternate sequence views reveal an omission or reordering.

## Non-substitutability

A provenance graph can be complete while the sequence has been corrupted.

A sequence can be perfectly preserved while the claimed source path is false or unknown.

Therefore:

- hadith = provenance/content separation and lineage topology;
- Vedic recitation pathas = sequence/boundary fidelity across alternate views.

## Runtime implication

Near-neighbor distinctness is real.

But it does not by itself justify hadith runtime retention. Hadith must still add discovery value beyond ordinary provenance tools and CSW's always-on provenance/evidence rules.
