# Mīmāṃsā sentence-meaning boundary

Status: profile-readiness note

Mīmāṃsā内部でも、文の意味がどう成立するかについて一枚岩の説明はない。

- Prābhākara系では、語は文脈の中で相互に結びついた意味を伝えるという立場が中心になる。
- Bhāṭṭa系では、各語がまず独立した意味を伝え、その後に文としての関係が成立するという立場が中心になる。

この差は、CSWが「文脈を足せば意味が完成する」という一つの規則をMīmāṃsā全体へ帰属することを防ぐ。

runtime候補として共通に使えるのは、立場の決着ではなく、少なくとも次を分けて検査する操作である。

- syntactic expectancy;
- semantic fitness;
- cognitive proximity / contiguity;
- explicitly stated vs context-supplied material;
- whether two prescriptions truly concern the same agent, act, condition, time, and purpose.

この共通部分を超える解釈規則は、Bhāṭṭa / Prābhākaraの系譜を明示して追加する。
