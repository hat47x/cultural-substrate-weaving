# Mīmāṃsā / stasis / Nyāya operation boundary

Status: runtime adoption boundary

These three adopted or candidate systems can all improve reasoning over text, but they intervene at different points.

## Mīmāṃsā

Primary question: how do words, clauses, purposes, exceptions, and contextual supplementation form one or more prescriptive units?

Strong use: scope of a rule, unity of a prescription, explicit versus supplied meaning, and apparent norm conflict.

## Classical stasis theory

Primary question: what kind of issue is actually disputed?

Strong use: separating fact, definition, evaluation, and procedure/competence.

## Nyāya five-member inference

Primary question: how does a reason support a conclusion?

Strong use: separating thesis, reason, corroborating example, application, and conclusion.

## Runtime rule

Do not substitute one for another because all three are “argument analysis.”

- If the problem is the scope or connection of prescriptions, open Mīmāṃsā.
- If the problem is that parties answer different kinds of questions, open stasis theory.
- If the problem is an unsupported inferential jump, open Nyāya.

A second framework is opened only if the first pass reveals a different missing cognitive operation.
