# Wuxing vs ordinary signed causal-loop analysis

Status: runtime requalification / same-target ordinary-baseline comparison

## Purpose

Wuxing is currently a default runtime framework. Its CSW runtime use foregrounds two relation cycles: generation / support and overcoming / restraint.

This comparison asks:

> after de-binding, does Wuxing add a target-relevant cognitive operation that ordinary signed causal-loop / system-dynamics analysis does not already provide?

The target is the same oscillating distributed-worker autoscaler used in the positive fixture.

## Condition A — Wuxing-derived pass

The de-bound pass asks the target to distinguish:

1. enabling / amplifying relations;
2. constraining / counteracting relations;
3. closed relation cycles;
4. relation roles that change by edge or context;
5. missing or broken relations;
6. temporal changes in the relation pattern.

It does not force Wood / Fire / Earth / Metal / Water assignments onto the target.

## Condition B — strong ordinary causal-loop baseline

Use no cultural framework.

Represent the target as a directed influence graph. Each edge records:

- source variable;
- target variable;
- direction;
- polarity or typed effect where known;
- evidence / confidence;
- operating state or time window.

Then inspect:

- reinforcing feedback loops;
- balancing feedback loops;
- delayed relations;
- links whose polarity or effect changes by operating state;
- missing or weak balancing links;
- intervention points and observations.

For the autoscaler target this exposes:

- retry / timeout / saturation reinforcement;
- admission-throttle balancing;
- scale-out's opposite effects on queue depth and backend load;
- delayed balancing that can produce overshoot;
- relation changes across spike and recovery.

## Operation-by-operation comparison

| De-bound operation | Wuxing-derived pass | Ordinary causal-loop baseline | Residual target-side difference |
|---|---|---|---|
| enabling / supporting relation | generating/support path | directed enabling / amplifying influence | none for tested target |
| constraining relation | overcoming/restraint path | balancing / constraining influence | none for tested target |
| cycle inspection | generation / overcoming cycles | reinforcing / balancing feedback loops | none for tested target |
| relation-role reversal | one phase supports / is supported / constrains / is constrained | one variable can have different incoming/outgoing typed edges | none |
| dynamic balance | inspect cyclical relation pattern and bias | inspect feedback dominance, delay, and balancing strength | ordinary baseline is at least as direct |
| missing-link probe | broken generation/restraint relation | missing or unsupported edge / missing balancing path | none |
| phase-shift probe | relation changes through transformation | compare time-indexed graph states / loop dominance | none |
| five-phase historical topology | culturally distinctive fixed relation structure | absent | historical/comparative residue, not a new target-side question |

## Important non-equivalence

This comparison does **not** claim:

- `sheng` is literally a positive causal edge;
- `ke` is literally a negative causal edge;
- reinforcing / balancing loops are historically derived from Wuxing;
- modern system dynamics and Wuxing express one ontology.

The claim is narrower:

> for the tested SIer systems-analysis target, after removing culturally specific labels and unsupported phase assignments, the remaining target-side questions are already generated by ordinary causal-loop analysis.

## Result

The ordinary-baseline counter-hypothesis survives.

Both passes ask which relations amplify, constrain, loop, change role, break, or shift over time. The ordinary baseline can also represent delay, evidence, and operating-state dependence without a mandatory five-node topology.

No additional target-side question remains that requires Wuxing contact for this use.

## Runtime consequence

The current evidence does not support keeping Wuxing as a general default runtime framework for SIer feedback / dependency analysis.

Preserve its research profile, source basis, target-return fixture, non-activation fixture, selection cues, and explicit Wuxing / Chinese-intellectual-history / comparative-systems use.

## Product-value consequence

The typology already notes that the prior Wuxing task set failed calibration. Requalification shows a more fundamental product issue: the tested de-bound runtime operations are supplied directly by ordinary causal-loop analysis.

Keeping Wuxing in default runtime under that condition adds framework-selection complexity and cultural-label overhead without increasing tested target-side cognitive capability.
