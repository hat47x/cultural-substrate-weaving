# Comparison — Marshallese wave navigation vs Vaeakau–Taumako navigational toolkit

Status: research-only / near-neighbor differentiation / public-source boundary

## Purpose

This note tests whether `marshallese-wave-navigation` contributes a distinct operation or merely duplicates generic route planning / Pacific navigation vocabulary.

The comparison target is the Vaeakau–Taumako wind compass and broader navigational toolkit as described in public ethnographic scholarship.

This is **not** a claim that either tradition can be reduced to the other.

## Source basis

### Vaeakau–Taumako

Cathleen Conboy Pyrek and Richard Feinberg, *The Vaeakau-Taumako Wind Compass as Part of a “Navigational Toolkit”*

https://escholarship.org/uc/item/1114c5xp

The article presents the wind compass as a cognitive construct that divides the horizon into named directional points and places it within a broader toolkit that includes wind, stars, waves, birds, and other wayfinding techniques.

### Marshallese comparison source

Joseph H. Genz, *Resolving Ambivalence in Marshallese Navigation*

https://escholarship.org/uc/item/43h1d0d7

Used here only to compare publicly documented operation structure: wave models, navigator-school variation, and the relation between abstract models and practical engagement.

## Shared family

Both traditions support a broad family that can be de-bound as:

- wayfinding under incomplete direct visibility;
- environmental cue use;
- learned spatial frameworks;
- practical correction during traversal;
- multiple information sources rather than one instrument.

This overlap is not enough to keep both as separate CSW candidates.

## Vaeakau–Taumako structure that is different

From the public source, the wind compass is described as an **abstract horizon framework** with discrete named directional points.

The larger navigational toolkit combines multiple cue systems:

- wind compass;
- star compass;
- waves;
- birds;
- other environmental observations.

The distinctive de-bound operation is therefore closer to:

### frame-and-toolkit switching

Choose among several orientation frameworks or cue families depending on conditions.

Questions:

- Which orientation frame is currently usable?
- What happens when one cue family becomes unavailable?
- Can two independent cue systems cross-check each other?
- Is the current error caused by the route model, or by selecting the wrong orientation frame?

### discrete directional anchoring

Use a finite directional scheme to stabilize orientation even when exact coordinates are unavailable.

Questions:

- Which coarse direction remains stable enough to act on?
- Does a discrete orientation point help before metric precision is possible?
- When should the frame itself be recalibrated?

## Marshallese structure that remains distinct

The Marshallese candidate keeps a different center of gravity:

### perturbation-mediated relative wayfinding

- islands/atolls alter surrounding wave patterns;
- the disturbance itself can become location information;
- route knowledge is not simply a finite direction frame.

### model / environment return

- instructional representation is learned before traversal;
- live sensing remains necessary during traversal;
- the model and situated evidence can disagree and must be reconciled.

### cue-sequence local update

- local route progress can be maintained by cue transitions;
- a new cue can reopen only one segment rather than requiring a global remap.

## Collapse test

If Marshallese wave navigation is reduced to:

> use several environmental cues to navigate

then it is not distinct enough from the Vaeakau–Taumako toolkit and should not remain an independent candidate.

If it retains:

1. disturbance-as-signal;
2. relative environmental structure;
3. model/environment return;
4. local cue-sequence route update;

then the candidate contributes an operation that the wind-compass/toolkit description does not replace.

Conversely, Vaeakau–Taumako adds a potentially distinct operation that the Marshallese profile does not currently emphasize:

- discrete orientation frame;
- switching / combining cue families;
- fallback among multiple navigational tools.

## CSW decision

Do **not** add Vaeakau–Taumako as another inventory candidate yet.

For now it serves as a **comparison tradition** that strengthens differentiation.

This avoids inflating the corpus with two Pacific navigation candidates before their operation-level difference is established.

## Target-side distinction

For a partially observable incident:

### Marshallese-derived pass

Ask:

- what local disturbance contains location information?
- what cue sequence lets investigation proceed without a full global map?
- where does live evidence disagree with the preparatory model?

### Vaeakau–Taumako-derived comparison pass

Ask:

- which orientation frame is currently usable?
- which independent cue family can cross-check the current direction?
- if one cue system disappears, what fallback tool remains?

These are related but not identical.

## Living-tradition boundary

- do not infer unpublished navigational knowledge;
- do not reconstruct restricted techniques from comparative similarities;
- do not flatten different Pacific traditions into one “Polynesian/Micronesian navigation method”;
- do not use the comparison for real-world navigation advice;
- keep public ethnographic description separate from community-held expertise.

## Consequence for Marshallese candidate

The comparison provisionally supports keeping `marshallese-wave-navigation` as an independent profile-ready candidate.

The remaining adoption checks are now narrower:

1. verify the operation in a second **non-navigation target domain**;
2. preserve living-tradition/public-source boundaries in a possible runtime dossier;
3. reject the candidate if real CSW use collapses it to generic graph or generic multi-cue reasoning.
