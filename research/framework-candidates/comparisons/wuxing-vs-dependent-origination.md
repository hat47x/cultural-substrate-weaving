# Wuxing vs dependent origination

Status: runtime requalification / near-neighbor differentiation

## Purpose

Wuxing and dependent origination can both move analysis away from isolated entities, but their historical structures and de-bound cognitive directions differ.

This comparison preserves that difference without treating cultural distinctness as automatic runtime value.

## Wuxing

Primary tested job:

> inspect a target through multiple directed relation modes and cycles.

Current de-bound emphasis:

- enabling / generating relation;
- constraining / overcoming relation;
- feedback cycle;
- relation role by edge;
- missing relation;
- temporal relation-pattern change.

## Dependent origination

Primary tested job:

> trace conditions under which a phenomenon arises and ask what changes when conditions cease.

De-bound emphasis:

- upstream condition;
- conditional chain;
- cessation counterfactual;
- intervention point;
- dependency reframing.

## Same systems target

On an oscillating autoscaler:

### Wuxing-derived pass

foregrounds the coexistence of:

- retry amplification;
- scale-out effects;
- backend constraint;
- admission throttling;
- feedback cycles and relation roles.

### Dependent-origination-derived pass

would more naturally begin from the observed oscillation and trace upstream conditions, then ask which condition's cessation breaks the pattern.

## Distinction

The framework-level difference is real:

- Wuxing emphasizes relation mode and cyclical interplay;
- dependent origination emphasizes conditional arising and cessation.

However, dependent origination has already been demoted from default runtime because ordinary RCA / fault-tree / dependency analysis reproduced its tested SIer operations.

Wuxing must therefore independently survive comparison with ordinary signed causal-loop analysis. Difference from dependent origination is not sufficient evidence for runtime retention.

## Decision boundary

Keep this comparison as provenance and research material.

Do not infer that Wuxing adds runtime value merely because it differs from another cultural framework.
