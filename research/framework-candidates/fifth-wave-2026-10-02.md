第4波までで、伝承 provenance、規範解釈、境界通過、空間中心／周縁などのoperation familyは候補層まで広がった。

一方、portfolio auditでは **route-oriented non-medical network** がまだ薄い。Jingluoはroute/networkの構造価値を持つが、伝統医療体系としての境界が重く、非医療のwayfinding operationを同一候補に背負わせるべきではない。

第5波では、routeを「global map上のedge」ではなく、**相対環境・局所cue・記憶モデル・situated sensingの往復**として扱える候補を追加する。

## 構造核

公開資料から安全に保持できる最小構造は次である。

1. island / atoll と swell / current interactionを、絶対座標ではなくrelative relationとして扱う。
2. chartはlive GPSの代替ではなく、instruction / rehearsal / memoryのためのmodelとして使われる。
3. 実際のwayfindingでは、事前に学んだmodelと海上でのsituated sensingを往復する。
4. disturbanceやwave interactionが「noise」ではなくroute/location cueになり得る。
5. routeはglobal mapを完全に持つことより、local cue sequenceを更新しながら維持される場合がある。

## target return

CSWでは、海・島・波の対応を対象へ移植しない。

de-binding後に残す問いは、

- global coordinateがなくてもlocal cueの連鎖で進めるか。
- modelで予習できる部分と、実環境で再観測しなければならない部分は何か。
- obstacle周辺のperturbationが位置や状態のsignalになっていないか。
- route更新はmap全体の再構築を要するか、それとも局所cueで足りるか。
- abstract representationとsituated evidenceが食い違ったとき、どちらをどうtarget-side observationへ戻すか。

である。

## Jingluoとの差分

両者を単に「network」として統合しない。

Jingluoが提供するのは、

- main / collateral channel
- branching
- flow route
- traditional medical-system topology

である。

Marshallese wave navigation側で追加されるのは、

- non-medical wayfinding
- relative environmental cue
- instructional model vs live sensing
- disturbance-as-signal
- route memory / cue sequence

である。

したがって、医療的主張をde-bindしたJingluoだけでは、model-environment returnやsituated sensingとの往復を十分に代替できない。

## cultural / living-tradition boundary

- family / school-specificな非公開知識を推定しない。
- 公開museum objectだけから一つのuniversal notationを再構成しない。
- chart terminology / typologyのhistorical variationを固定しない。
- traditional navigationをmodern oceanographyの事実へ直接変換しない。
- real-world marine navigationへ使わない。
- cultural expertiseやnavigator authorityをCSWが代行しない。

## runtime adoptionを急がない理由

operation gapは明確に埋まるが、living traditionであり、知識伝承の公開範囲・学校差・歴史的断絶を尊重する必要がある。

runtimeへ進める前に、

1. global mapが不完全なtarget-side worked exampleを作る。
2. another non-medical wayfinding traditionと比較し、generic route planningとの差を確認する。
3. public-source boundaryをprofile単体で守れるか再監査する。
4. target-return後にも model/environment return と cue-sequence operation が残るか確認する。

## portfolioへの影響

この追加で、route / network familyは

- Jingluo: medical-channel topology
- Marshallese wave navigation: non-medical relative wayfinding

という異質な2候補を持つ。

これでroute-networkの空白は「候補が一つもない」状態ではなくなった。ただしroute tradition全体のcoverageが十分という意味ではない。今後は候補数を増やすより、**別の非海洋・非医療route traditionでも同じoperationが出るか**を確認する方が価値が高い。

## 比較伝統によるcollapse test

Vaeakau–Taumakoのwind compass / navigational toolkitを比較対象として調べた。

比較ノート:

- `comparisons/marshallese-vs-vaeakau-taumako.md`

この比較では、両者に環境cue・wayfinding・学習された空間frameworkという共通性がある一方、

- Vaeakau–Taumako: discrete directional frame / multiple cue-family toolkit / fallback;
- Marshallese: perturbation-as-signal / relative environmental structure / model-environment return / local cue sequence;

という中心操作の差が残った。

そのためVaeakau–Taumakoは当面inventory候補へ追加せず、Marshallese候補がgeneric route planningへ崩れていないか確認する比較伝統として保持する。
