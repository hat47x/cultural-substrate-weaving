# Jain anekāntavāda / syādvāda / sevenfold predication profile

Status: adopted / runtime-corpus

## Identity

- names: ジャイナ多面説 / anekāntavāda / syādvāda / saptabhaṅgī
- family: Jain philosophical traditions
- intended CSW use: conditioned assertion and perspective binding
- runtime dossier: src/ja-JP/frameworks/jain-sevenfold-predication.md

## Source basis

Internet Encyclopedia of Philosophy, Jain Philosophy

https://iep.utm.edu/jain/

The reference describes seven predicative forms involving affirmation, negation, both, indescribability, and combinations, all marked by syāt / conditioned standpoint.

## Structural core

The central cognitive value for CSW is not seven labels by themselves. It is the requirement that assertions be bound to circumstance, standpoint, or aspect, while leaving room for what is not adequately expressible under the current vocabulary.

## Native operation candidates

- perspective-binding;
- qualified-assertion;
- indescribability-probe;
- contradiction-decomposition;
- perspective-rotation.

## Lineage / variant boundary

Do not reduce syāt to casual uncertainty or generic “everything is relative.” Translation of syāt varies, and the system belongs to a larger Jain metaphysical and epistemic context. Do not identify the sevenfold scheme with the Buddhist catuṣkoṭi.

## Exploratory outputs

- conditioned claim;
- standpoint-specific contrast;
- unresolved/indescribable residual;
- decomposition of apparent contradiction.

## Prohibited shortcuts

- “all views are equally true”;
- seven modern truth values;
- using indescribability to avoid target checking;
- assigning seven ontological states to a target.

## De-binding

1. replace syāt language with explicit target conditions;
2. name the dimension that changes: time, actor, scale, definition, evidence state;
3. preserve unresolved residuals;
4. return each conditioned claim to target support or falsification.

## Target-return questions

- From which standpoint is this claim valid?
- Which omitted condition makes the opposite claim valid?
- Which part cannot be stated with the current vocabulary?
- Does the contradiction disappear when aspect or time is split?

## What this framework does not license

It does not license generic relativism, epistemic evasion, or unsupported claims about the nature of reality.
