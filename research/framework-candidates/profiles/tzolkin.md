# Tzolk’in framework profile candidate

Status: sourced-candidate / research-only

## Identity

- names: Tzolk’in / Chol Q’ij / Maya sacred calendar
- family: Maya calendrical traditions
- intended CSW use: coupled-cycle and recurrence questions
- current profile scope: calendar mechanics only; interpretive/ceremonial meanings remain under research

## Source basis

Smithsonian National Museum of the American Indian, Living Maya Time: The Calendar System

https://maya.nmai.si.edu/calendar/calendar-system

The source describes the sacred calendar as a succession of twenty day glyphs combined with the numbers one through thirteen, producing 260 unique days. It also presents the calendar as a living Maya tradition rather than only an archaeological object.

## Structural core retained by this profile

### Twenty day signs

The system uses a repeating sequence of twenty day signs.

For CSW, these are not imported as personality types. Their first structural value is that they form one periodic coordinate.

### Thirteen-number cycle

A separate numerical sequence cycles from one through thirteen.

This supplies a second periodic coordinate.

### Coupled cycle

The two cycles combine to create 260 unique day combinations.

This is the main cognitive contribution of the minimal profile:

- two periodic structures can coexist;
- their joint state is not reducible to either cycle alone;
- a recurrence in one coordinate does not mean recurrence of the whole configuration.

## Native operation candidates

### phase-coupling

Ask how two independent periodic structures combine at the current point.

Outputs:

- temporal distinction
- phase relation
- question

Boundary:

The target need not literally have a 13-by-20 calendar. The operation is exploratory unless the target itself contains compatible cycles.

### recurrence-distance

Ask when a composite configuration recurs, and whether a partial recurrence is being mistaken for a full recurrence.

Outputs:

- recurrence question
- comparison point
- residual

### split-cycle-view

Hold one cycle fixed conceptually while examining movement in the other.

Questions:

- Which apparent repetition is only repetition on one axis?
- What difference is hidden when only the dominant cycle is tracked?
- Are two events similar because both coordinates align, or only one?

### de-synchronize

Intentionally compare points where one cycle aligns and the other does not.

Outputs:

- counter-example candidate
- distinction
- falsifier

## What not to import by default

- personality descriptions for day signs;
- generalized fortune telling;
- pan-Maya claims that erase community differences;
- ceremonial meanings without community/source attribution;
- claims that calendar position causes target events.

## Living-tradition boundary

This system remains in sourced-candidate rather than profile-ready because mechanics alone are not enough for culturally faithful enacted use.

Before skill-candidate status:

- distinguish Yucatec Tzolk’in and K’iche’ Chol Q’ij terminology and living practice;
- add sources from living Maya educational or scholarly materials on day-sign interpretation;
- separate calendar arithmetic from ceremonial and divinatory practice;
- avoid extracting sacred vocabulary merely as generic productivity metaphors.

## Exploratory prompts produced by this profile

- Are two different cycles being collapsed into one timeline?
- Does a pattern recur on one scale while remaining different on another?
- What only becomes visible when the two phases are considered together?
- Which claimed repetition disappears when the second coordinate is included?
- Is the useful result the coupled-cycle question even if the Maya calendar mapping is later removed?
