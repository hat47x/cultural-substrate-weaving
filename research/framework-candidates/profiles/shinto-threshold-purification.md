# Shinto shrine threshold / purification candidate profile

Status: sourced-candidate / research-only

## Identity

- names: shrine-entry threshold, torii / temizu / harae sequence
- current scope: contemporary shrine-visit protocol and selected purification concepts documented by Jinja Honcho and Kokugakuin University's Encyclopedia of Shinto
- intended CSW use: explicit boundary crossing, pre-entry preparation, path-to-center, and state transition through practice
- not intended use: representing all Shinto ritual, all shrines, or all historical periods with one protocol

## Structural core

A minimal contemporary sequence can be represented as:

outside ordinary space
→ torii / marked threshold
→ approach path
→ temizu / preparation-purification
→ place of worship / central act
→ departure / return

The cognitive value lies in **a boundary that changes the state of participation and requires preparation before the central act**.

## Candidate operations

### threshold-marking

Ask where a transition is explicitly marked rather than inferred.

### before-entry-preparation

Ask what must happen before a participant is treated as ready to proceed.

### path-to-center

Distinguish threshold, approach, preparation point, and central interaction.

### state-transition-by-practice

Ask whether a practice changes what actions are considered appropriate next, without assuming any supernatural or medical mechanism.

### closure-and-return

Inspect whether leaving, returning, or re-entering changes the participant's state or obligations.

## What not to import by default

- sacredness as a target-side fact;
- ritual purification as hygiene, medicine, or causal cleansing;
- contemporary protocol as an unchanged ancient sequence;
- Jinja Honcho's presentation as exhaustive of all Shinto traditions;
- shrine etiquette as a description of "Japanese people" in general;
- historical ideas of tsumi / kegare as direct moral judgments on unrelated targets.

## Historical and variation caution

Harae, misogi, shubatsu, and ōharae are not interchangeable labels for one invariant ritual.

The current profile uses the shrine-entry sequence because it is well documented and operationally clear. Historical purification rites should remain a separate research layer.

## Exploratory prompts

- Where is the actual threshold in this process?
- What changes immediately after crossing it?
- Is there a preparation state before the central action?
- What path is treated as privileged or constrained?
- Does a failure occur because entry happened without preparation?
- Is there a closing or return action that restores the ordinary context?

## De-binding

1. remove shrine, torii, purity, and sacred-space vocabulary unless needed for provenance;
2. restate the structure as threshold, approach, preparation, central action, and return;
3. ask whether the target independently has such states;
4. preserve cases where the target has no meaningful boundary instead of inventing one;
5. do not turn "prepared/unprepared" into moral worth.

## Adoption gap

Needs at least:

- historical separation among harae / misogi / shubatsu / ōharae;
- evidence of variation among shrine contexts rather than one institutional protocol;
- a target-return example showing useful threshold questions without importing purity judgments.
