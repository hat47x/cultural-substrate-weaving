# Catuṣkoṭi framework profile

Status: adopted / runtime-corpus

## Identity

- names: 四句分別 / catuṣkoṭi / tetralemma
- family: Buddhist philosophical and logical traditions
- intended CSW use: binary-frame disruption and predicate audit
- runtime dossier: src/ja-JP/frameworks/catuskoti.md

## Source basis

Stanford Encyclopedia of Philosophy, Contradiction — LNC and the Buddhist Tetralemma

https://plato.stanford.edu/entries/contradiction/

The reference lays out the four corners around a proposition: P, not-P, both, and neither, while situating the form in Buddhist philosophical debates.

## Structural core

For a proposition P, open four positions:

1. P;
2. not-P;
3. both P and not-P;
4. neither P nor not-P.

CSW uses the four positions to test framing. It does not treat them as one uncontested modern four-valued semantics.

## Native operation candidates

- binary-break;
- both-probe;
- neither-probe;
- predicate-audit;
- de-reification.

## Lineage / variant boundary

Uses of the tetralemma differ by text, period, and philosophical purpose. Nāgārjuna/Madhyamaka use must not silently stand for every Buddhist use, and modern formal reconstructions should not be projected back as the one historical logic.

## Exploratory outputs

- third/fourth-position question;
- mixed-layer or mixed-time diagnosis candidate;
- predicate failure;
- residual outside the original opposition.

## Prohibited shortcuts

- declaring every four corners simultaneously true;
- using “both” as a license for contradiction without conditions;
- treating “neither” as mystical closure;
- promoting a framework position to target fact.

## De-binding

Translate the surviving insight back into target terms: different time, layer, actor, definition, or a malformed predicate. Remove Buddhist terminology when it no longer adds provenance value.

## Target-return questions

- What condition makes P hold?
- What condition makes not-P hold?
- Does “both” disappear when time or viewpoint is separated?
- Does “neither” indicate a missing category?
- Is P itself the wrong predicate?

## What this framework does not license

It does not settle formal logic disputes or establish ontological contradictions in the target.
