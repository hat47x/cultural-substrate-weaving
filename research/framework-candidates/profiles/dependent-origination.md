# Dependent origination framework profile candidate

Status: sourced-candidate / research-only

## Identity

- names: 縁起 / pratītyasamutpāda / paṭiccasamuppāda / dependent origination
- family: Buddhist philosophical and soteriological traditions
- intended CSW use: conditional-arising and cessation questions
- current profile scope: conditional structure; not doctrinal adjudication

## Source basis

Stanford Encyclopedia of Philosophy, Buddha

https://plato.stanford.edu/entries/buddha/

The source presents the Buddhist analysis of suffering in terms of causes and conditions and notes the traditional twelve-link chain, while also noting that the twelve-link formulation is a later compilation and that shorter formulations occur in early materials.

## Structural core retained by this profile

### Conditional arising

A phenomenon is approached through the conditions under which it arises, rather than as an isolated essence.

Cognitive contribution:

- move from entity language to condition language;
- ask what must be present for an observed pattern to arise;
- distinguish enabling condition from the apparent final event.

### Linkage

Traditional presentations often use linked sequences.

For CSW, the useful structure is not merely a fixed list of twelve labels. It is the discipline of tracing a phenomenon through connected conditions and refusing to treat the endpoint as self-explanatory.

### Cessation

If an outcome depends on conditions, changing or ceasing relevant conditions changes what can arise.

This opens a counterfactual operation:

- what would have to stop;
- what would remain;
- which link is actually supported by target evidence.

## Native operation candidates

### condition-chain

Rewrite an apparent thing or event as a chain of necessary or contributing conditions.

Outputs:

- condition candidate
- relation candidate
- question

### upstream-condition

Move one or more steps upstream from the visible problem.

Questions:

- What does this state depend on?
- Which dependency is assumed but unobserved?
- Where does the current explanation begin too late?

### cessation-counterfactual

Remove or alter one proposed condition hypothetically.

Questions:

- Does the target evidence predict change?
- Which downstream effect should disappear first?
- What remains, indicating the condition was not sufficient?

Outputs:

- falsifier
- observation target
- residual

### anti-essentialist-counter-view

Ask whether a fixed trait description is hiding a contingent set of conditions.

Output:

- reframing question
- distinction

Boundary:

This is an exploratory cognitive move, not a claim that Buddhist ontology has been established as the domain model.

## What not to import by default

- the twelve links as the only historically valid formulation;
- Buddhist soteriological claims as domain facts;
- karma or rebirth claims into unrelated target domains;
- a generic deterministic causal DAG;
- a claim that every phenomenon can be decomposed into one linear chain.

## Historical/lineage caution

The twelve-link chain is important but should not be treated as a timeless single-format algorithm.

Before skill-candidate status, the profile should distinguish at least:

- early/shorter formulations;
- the standard twelve-link presentation;
- later Abhidharma interpretations;
- Mahayana uses where relevant.

The purpose is not to teach all Buddhist schools. It is to prevent one later schematic form from silently becoming the whole tradition.

## Exploratory prompts produced by this profile

- What conditions must be present for this pattern to arise?
- Which condition is merely correlated, and which is actually needed?
- If this condition ceased, what target-side observation should change?
- Does the explanation start at the visible symptom rather than upstream?
- Is a fixed label hiding a repeatable conditional process?
- Which link was supplied by the framework rather than observed in the target?

## De-binding

1. restate links as target-side conditions;
2. remove Buddhist doctrinal terms unless needed for provenance;
3. label unsupported links framework_generated;
4. formulate cessation claims as testable target questions where possible;
5. preserve contradiction if target material does not behave as the chain predicts.

## Candidate adoption note

Current status remains sourced-candidate.

The conditional-arising operation is promising and structurally distinct, but the profile needs lineage-aware source expansion before use as an independent Skill module.
