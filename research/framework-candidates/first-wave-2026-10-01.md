# Framework candidate first wave — 2026-10-01

Status: research-only / qualitative expansion before effectiveness evaluation

## 目的

CSWの文化体系層は、現時点では方法論の厚みに比べて個別体系の量と精度が不足している。

この段階では効果検証を急がず、まず異なる認知operationを供給できる体系の質と量を確保する。

第一波では、対象への表面的な「相性」ではなく、現在のCSWが必要としているoperation空間の差で候補を選ぶ。

## 第一波で厚くする五体系

### 1. 易 / Yijing — 離散状態と変化

構造核:

- 陰陽の線。
- 三爻の八卦。
- 六爻の六十四卦。
- 配置の組合せと変化を読む長い解釈史。

CSWで開ける仕事:

- static descriptionをstate configurationとして見直す。
- 一要素が変わったとき、全体配置の意味がどう変わるかを問う。
- 対立・反転・隣接する配置からcounter-viewを作る。
- 「現在どこに当たるか」より、何が変わると別状態になるかを前景化する。

重要な境界:

- 卦への対応付けをtarget-side factにしない。
- 後世の配当表を一つの古典的正本として混ぜない。
- exploratory useでは占断そのものを必須にしない。

主要source:

- Chinese Text Project, Book of Changes: Xi Ci I
  - https://ctext.org/book-of-changes/xi-ci-shang
- Stanford Encyclopedia of Philosophy, Metaphysics in Chinese Philosophy
  - https://plato.stanford.edu/entries/chinese-metaphysics/

profile: profiles/yijing.md

### 2. 五行 / Wuxing — 複数の関係原理を持つ循環

構造核:

- 木・火・土・金・水という五つのphase。
- 生成 sheng と克／制約 ke という異なるrelation。
- 周期と相互作用。
- 歴史的には多様な領域へのcorrelative extensionがある。

CSWで開ける仕事:

- 「支える」と「抑える」を同じrelationへ畳まない。
- 一方向の原因説明からcycleへ視点を移す。
- 同じ対象がcontextにより別phase的に振る舞う可能性を問う。
- loopの中で促進側と制約側を別々に見る。

重要な境界:

- 五つの物質として固定しない。
- 歴史上の全対応表を同時に正本化しない。
- phase割当をtarget evidenceにしない。

主要source:

- Stanford Encyclopedia of Philosophy, Metaphysics in Chinese Philosophy
  - https://plato.stanford.edu/entries/chinese-metaphysics/
- Stanford Encyclopedia of Philosophy, Religious Daoism
  - https://plato.stanford.edu/entries/daoism-religion/

profile: profiles/wuxing.md

### 3. Tzolk’in / Chol Q’ij — 二つの周期の結合

構造核:

- 20のday glyph。
- 1〜13のnumber cycle。
- 二つの系列の組合せによる260のunique day。

CSWで開ける仕事:

- 一つの周期ではなく、独立した周期のphase couplingを見る。
- 同じ見かけの局面が、別周期の位置によって異なることを問う。
- recurrence distanceやphase coincidenceを対象の問いへ翻訳する。

重要な境界:

- 一般化された性格診断や運勢ロジックへ変換しない。
- living Maya communitiesの解釈差を消さない。
- calendar coordinateを因果根拠にしない。

主要source:

- Smithsonian National Museum of the American Indian, Living Maya Time: The Calendar System
  - https://maya.nmai.si.edu/calendar/calendar-system

次段:

- living-tradition側の用語・実践差を追加確認。
- calendar mechanicsとinterpretive traditionを別層にしたprofileを作る。

### 4. 縁起 / dependent origination — 条件連鎖と停止点

構造核:

- 現象が条件に依存して生起するという見方。
- 伝統的な十二支縁起。
- 十二項だけではない歴史的なformulationが存在する。
- 条件の消滅と結果の停止を結びつける見方。

CSWで開ける仕事:

- 結果から上流条件へ戻る。
- 「原因は何か」ではなく「成立に何が必要か」を問う。
- 一つの条件を外したcounterfactualを作る。
- entity中心の説明をdependency中心へ反転する。

重要な境界:

- 十二支を唯一の歴史的形式としない。
- generic causal DAGへ薄めない。
- 仏教の宗教的・解脱論的文脈を、一般領域の事実へ移さない。

主要source:

- Stanford Encyclopedia of Philosophy, Buddha
  - https://plato.stanford.edu/entries/buddha/

次段:

- early Buddhist / Abhidharma / Mahayana等のformulation差を整理してからprofile化する。

### 5. Rasa — 表現内容と受容経験を分ける

構造核:

- Nāṭyaśāstraを起点とするaesthetic theory。
- 表現された感情要素と、受け手が味わうaesthetic experienceを区別する長い議論。
- Abhinavagupta等による後世の展開。

CSWで開ける仕事:

- 「作品に何が書かれているか」と「受け手に何が立ち上がるか」を分ける。
- affectを単一labelにせず、構成→受容の変換として見る。
- writer / artifact / spectatorの視点を切り替える。
- target artifactの意味とexperienceを同一視しない。

重要な境界:

- modern universal emotion taxonomyとして使わない。
- navarasaの固定一覧だけで歴史全体を代表させない。
- 心理診断へ転用しない。

主要source:

- Oxford Bibliographies, Rasa in Indian Aesthetics
  - https://academic.oup.com/reference/62382/reference-article-abstract/566568637
- Oxford Bibliographies, Aesthetics
  - https://academic.oup.com/reference/62357/reference-article-abstract/554506345

次段:

- Nāṭyaśāstraの構造語とAbhinavagupta以降の展開を分けてprofile化する。

## 第二波に留める候補

### Jingluo / 経絡

認知上はmain route / collateral / network / branchingを強く供給できる。

ただし医療体系であり、探索的なnetwork metaphorと診断・治療主張を厳密に分ける必要がある。WHO標準用語とNCBI MeSHで構造語の基礎は取れるが、Skill候補化前に「文化構造として使う範囲」を明示する。

### Sefirot

層、媒介、balance/tension、emanationという異なる構造を持つ。

一方、Sefer Yetzirahの用法と後代Kabbalahの十のsefirotを一つの固定Treeへ潰す危険が大きい。系譜別profileを先に作る。

### Chakra systems

vertical axis / embodied position / practice sequenceを供給し得るが、Hindu/Buddhist tradition間、時代、lineageによる数・配置・意味の差が大きい。

現代の「虹色7 chakra」図を古典的な普遍schemaとして採用しない。lineage-specificなsourceが揃うまで defer-lineage-specific とする。

## coverageとして見るもの

第一波の狙いは次のoperation差を同時に持つことにある。

| operation family | 主候補 |
|---|---|
| discrete state / recomposition / transition | Yijing |
| relational cycle / generation vs constraint | Wuxing |
| coupled periodicity / recurrence | Tzolk’in |
| condition chain / interruption / anti-essentialist view | dependent origination |
| aesthetic emergence / receiver position | Rasa |

ここで埋まっていない主な空間は、

- network / collateral
- spatial center-periphery
- embodied axis
- ritual practice sequence
- layered mediation
- explicit boundary-crossing

である。

第二波は、この空間を埋めるために選ぶ。第一波と似た分類体系を大量に追加することは優先しない。

## Skill候補化の条件

profile-readyからskill-candidateへ進める際は、少なくとも以下を揃える。

1. source basis
2. lineage / variant note
3. structural core
4. native operations
5. exploratory outputs
6. prohibited shortcuts
7. de-binding route
8. target-return questions
9. what the framework does not license
10. enough detail to run more than one operation without web lookup

効果比較は、この量と質が一定程度揃った後に行う。
