# Framework corpus eighth wave — 2026-10-02

Status: bounded runtime adoption / no broad efficacy benchmark

## Decision

Mīmāṃsā hermeneutics moves from profile-ready to adopted.

The decision is based on source quality, explicit Bhāṭṭa / Prābhākara boundaries, two structurally different non-religious target-return examples, and a clear distinction from classical stasis theory and Nyāya inference.

The runtime core remains deliberately narrow:

- prescriptive-unit detection;
- purpose unity;
- syntactic expectancy;
- semantic fitness;
- explicit versus context-supplied material;
- norm-conflict decomposition.

No Vedic authority, ritual obligation, or universal interpretation algorithm is transferred to target documents.

## Product-value effect

CSW now has a framework for a class of tasks that the existing portfolio handled only indirectly: rules and specifications that appear contradictory because their sentence scope, exception conditions, or contextual supplementation are unclear.

This fills the prescriptive-hermeneutics gap without adding a general-purpose “legal interpretation” layer or automatic correctness score.

## Remaining gaps

Indexed narrative corpora and historically bounded mediation/layer systems remain the main corpus gaps. Ifá / Odù and the split sefirot research tracks remain promising but are not promoted until their living-tradition and lineage boundaries can be preserved without simulating specialist religious authority.
