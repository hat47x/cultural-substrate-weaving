# Jingluo route-network negative example

Status: negative example / profile-readiness support

A target consists of three independent configuration values with no handoff, route, branch, or transfer relation.

Representing them as main and collateral routes would add topology that the target does not contain.

The correct CSW result is to reject the Jingluo pass. A set of related variables is not automatically a route network, and cultural variety is not a reason to invent path continuity.
