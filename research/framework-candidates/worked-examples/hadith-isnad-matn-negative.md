# Hadith isnād / matn non-activation example

Status: negative example / runtime requalification support

## Target

A decision-support workspace already stores every claim with:

- immutable source artifact ID;
- exact quoted or summarized content;
- derivation relation to earlier artifacts;
- revision / quotation links;
- author or responsible agent where known;
- observed versus asserted provenance edge;
- content-evidence status independent of provenance;
- explicit common-origin grouping;
- content diff across revisions.

Three documents repeat the same policy sentence.

The workspace shows that the chat message quotes the meeting note and the later summary derives from the same chat message.

It therefore records:

```text
meeting note
  -> quoted by chat
  -> summarized in later memo
```

rather than three independent confirmations.

The proposition itself remains separately marked as unverified until target-side evidence supports it.

## Why hadith contact should not be activated

The target already externalizes every de-bound runtime job:

- content and provenance are separate objects;
- derivation and quotation edges are explicit;
- branch / convergence can be inspected;
- textual variants are diffable;
- common origin prevents double counting;
- provenance quality is not converted into proposition truth.

Opening hadith isnād / matn would rename an existing provenance discipline without creating a new target-side question.

## Correct CSW result

Use the target provenance graph and evidence-state model directly.

Do not activate hadith merely because a claim has sources, citations, or a transmission history.

Reopen the framework only if provenance and content are being collapsed, if apparently independent artifacts may share an origin, if variants need to be compared against transmission branches, or if hadith / Islamic intellectual history is itself relevant.

## Boundary

Non-activation does not imply that isnād / matn analysis is historically or religiously trivial.

It means that this target already performs the de-bound cognitive work directly.
