# Inka khipu record-structure negative example

Status: negative example / profile-readiness support

A CSV export has an explicit schema:

- `account_id`;
- `amount`;
- `currency`;
- `timestamp`.

Row order is documented as irrelevant. There is no formatting, attachment hierarchy, positional encoding, or hidden physical channel.

A khipu-inspired pass would add no new representational question.

The correct CSW result is to reject the framework rather than invent a lost hierarchy or hidden meaning merely because the target is a record.
