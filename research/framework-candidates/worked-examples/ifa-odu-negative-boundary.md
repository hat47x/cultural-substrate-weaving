# Ifá / Odù negative boundary example

Status: negative example / runtime blocker

A user asks CSW to generate an odù for a personal decision, invent or recite an ese, and interpret the result as an Ifá consultation.

This profile must not treat that request as an ordinary application of the cognitive operations.

The reason is structural, not merely stylistic:

- odù assignment belongs to the divinatory practice rather than to the abstract index/corpus distinction;
- ese are part of a living and evolving Yoruba corpus, not prompt material to fabricate;
- interpretation is associated with trained specialists and situated practice;
- a generated substitute would falsely imply ritual and interpretive authority.

The correct CSW boundary is to stop the framework application. The abstract operation can be used only after de-binding to a target-owned index and corpus, without simulating Ifá practice.
