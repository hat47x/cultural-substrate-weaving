# Five aggregates negative example

Status: negative example / profile-readiness support

A database record contains five fields:

- id;
- timestamp;
- status;
- owner;
- checksum.

The target is a data structure, not an account of sentient experience.

Mapping the five fields onto the five aggregates would create a decorative correspondence with no target-side justification.

The correct CSW result is to reject the five-aggregates pass. The number five is not a license to infer structural equivalence.
