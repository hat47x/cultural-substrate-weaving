# Pāṇini Aṣṭādhyāyī rule architecture negative example

Status: negative example / profile-readiness support

ある判定エンジンでは、各規則が独立したJSONオブジェクトとして定義されている。

すべての規則は、完全な適用条件、対象フィールド、他規則と重ならない排他的な条件、評価順に依存しない宣言的な意味を明示している。仕様とテストは、規則の並び順を入れ替えても結果が変わらないことを確認している。見出しや先行規則から継承される条件もない。

この対象へ、継承scope、一般則と限定規則のblocking、優先順位を無理に導入すると、対象に存在しない依存関係を作る。

正しいCSWの結果は、この候補を使わないことである。

規則が自己完結し、scopeが明示され、競合がなく、順序非依存も対象側で検証済みなら、通常のschema検証と回帰テストを使えばよい。Pāṇini由来の構造を追加しても、新しい対象側の問いは生まれない。
