# チベット仏教マンダラ target-return例

Status: hypothetical / runtime adoption support

複数段階のアクセス制御を持つ業務システムを考える。通常利用者、担当者、承認者、管理者が同じ画面群を使うが、機能ごとに境界と入口が異なる。

マンダラの空間構造を一時的に当てると、単純な「権限が高い／低い」という縦一列の見方から離れられる。中心とみなされる機能、周辺領域、複数の囲い、特定の入口、方位に相当する役割別区画を分けて確認できる。

対象へ戻すと、残る問いは次のようになる。

- 中心機能は本当に全利用者にとって中心か。
- 同じ権限段階でも、役割によって別の入口が必要ではないか。
- 外部と内部の二分では見落とす中間領域がないか。
- ある領域へ入るための門は、権限、承認、手続きのどれか。
- 中心を別の機能へ移しても、同じアクセス構造は残るか。

尊格、色、宗教上の価値序列を外した後も、中心、方位、境界、門、接近経路という構造が残る。
