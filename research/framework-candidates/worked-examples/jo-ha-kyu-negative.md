# Jo-Ha-Kyū negative example

Status: negative example / profile-readiness support

A batch process runs at a constant documented rate from start to finish, with no change in interaction density, acceleration, or closing behavior.

Dividing the run into jo, ha, and kyū would add labels without exposing a temporal distinction.

The correct CSW result is to reject the jo-ha-kyū pass. Beginning, middle, and end alone are not enough; the target must support a meaningful pacing or transition-shape difference.
