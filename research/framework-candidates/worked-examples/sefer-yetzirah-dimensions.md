# Sefer Yetzirah dimensions target-return example

Status: hypothetical / profile-readiness support

An incident review uses one mixed label: “the rollout was bad downstream after the release.”

The statement mixes at least three possible target-owned distinctions:

- time: before / after release;
- topology: upstream / downstream;
- evaluation: expected / problematic.

A Sefer-Yetzirah-dimensions pass does not assign historical sefirot to these labels. It asks whether the target becomes clearer when the mixed statement is separated into independent axes.

The target-return questions become:

- Was the change only after release, or did it already exist before?
- Is the effect actually downstream, or present on both sides of the dependency boundary?
- Is “bad” an observed failure condition or only an evaluation label?

The value is axis separation. The historical vocabulary disappears before the result is attributed to the incident.
