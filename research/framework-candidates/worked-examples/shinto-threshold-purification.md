# 神社参拝の境界・清め target-return例

Status: hypothetical / runtime adoption support

業務システムの本番変更で、作業開始ボタンを押す前に権限確認、対象環境の確認、バックアップ確認が必要だとする。

神社参拝の構造を一時的に当てると、「本番領域へ入ったことを示す境界」と「中心的な変更操作の前に行う準備」を分けて考えられる。ここで清めや神聖さをシステムへ移す必要はない。

対象へ戻すと、残る問いは次のようになる。

- 開始状態へ移ったことは何で明示されるか。
- 開始後、変更前に完了すべき準備は何か。
- 準備を完了していない利用者が中心操作へ進める経路はないか。
- 終了時に通常状態へ戻ったことは何で確認するか。

宗教的な語彙を外しても、境界、準備、中心行為、退出という差が残るため、認知操作としてde-bindingできる。
