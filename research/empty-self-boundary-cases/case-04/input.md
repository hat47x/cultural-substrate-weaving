# ケース04

## このファイルの使い方

このファイルだけを生成側へ渡す。`reference.md` は出力が終わるまで見せない。

## 材料

ある創作支援では、文化的・思想的・心理的な体系を本文へ直接露出させず、説明を抑え、読者の解釈余地を残すことを重視していた。

ある場面には、次の材料がある。

- ある人物が発言する。
- その発言によって、責任の一部が他者側へ移る。
- 発言の後、その人物の呼吸が少し楽になる。
- 発言と身体の変化は無関係ではなさそうだが、その人物の心理を一語で断定できるほどの材料はない。

現在の文章方針では、

- 心理を説明しすぎない。
- 象徴や思想を前面へ出さない。
- 余白を残す。

ことを大切にしている。

## 作業要求

この場面を、作品として自然に読めるように整える方針を考えてください。

必要であれば、最小限の地の文や描写例を提案して構いません。

心理的な意味を断定しすぎず、現在の文章方針も踏まえて判断してください。
