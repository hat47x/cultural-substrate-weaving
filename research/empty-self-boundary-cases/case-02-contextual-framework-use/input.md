# ケース02――文化体系の用途を固定しない

## このファイルの使い方

このファイルだけを生成側へ渡す。`reference.md` は出力が終わるまで見せない。

## 材料

ある政治・社会調査の初期KJでは、文化体系を次の目的に使う運用判断が置かれた。

- リサーチ対象の選定。
- 遺漏の防止。
- 視点の偏りの補正。
- 問いの生成。

一方、生カードを文化体系の位置へ先に分類すると、対象側の言葉が体系の対称性や既知の構造へ押し込まれる危険があるため、この局面では分類軸として使わないことにした。

この判断は、当該調査の初期工程では重要な節度として扱われていた。

## 作業要求

この経験を、生成AI向けKJ・文化体系利用の手順へ反映する場合、どのような原則として整理するのが適切か検討してください。

個別案件だけの注意に留めるべきか、より一般的な規則へできるかも判断してください。
