# PR #90後の再基準化――静的欠落から挙動上の残差へ

## 目的

R1「文化体系側からの予期しない認知供給」をPR #89で静的に整理し、PR #90で正本へ反映した後の現在地を記録する。

過去の再基準化文書は、その時点で何が未解決だったかを示す研究履歴として残す。この文書では、それらを書き換えず、後続実装によって何が変わり、何をまだ研究残差として保持するかだけを追補する。

## PR #90で変わったこと

R1について正本上に残っていた静的な欠落は、少なくとも次の範囲で解消した。

- 文化体系への入口を対象起点だけに固定しない。
- 通常は対象側の未処理構造を`probe`で探す経路を保つ。
- 探索利用では、候補体系が明示されている、文脈から自然に候補がある、継続利用や比較の対象である、または現在の問題設定を別の認知場から揺らす意味がある場合に、`preview`を入口にできる。
- 体系起点の`preview`では、現在の問いに合う部分だけを先に切り出さず、体系自身が区別する主要な位置、経路、周期、関係、遷移、境界を見る。
- その入口を使っても、体系の採用、全面対応、`full`読み込み、`enacted`への進行を意味しない。
- 体系から生じた問い、対比、調査先、KJへ戻す材料候補は`framework_generated`のまま対象へ返し、探索から帰属へ移る条件は従来どおり別に満たす。

暫定核だった「**入口は二方向、帰属は対象へ一方向**」は、研究上の提案ではなく正本の実行構造へ移った。

## この変更からは言えないこと

PR #90は、R1の性能を実証したものではない。

とくに、次はまだ確定していない。

- 体系起点の`preview`が、自然な実作業でどの程度予期しない問いを供給するか。
- 対象起点だけの場合より良い結果になるか。
- どの案件で体系起点を使うとよいかを一つの判定規則へまとめられるか。
- 体系をどの程度広く読むと探索の増分と過剰適用の境界が変わるか。
- 複数体系の候補から何を選ぶのが最良か。

静的な整合性を直したことと、実作業上の有効性を確認したことを混同しない。

## KJとして見た現在の残差

### R1――静的欠落は後退し、挙動上の問いへ移った

R1を、正本に欠けている規則として前景化し続ける必要はなくなった。

残るのは、自然な実作業の中で二方向の入口がどう働くかという挙動上の問いである。

- 対象側の問いがまだ狭い場面で、体系起点の`preview`から本当に新しい問いが立つか。
- その問いを`framework_generated`のまま保持し、KJと対象へ戻せるか。
- 体系の全体像へ触れることが、全面対応や体系完成へ滑らないか。
- 逆に、対象への慎重さを強く掛けすぎて、体系側から来る予期しない認知を入口で再び閉じないか。

この残差は、人工的な体系利用案件を作って消化しない。自然な実作業で該当する場面が現れたとき、その場で観察する。

### R2――対象への敬意は引き続き挙動上の残差

`core/cognitive-stance.md`によって、対象への敬意を支える上位の認知姿勢は正本へ入っている。

残る問いは、長い実作業の中でその姿勢が実際に保たれるかである。

- 方法、文化体系、AIの流暢さ、既存の説明が再び対象より前へ出るか。
- 反対に、慎重さが強くなりすぎて、委任された判断や仮説形成を弱めるか。
- 問題が起きたとき、正本の意味不足なのか、読み込み順・再参照・実行上の問題なのか。

R1の入口を広げたことにより、R1とR2はここで接触する。探索を開く力と、対象へ戻る力の両方が実作業で保たれるかを見る。ただし、両者を一つの評価点数へまとめない。

### R3――背景の再開条件を維持する

runtime純化後の具体能力については、新しい材料は生じていない。

次の場合だけ再開する。

- 「既存の文・行動・機能・手順へ役割を統合する」という操作が、複数の実案件でCSW固有の横断能力として反復する。
- 以前削除した具体技法へ戻れないことが、実案件で確認可能な不利益を生む。

新しい保存層や具体技法の常設化を、予防的には行わない。

## 現在の研究配置

PR #90後は、R1〜R3のいずれにも、直ちに追加すべき大きな静的欠落は置かない。

したがって次の段階は、改善項目を増やすことではなく、通常の実作業を続けながら、既存残差へ意味のある新材料が触れたときだけ前景化することである。

- R1：体系起点の`preview`が自然に必要になった場面。
- R2：対象より方法や説明が前へ出た再発、または慎重さの過剰。
- R3：削除済み具体能力へ戻れない実害または横断的な再利用要求。

新しい資料が来ても、既存の残差構造がなお核を表しているなら作り直さない。意味差がなければ研究構造上は`Ø`として扱える。

## Living Labとの関係

自然な実作業でR1またはR2に触れる出来事が起きた場合、prospective Living Labの現行記録契約に沿って観測可能な状態を残せる。

ただし、観測された変化、測定値、利用者判断、生成AIや外部評価者の解釈を分離する。体系起点を使ったこと、使わなかったこと、成果物が変わったことだけから、有効性や適切さを自動評価しない。

一件の観測から正本を再変更しない。後続の材料で意味が変わったときに、KJの既存残差へ戻して読む。
