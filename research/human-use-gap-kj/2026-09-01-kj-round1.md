# 3. 現行sourceとの最も強い緊張

このKJラウンドから、現行sourceとの関係で、とくに再確認が必要な箇所を挙げる。ただし、ここではsource変更案にはしない。

## 3.1 `core/activation.md`

照合時点のsourceでは、

- 非発動
- 限定利用
- 探索利用

をCSWの発動範囲として並べ、単純な作業などでは通常手法を優先していた。

一方、HC-017〜018では、CSW自体を使うと決めた後の文化体系側について、発動を予測だけで抑制せず、発動と採用を分けるという人的補正がある。

ここではまず、

- CSW全体を使わない
- CSWのうちKJだけを使う
- CSWを使っているが、文化体系側は発動しない

という状態が、一つの `非発動` 概念へ混ざっていないかを見る必要がある。

## 3.2 `methods/system-selection.md`

照合時点のsourceは、対象側に残る未処理構造から候補体系を探す。

HC-019〜021は、体系側に対象選択前からある比較的安定したレパートリーや全体的な認知場が、現在の対象側の手掛かりだけでは出ない問いを供給することを重視する。

ここでは、

- 対象側から必要性を見て選ぶこと
- 体系側から独立に認知資源を供給すること

のどちらかを消すのではなく、両者がどのような順序と条件で共存できるかを見る。

## 3.3 `core/iteration.md`

照合時点の「文化体系をKJの分類軸として機械的に固定しない」という原則は、政治・社会調査などでは重要な節度として働く。一方、HC-007では、ある局面で必要だった抑制を普遍的な禁止へ広げないよう、人的補正がある。

文脈を限定した規則を、無条件の規則へ変えていないかを読む。

## 3.4 Living Lab / evaluation

照合時点のLiving Labは、単一観測を点数へ潰さず、不使用もeventとして保持していた。

しかしG4が示しているのは、eventの種類をどう選ぶかよりも手前の問題である。

> **eventの意味を記述したAI自身が誤っている可能性を、記録構造がどのように保持するか。**

`useful_nonuse` という名前自体が、その時点ですでに「useful」という評価を含んでいることも再検討対象になった。

この論点は、後続の追加分析を経てPR #72で改修した。第1ラウンドの時点では、まだ名前を変えるかどうかも確定していなかった。

# 5. B型叙述の暫定核

これまでの人的利用を現行スキルへ戻して読むと、問題は「文化体系を使いすぎるか、使わなさすぎるか」という量の調整だけではないように見える。

KJの材料では、新しい資料が来ても、意味が変わらなければ既存の島を安易に壊さない。意味が共同して一つの生命を持つなら統合し、証拠状態が変わるなら分ける。理由の分からない違和感も、説明を作って埋めずに残す。この運用では、AIが扱いやすい形へ早くそろえることよりも、後から元へ戻って違いを確かめられることの方が重い。

人間との関係でも、同じことが起きている。人間が付けたタグや印、AIへ委ねた判断範囲、問題設定そのものを変える指示は、対象についての事実と同じではない。しかし、それらはAIがどの操作をしてよいかを変える。AIが人間から与えられた制御を自分の洞察として取り込み直したり、自分なりの安全・効率・適切さの判断で委任範囲を狭めたりすると、誰が何を決めたのかが消える。

文化体系については、この差がさらに大きい。現在の問いに合う体系や、その一部だけを先に選べば、対象を歪める危険は減るように見える。しかし、過去の人的補正では、それ自体が文化体系の役割を現在の問題設定へ従属させると考えられていた。文化体系には、対象が決まる前から固有の位置、経路、周期、象徴、体系固有の文法（native grammar）の広がりがあり、一つの用例はその一部しか使わない。だから、発動することと、その投影を対象の事実や最終成果として採用することを分ける。探索側では、現在の対象にない見方まで働ける余地を残し、採否は対象へ戻ってから厳しく行う。

ここで、生成AI自身の評価が問題になる。AIが「これは使わない方が適切だった」「ここで止めたことが成功だった」と評価しても、それは対象で実際に起きたこととは別の材料である。測定値があっても、その値とAIによる採点や因果説明は同じではない。AIの自己評価だけを根拠に次の静的規則を作ると、AIが自分で探索を狭め、自分でそれを成功と呼び、その成功を理由にさらに探索を狭める循環が成立し得る。

このため、現段階で見えている核は、「抑制を減らす」という単純な方向ではない。**広く認知する工程と、責任をもって残す工程を分け、その間に対象の材料、人間の意思、来歴へ戻る場所を確保すること**である。

この暫定核が現行sourceのどこまでを変えるべきかは、まだ決めない。次のラウンドでは、この核を複数の実案件へ戻し、人的直接補正がどのように反復していたかを確認する。
