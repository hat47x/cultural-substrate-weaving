# human-use-gap-kj

このディレクトリは、`cultural-substrate-weaving` の人的利用、現行スキル、過去版の間にある差を、KJ法で継続的に読み直すための研究用ワークスペースである。

目的は、現行スキルの不足を急いで列挙することではない。人的利用の中で実際に行われた補正、採用、撤回、違和感と、生成AI自身が後から付けた評価とを分け、必要な差を元の材料へ戻って確かめる。

## 基本姿勢

- 利用者による直接の判断、補正、違和感、採否、撤回を優先して材料にする。
- 実際の成果物に残った差分と、後から生成AIが付けた評価を分ける。
- 生成AIによる「成功」「失敗」「有効」「不要」「適切だった」といった自己評価を、人的利用の証拠としてそのまま扱わない。
- 測定結果は、観測値や直接確認できる差と、採点、評価、因果解釈とを分けて読む。
- 生成AIの誤判断は捨てず、AI自身の判断傾向を調べる別の材料として保持する。
- 生カードを、あらかじめ改善項目や欠陥分類へ振り分けない。
- 一回のKJラウンドだけを根拠に、`src/` の静的規則を変更しない。
- 初回分析の読み違いは消さず、訂正の来歴を残す。
- 後続実装によって解消された論点を、研究上の未解決事項として惰性的に残さない。
- 文書は内容を整理した後、意味や証拠境界を変えずに全文を読み直し、自然な日本語であることを最優先して推敲する。

## 読む順序

研究の経過を最初から追う場合は、次の順が分かりやすい。

1. `2026-09-01-initial-cards.md`
2. `2026-09-01-current-gap-map.md`
3. `2026-09-01-gap-map-corrections.md`
4. `2026-09-01-direct-corrections-round2.md`
5. `2026-09-01-kj-round1.md`
6. `2026-09-01-ai-evaluation-contamination.md`
7. `2026-09-01-living-lab-observation-assessment-gap.md`
8. `2026-09-01-post-pr72-residual-map.md`
9. `2026-09-01-r3-capability-preservation-inventory.md`

この順序は、正しい結論へ一直線に進んだ履歴を示すものではない。初回の読み違いを含め、**分析そのものが訂正され、後続実装や追加照合によって問題設定も更新されていく過程**を追えるようにしている。

現在残っている研究課題だけを確認したい場合は、まず `2026-09-01-post-pr72-residual-map.md` を読み、R3については続けて `2026-09-01-r3-capability-preservation-inventory.md` を参照する。
