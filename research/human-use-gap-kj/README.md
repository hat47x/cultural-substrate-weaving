# human-use-gap-kj

このディレクトリは、`cultural-substrate-weaving` の人的利用、現行スキル、過去版の間にある差を、KJ法で継続的に読み直すための研究用ワークスペースである。

目的は、現行スキルの不足を急いで列挙することではない。人的利用の中で実際に行われた補正、採用、撤回、違和感と、生成AI自身が後から付けた評価とを分け、必要な差を元の材料へ戻って確かめる。

## 基本姿勢

- 利用者による直接の判断、補正、違和感、採否、撤回を優先して材料にする。
- 実際の成果物に残った差分と、後から生成AIが付けた評価を分ける。
- 生成AIによる「成功」「失敗」「有効」「不要」「適切だった」といった自己評価を、人的利用の証拠としてそのまま扱わない。
- 測定結果は、観測値や直接確認できる差と、採点、評価、因果解釈とを分けて読む。
- 生成AIの誤判断は捨てず、AI自身の判断傾向を調べる別の材料として保持する。
- 生カードを、あらかじめ改善項目や欠陥分類へ振り分けない。
- 一回のKJラウンドだけを根拠に、`src/` の静的規則を変更しない。
- 初回分析の読み違いは消さず、訂正の来歴を残す。
- 後続実装によって解消された論点を、研究上の未解決事項として惰性的に残さない。
- 方法や分類を先に対象へ当てるのではなく、なぜ人間の補正が必要になったのか、補正前に何が対象から失われていたのかまで戻って読む。
- 共通点を急いで取り出さず、対象ごとの違いを保ったまま個別事例へ戻してからKJで束ねる。
- 文書は内容を整理した後、意味や証拠境界を変えずに全文を読み直し、自然な日本語であることを最優先して推敲する。

  - 「対象への敬意」を、利用者への無条件の服従や慎重さとはせず、それぞれに属する意味を別のものの都合で置き換えない姿勢として整理した。
  - 現行sourceには実質の多くがすでにあるため、すぐに新しい規則や記録形式を加えず、同型の短絡がなぜ起きるのかを次の観察対象とする。
- `2026-09-01-r2-cross-case-respect-map.md`
  - 創作、KJ、沖縄リサーチ、AIへの委任、今回の研究という五つの事例を、利用者の補正が入る直前まで戻って独立に記述した。
  - 何が対象より前へ出たのか、補正によって何が戻ったのかを事例ごとに確認した後でKJを行い、「こちら側にある整ったものが、対象を読む前に答えを用意してしまう」という共通構造を暫定的に立てた。
  - 共通表札を各事例へ戻し、五件には載ることを確認した一方、「何をもって対象を十分に読んだといえるか」は未解決として残した。
- `2026-09-01-r2-responsibility-boundary-history.md`
  - 「対象への敬意」をすぐruntimeへ追加せず、v0.2.0から現在まで、対象への忠実性とAI自身の癖を補正する責務がどこに置かれてきたかを追った。
  - 2026-08-22の純化では、CSW固有の認知能力を本体へ残し、AI一般の既定傾向の補正を呼ぶ側へ移すという明確な境界があった。
  - 純化直後のcaller guideには、均衡化、弱め、行為者消去、余計な説明、標準解などを呼ぶ側が補正する案内があったが、v0.3.0以降の簡略化では前景から消えている。
  - 一方、KJで必要になった「流暢さによる材料の上書き」など、CSW固有の必要性が明確なものは現在の本体へ別の形で戻っている。
  - 現在の問いを、「敬意を本体へ戻すか」ではなく、CSW固有の責務、呼ぶ側の責務、静的文書ではなく実行時の注意に属する問題をどう分けるか、と置き直した。

## 読む順序

研究の経過を最初から追う場合は、次の順が分かりやすい。

この順序は、正しい結論へ一直線に進んだ履歴を示すものではない。初回の読み違いを含め、**分析そのものが訂正され、個別事例への戻りと後続実装によって問題設定も更新されていく過程**を追えるようにしている。

現在残っている研究課題だけを確認したい場合は、まず `2026-09-01-post-pr72-residual-map.md` を読む。そのうえで、R2は `2026-09-01-r2-respect-and-method-control.md` → `2026-09-01-r2-cross-case-respect-map.md` → `2026-09-01-r2-responsibility-boundary-history.md`、R3は `2026-09-01-r3-capability-preservation-inventory.md` を続けて参照する。
