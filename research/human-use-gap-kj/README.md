# human-use-gap-kj

このディレクトリは、`cultural-substrate-weaving` の人的利用、現行スキル、過去版の間にある差を、KJ法で継続的に読むための研究用ワークスペースである。

## 基本姿勢

- 利用者の直接判断、補正、違和感、採否、撤回を優先して材料にする。
- 実際の成果物に残った差分と、後から生成AIが付けた評価を分ける。
- 生成AIによる「成功」「失敗」「有効」「不要」「適切だった」という自己評価を、人的利用の証拠として扱わない。
- 測定結果は、観測値・差分と、採点・評価・因果解釈を分離して読む。
- 生成AIの誤判断は捨てず、AI自身の判断傾向を調べる別材料として保持する。
- 生カードを改善項目へ先験分類しない。
- 一回のKJラウンドだけで runtime source を変更しない。
- 文書は内容整理後に、意味を変えず自然な日本語を最重要視して全文を見直す。
