# human-use-gap-kj

このディレクトリは、`cultural-substrate-weaving` の人的利用、現行スキル、過去版の間にある差を、KJ法で継続的に読み直すための研究用ワークスペースである。

目的は、現行スキルの不足を急いで列挙することではない。人的利用の中で実際に行われた補正、採用、撤回、違和感と、生成AI自身が後から付けた評価とを分け、必要な差を元の材料へ戻って確かめる。

## 基本姿勢

- 利用者による直接の判断、補正、違和感、採否、撤回を優先して材料にする。
- 実際の成果物に残った差分と、後から生成AIが付けた評価を分ける。
- 生成AIによる「成功」「失敗」「有効」「不要」「適切だった」といった自己評価を、人的利用の証拠としてそのまま扱わない。
- 測定結果は、観測値や直接確認できる差と、採点、評価、因果解釈とを分けて読む。
- 生成AIの誤判断は捨てず、AI自身の判断傾向を調べる別の材料として保持する。
- 生カードを、あらかじめ改善項目や欠陥分類へ振り分けない。
- 一回のKJラウンドだけを根拠に、`src/` の静的規則を変更しない。
- 初回分析の読み違いは消さず、訂正の来歴を残す。
- 後続実装によって解消された論点を、研究上の未解決事項として惰性的に残さない。
- 方法や分類を先に対象へ当てるのではなく、なぜ人間の補正が必要になったのか、補正前に何が対象から失われていたのかまで戻って読む。
- 共通点を急いで取り出さず、対象ごとの違いを保ったまま個別事例へ戻してからKJで束ねる。
- 新しい資料が来たこと自体を理由に、なお材料の核を表している既存の研究構造を作り直さない。意味が変わった部分だけを追補する。
- 文書は内容を整理した後、意味や証拠境界を変えずに全文を読み直し、自然な日本語であることを最優先して推敲する。

## 現在地

PR #84〜#90を経て、R1とR2で確認されていた大きな静的欠落は正本へ反映された。`core/cognitive-stance.md` はKJ法の「己を空しくしてデータをして語らしめる」を、**自分の知識や推論を対象によって修正され得る位置へ置くこと**としてCSW全体の上位姿勢へ接続している。さらにPR #90では、文化体系への探索入口を対象起点だけに固定せず、条件に応じて体系起点の`preview`から入る経路を追加した。

現在は、新しい静的規則を急いで増やす段階ではない。残差は次のように扱う。

- **R1――文化体系側からの予期しない認知供給**：静的なsource差はPR #90で解消した。今後は、体系起点の`preview`が自然な実作業で本当に新しい問いを供給するか、その問いを`framework_generated`のままKJと対象へ戻せるか、全面対応へ滑らないかという挙動上の残差だけを見る。
- **R2――対象への敬意が失われる過程**：静的な規則不足としては後退し、挙動上の残差だけを残す。方法や既存説明が対象より前へ出る再発と、逆に慎重さが強すぎて委任された判断や仮説形成を弱める歪みの双方を見る。
- **R3――runtime純化後の具体能力**：背景へ置く。具体的な再利用要求または確認可能な実害が現れたときだけ再開する。

R1とR2は、探索を開く力と対象へ戻る力が実作業で両立するかという接触面を持つ。ただし両者を一つの評価点数へまとめない。自然な実作業で意味のある新材料が現れたときだけ、既存の残差へ戻して読む。

境界ケースは `research/empty-self-boundary-cases/` に検査資産として保存されている。現時点では、ケースを回すこと自体を研究成果にしない。自然な実作業で挙動上の残差が現れた場合や、release前に限定的な回帰確認が必要になった場合に使う。

PR #90後の現在地は `2026-09-03-post-r1-runtime-rebaseline.md` を参照する。それ以前の再基準化は、その時点の問題設定を残す研究履歴として読む。
