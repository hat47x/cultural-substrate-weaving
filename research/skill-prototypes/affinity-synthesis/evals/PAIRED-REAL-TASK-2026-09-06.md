# Affinity Synthesis — Real-task Paired Comparison 2026-09-06

Status: **same-model comparative authoring exercise; not an independent randomized evaluation**

## Purpose

現行CSW/KJ運用で実際に扱われた材料へ、分離後の `affinity-synthesis` contractを改めて当てる。

比較するのは最終文言の一致ではない。

- 元材料に戻れるか。
- 現行統合で保存できていた差を、新prototypeも保存できるか。
- 現行結果に含まれる新しい意味を、元材料から継承した意味と区別できるか。
- 創作材料でも概念へ早く逃げず、場面・身体・温度を保てるか。

二種類の実材料を使う。

1. 分析系：沖縄連載 C2334-C2336 → 現行融合 C3287。
2. 創作系：『ひとりぼっちの空』の原典近接／空白／公開文章由来カードの小集合。

# Case A — 沖縄連載 C2334-C2336

## A0. Baseline material

### C2334 — 反発を起こさない出口

高圧的な説得は心理的リアクタンスを起こしやすい。本文では「考え直すべき」「恥じるべき」「あなたも同じだ」と命じず、問いと事実を置き、読者が黙って距離を取る出口を残す。

### C2335 — 行為焦点

道徳的自己評価では、自己全体を否定する羞恥より、具体的行為へ焦点を当てる罪悪感・後悔の方が修復的行動と結びつきやすいという研究蓄積がある。本連載では「人間として悪い」ではなく、言い方・共有の仕方・対象の扱い方へ鏡を返す。

### C2336 — 時間差と自己距離化

すぐに態度変更を要求せず、後日同じ言葉を思い出したときに、自分の振る舞いを少し外から見直せることを重視する。自己距離化は、感情的反応を弱め、再構成的な自己省察を助ける研究と整合する。

## A1. Meaning kernels under the prototype

C2334:
> 問いと事実を置きつつ、即時の服従や改心を迫らず、受け手が距離を取れる出口を残す。

C2335:
> 人格全体を悪とするのでなく、言い方・共有・対象の扱いという具体的行為へ振り返りを戻す。

C2336:
> その場の態度変更を完了条件にせず、時間をおいて自分の振る舞いを外から見直せる余地を残す。

三つは近いが同義ではない。

- C2334は**受け取り時の圧力と出口**。
- C2335は**評価対象を人格から行為へ限定すること**。
- C2336は**時間差と自己距離化**。

この差を消す融合は不可。

## A2. Prototype fusion candidate

> **問いと事実を置きながら、人格全体やその場での態度変更を迫らず、具体的な言い方・共有・対象の扱いへ焦点を返し、受け手が距離を取り、後から自分で見直せる余地を残す。**

## A3. Return-to-source check

### Meaning inherited directly

- 問いと事実を置く。
- 高圧的に態度変更を迫らない。
- 人格全体でなく具体的行為へ焦点を返す。
- 距離を取る出口を残す。
- 時間を置いた自己再検討を許す。

### Meaning newly emergent from the combination

次の要約は三カードを一緒に見たときに自然に立つが、一枚にそのまま書かれてはいない。

> **圧力を下げることと、責任の焦点を失うことは同じではない。**

これは後のC3287「低抵抗 ≠ 低責任」へ接続する有力なemergent meaningである。

### Meaning not supported by C2334-C2336 alone

現行C3287には、より広いKJ文脈から次が加わっている。

- 被害側へ赦しや理解を求めない。
- 善意を仮定しない。
- 信頼を先払いしない。
- 謝罪・開示・協力・停止・是正等の責任行為へ接続する。
- 情感表現は事実認定に代わらない。

これらは重要であり削るべきではないが、**C2334-C2336だけから継承された意味とは表示しない方がよい。** C2324、C2325-C2327、C2675、C3153、補論本文等との横断統合によって支えられた追加層として扱うのがより追跡可能である。

## A4. Comparison with current C3287

現行C3287は、C2334-C2336の三機能を失わず、さらに連載全体の責任・被害側尊厳・事実認定境界を組み込んだ、**局所核融合 + 横断統合**として成立している。

prototypeから見た重要な改善点は、C3287そのものを書き換えることではない。

> **融合カードの中で、元カードから直接継承した意味と、周辺カード／B型文章／監査から新しく統合された意味を区別できるようにする。**

これにより、後で融合カードだけを読んでも「どこまでが元三カードの核で、どこからが横断的に生じた意味か」を誤認しにくい。

## A5. Result

| Check | Current KJ result | New prototype | Observation |
|---|---|---|---|
| C2334 pressure/exit | preserved | preserved | equivalent |
| C2335 action focus | preserved | preserved | equivalent |
| C2336 time/self-distance | preserved | preserved | equivalent |
| temperature / rhetorical function | strongly preserved | preserved | current C3287 is richer |
| inherited vs emergent distinction | implicit | explicit | prototype advantage |
| broader responsibility safeguards | strong | not invented from 3 cards | current result appropriately uses wider context |
| overcompression | avoided | avoided | equivalent |
| source round-trip | possible via absorbed refs | explicit in procedure | prototype advantage in auditability |

### Case A decision

**PASS with one design improvement candidate:** fusion outputs should optionally record `inherited / emergent / residual` meaning, especially when a fused card later absorbs B型文章や別島の監査結果。

# Case B — 『ひとりぼっちの空』小集合

## B0. Input subset

原典像を早く「器」「境界」「癒やし」等へ概念化しないことを試すため、次を小さな局所場として読む。

- UKJ-047: 若者が去った砂の上で、霧のように薄い「寂しい」と一緒にしばらく横たわった。
- UKJ-052: 赤子は何かをしてほしいのではなく、「この場でじっとしていたい」と頼んだ。
- UKJ-053: 暗い空間は嫌なだけではなく、少し守られている感じも含んでいた。
- UKJ-054: 食卓で泣いた子どもは身体へ溶け込み、遊びたい、楽しくしたいという薄い動きが内側に残った。
- UKJ-055: うさぎは中心のテーブルへ立ちながら目と口を点のまま保ち、薄く張りつめていた。
- UKJ-057: 男の子らしい小さな子は頭をなでられると腰へしがみついたが、触れた手にはちくちくする感じが残った。
- UKJ-059: 夫婦の争いをたどった像では、温かいミルクが暗いがらんどうへ一滴ずつ溜まった。
- UKJ-063: 余白は無感覚ではなく、感じているものを埋めたり意味づけたりせず保持できる状態として描かれる。

この小集合だけから、現行114枚A型の「水／器」全体構造を再現することを目標にしない。

## B1. First grouping without names

### Near set α

UKJ-047 / UKJ-052 / UKJ-063

近さ:
- すぐに何かを変えない。
- 寂しさや感覚を消さず、その場に置いておく。
- 「してほしい」より「ここにいる」「保持する」が前景にある。

### Near set β

UKJ-053 / UKJ-057

近さ:
- 接近／保護は単純な安心ではない。
- 暗さの中の保護、しがみつきの中のちくちくという両義性が残る。

### Near set γ

UKJ-054 / UKJ-059

近さ:
- 強い状態をすぐ解決するのではなく、身体／暗い空洞の内側に、小さい温かさや遊びたい動きが残る・溜まる。

### Singleton δ

UKJ-055

うさぎは「中心へ立つ」と「薄く張りつめる」を同時に持ち、上の三集合へ安易に入れると、中心へ出る緊張という独自の具体が消えるため、現段階では単独に置く。

## B2. Labels after grouping

### α

> **何かを直すより先に、薄い感覚と一緒にその場にいられる時間がある。**

Return check:
- 「寂しい」と横たわる具体を保持。
- 赤子の「じっとしていたい」を保持。
- 余白を無感覚／空白と誤読しない。
- 「受容」「癒やし」という上位語へ逃げない。

### β

> **近づくことや守られることの中にも、嫌さやちくちくする感覚が一緒に残る。**

Return check:
- 暗い空間の嫌さを「安心」に消さない。
- しがみつきを「信頼」に昇格させない。
- 触れた手のちくちくを残す。

### γ

> **暗い／泣いていた内側には、すぐ満たし切らず、小さな温かさや遊びたい動きが少しずつ残っていく。**

Return check:
- ミルク一滴ずつの速度を残す。
- 子どもが身体へ溶ける像を単純な消滅にしない。
- 「回復した」と完成させない。

### δ

> **中心へ出ても、うさぎはまだ薄く張りつめている。**

単独表札として保持する。

## B3. Relational reading

この小集合から安全に言えるのは、因果鎖ではなく**反復して現れる運動の近さ**である。

```text
α 変えずに一緒にいる／保持する
   ├─ coexists with ─ β 近さの中の両義性
   └─ resonates with ─ γ 少量ずつ内側へ残る

δ 中心へ出るが張りつめる
   └─ unresolved relation to α / β
```

ここから「余白があるから温かさが入る」「守られると遊びたい気持ちが戻る」という因果はまだ作らない。

## B4. Narrative candidate

> この小さな材料群では、変えることや満たすことより前に、その場にとどまる像が何度か現れる。砂の上では薄い寂しさと横たわり、赤子は何かを求める代わりに「ここにいたい」と言う。暗い場所や身体の内側も、一義的な安全にはならない。守られる感じのそばに嫌さがあり、しがみつく身体に触れた手にはちくちくが残る。一方で、泣いた子どものあとには遊びたいという薄い動きが残り、暗いがらんどうには温かいミルクが一滴ずつ溜まる。ここでは、感じているものを早く別の意味へ変えずに置いておくことと、小さな変化が内側に残ることとが、まだ一つの因果にはならないまま近くに見えている。

## B5. Comparison with current 114-card structure

現行114枚A型では、より広い材料から「量を知る」「入口を持つ」「力を壊さず収める」「異なるものを異なるまま置く」「必要なら外へ流す」という器の構造が立っている。

この小集合だけでは、その全体表札まで到達しない。

しかし次の二点は、現行構造と整合する前段の材料運動として見える。

1. **異なる／両義的な感覚を一つへ均さず置く。**
2. **大きく満たすのでなく、小さい量・薄い動きが内側に残る。**

重要なのは、prototypeがここから先に「これは器である」と命名しなかったことである。`器` は114枚全体では材料から立ち上がった有力構造でも、この8枚だけの局所場ではまだ**後から照合できる候補語**に留まる。

## B6. Result

| Check | New prototype result |
|---|---|
| concrete scenes preserved | PASS |
| bodily/sensory temperature preserved | PASS |
| ambivalence preserved | PASS |
| singleton retained | PASS |
| premature `境界/器/癒やし` taxonomy avoided | PASS |
| narrative causality inflation avoided | PASS |
| compatible with larger current structure without forcing it | PASS |

### Case B decision

**PASS.**

創作材料では、現在の `affinity-synthesis` wordingは現行KJ運用の「土の匂い」を大きく損なっていない。特に、概念名を先に置かず、singletonと両義性を保持する点は有効に働く。

# Cross-case findings

## 1. Layer 1 separation appears viable

分析系と創作系の双方で、一回の材料統合に必要な核は `affinity-synthesis` 側だけで表現できた。

現行CSW固有の文化体系ルーティングを使わなくても、カード境界、核融合、表札、関係、叙述、戻し検査が閉じる。

これはLayer 1をCSWから独立させる設計を支持する。

## 2. The prototype should distinguish inherited / emergent / residual meaning

Case Aで最も重要な差分。

現行C3287のような成熟した融合カードは、元三カードだけでなく、関連カード・B型文章・逆機能監査を横断して成長する。

そのため、融合後に次を区別するとよい。

- **inherited**: 入力材料から直接保持した意味。
- **emergent**: 複数材料の接触で新しく立った意味。
- **residual**: 融合へ入れず残した差・違和感・未解決。

これはKJの創発を抑える分類ではない。**新しく生じた意味を、元材料が最初から言っていたことへ遡及させないための変換後監査**である。

## 3. Round history belongs outside Layer 1

Case AのC3287は、局所融合後にB型横断、逆機能監査、本文再投影へ進んでいる。

これらを一つのLayer 1 runへ押し込めるより、

```text
round N: C2334-C2336 → local fusion
round N+1: B型 / related cards → enrich fusion
round N+2: inverse-function audit
round N+3: project to article and back-check
```

のように、`iterative-inquiry-synthesis` が外から履歴を持つ方が、意味がどこで増えたかを追いやすい。

## 4. Current CSW runtime should still not be thinned yet

今回の比較は二ケースで有望だったが、同一modelによる再読であり、独立evaluationではない。

次のゲートを残す。

- larger-card-set evaluation
- actual Agent Skill router / progressive loading behavior
- English realization parity
- separation of runtime dependencies / fallback
- build and regression checks

## Decision

**Layer 1 prototype: continue toward independent Skill.**

**Layer 2 prototype: continue as separate orchestration Skill.**

**CSW `src/` reduction: defer until at least one larger-card-set paired run and packaging/dependency design are complete.**
