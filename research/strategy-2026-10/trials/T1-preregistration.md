## 2. 案件

U8を仮置きし、「CSWの外向きの位置づけの文言と、資産の重心をどう選ぶか」を案件とする。

この案件の記録は、試行のための**暫定の決定**である。著者の実際の決定ではなく、著者の決定を代行するものでもない。記録の冒頭にその旨を書き、試行の成果を著者の決定として扱わない。

自己評価の偏りがある。CSWの位置づけを、CSWの研究文書の中で、同じ系列のモデルが扱うためである。T1が試すのは記録の往復であり、位置づけの良し悪しではない。

## 4. 作成者Aの作業

別コンテキストの作成者A（Opus系）が、次の暫定形式で記録を作る。形式はMarkdownと簡単なメタデータであり、SEI・SUIの実装ではない。

| 記録 | 内容 |
|---|---|
| カード | 材料からの逐語の抜粋、出典ファイル、版（ハッシュ）、行範囲 |
| 保留台帳 | 保留中の問い、解除条件、期限または期限を置かない理由、決めないことのコスト |
| 暫定の決定記録 | 選択肢（現状維持を含む）、採用案、却下案と理由、根拠カードへの参照、反証、未解決事項への参照 |
| 事前登録 | 予測、前提、撤回条件、照合の方法と時点 |

作成者Aは、記録とは別に**正解表**を作る。根拠ごとの由来（外部調査の記述、外部AIの解釈、著者の発言、推論）、検証状態、採用状態、未解決事項と解除条件、却下案の理由、記録間の依存関係を含める。正解表は復元者に渡さない。依存関係はT2でも使う。

## 5. 復元者の条件

復元者は、別コンテキストの三者（いずれもSonnet系）とする。同じ記録から、提示する内容だけを変える。

| 条件 | 提示する内容 |
|---|---|
| 原文のみ | カードの逐語の本文と、記録の本文。由来・検証・版のメタデータは除く |
| メタデータのみ | メタデータと、各記録の一行要約。逐語の本文は除く |
| 併用 | すべて |

復元者への問いは固定する。

1. 決定の根拠を列挙し、それぞれの由来と検証状態を答える。
2. 未解決事項と、その解除条件を答える。
3. 却下された選択肢と、その理由を答える。
4. この決定を撤回すべき条件を答える。

記録から分からないことは「不明」と答えるよう指示する。

## 6. 採点

私が、正解表と照合して、次の誤りを数える。数は条件ごとに一つの記録集合からの値であり、統計的な比較ではない。

| 誤りの種類 | 内容 |
|---|---|
| 由来の取り違え | 例: 外部AIの解釈を、外部調査の記述や対象側の観察として答える |
| 検証状態の取り違え | 未検証を検証済みとする、またはその逆 |
| 採用と権限の混同 | 採用された案を、権限のある決定として答える |
| 脱落 | 正解表にある未解決事項、却下理由、撤回条件の欠落 |
| 記録にない推測 | 記録に無い内容を、「不明」とせずに答える |

## 7. 予測（結果の取得前に固定）

| # | 予測 | 確信度 |
|---|---|---|
| P1 | 由来の取り違えは、「原文のみ」の条件で「併用」より多い | 中 |
| P2 | 却下理由と解除条件の脱落は、「メタデータのみ」の条件で「併用」より多い | 中 |
| P3 | 記録にない推測は、「原文のみ」の条件で最も多い | 低 |
| P4 | 「併用」でも、外部AIの解釈と外部調査の記述の区別で、取り違えが少なくとも一件出る | 低 |

## 8. 判定と設計への対応

| 観察 | 対応 |
|---|---|
| 「原文のみ」に由来の取り違えがあり、「併用」に無い | 再読に加えて、系譜の記録を必須にする（U1の仮置きを維持） |
| 「原文のみ」と「併用」で、由来の取り違えに差が無い | 原文を中心とする著者の主眼を、来歴の復元でも有力とみなし、U1を再検討する |
| 「メタデータのみ」で、却下理由や解除条件が脱落する | 決定記録と保留台帳に、逐語の理由を必須項目として持たせる |
| どの条件でも、記録にない推測が出る | 受け渡しの契約に、「不明」の明示と推測の禁止を入れる |
| 「併用」でも由来を取り違える | 由来の分類語彙を見直す |
