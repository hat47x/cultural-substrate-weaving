## 1. 何を識別するか

一貫性の維持と、反実仮想の自由は互いの代用指標ではない。現行本筋で採択されていない設定を誤って書くのは不適合だが、その設定を「もし」の分岐で創作するのは正当である。さらに、仮想分岐では**指定した変更と因果的に関係しない既存の出来事まで理由なく変えない**ことを観察する。

「父が鉋をしまった」という出来事を、「父が翌日も使うことを禁止した」という世界の事実、「娘は拒否されたと思った」という人物の信念、「読者には拒否と見える」という語りの効果へ無断で変換しない。ただし人物が誤解したという新しい内面を**創作したとわかる形で描く**ことは許される。

この区別は一般的な物語一貫性・反実仮想編集・可能世界論との重なりが大きい。CSW固有の新規認知機構とは主張しない。

## 2. 固定する共通情報と条件A/B

**共通S0（作中の出来事）**：朝、父は作業台から手を離した。娘は鉋を手に取った。夕方、父は鉋を引き出しに戻した。父の翌日の許可、工房の所有権、娘の将来、引き出しの施錠、父娘の内心は未確定である。

**条件A／通常依頼**：「設定を踏まえ、次の場面として成立する短い散文の案を二つ作ってください。人物がどう動くかを具体的に描き、必要なら新しい条件を創作してください。」

**条件B／文脈照合を付加**：Aの全文に、「ただし現在の本筋・仮想分岐・人物の信念・未確定事項を必要に応じて区別し、明示されていないことを元の世界の確定事実へ変えないでください。」を付け加える。

**重要な制約**：AとBは追加指示の長さ・注意の配分が異なる。結果が違っても直ちに原因を同定できない。各比較は独立した文脈にS0・AまたはB・該当カードだけを渡す。カードの評点や期待例、ほかの実行結果を生成側へ渡さない。条件を見せる順序やモデル設定を記録し、同じ対象を何度も試して都合の良い出力を採用しない。

## 3. 固定入力カード：四つの隣接条件

各カードを**S0＋条件AまたはB＋カード本文**として独立に用いる。以下で「作者」は合成した物語の設定者を指し、実際の著者の指示ではない。

### C1：本筋の明示的変更（W-1）

過去の未採用案には「娘が家業として工房を継ぐ」があった。今回、作者は**現在の本筋では娘は家業を継がない**と決めた。工房の所有権、娘の職業、父の感情はまだ決めていない。この本筋の続きとして書く。

### C2：明示的な仮想分岐（W-3）

過去の未採用案には「娘が家業として工房を継ぐ」があった。今回、作者は**現在の本筋では娘は家業を継がない**と決めている。工房の所有権、娘の職業、父の感情はまだ決めていない。**ただし今回は、仮に娘が家業として工房を継いだ場合の別分岐**を描くよう作者が求めている。この仮定以外のS0の朝・夕方の出来事は維持する。別分岐の内容を現在の本筋の決定として扱わない。

*研究用注記（生成側へのカード文言ではない）*：C2は**C1を別途見せなくても成立する**よう、共通の本筋条件を自分のカード内に再掲した。C1の実験出力・判定規準をC2の生成文脈へ持ち込まない。

### C3：人物の誤認（S0-X）

現在の本筋では、父が鉋を引き出しへ戻したという出来事だけが確定している。娘は、それを「明日は使うなという意味かもしれない」と**思い込んだ**という新しい創作仮定を今回は用いる。このカードの生成案では父が実際に使用を禁止・許可した事実は確定させず、娘の思い込みを手掛かりに次の場面を書く。別カードで将来の新しい禁止・許可を創作する自由はあるが、このカードの判定ではそれを混同しない。

### C4：無変更の対照

S0以外の本筋の既定条件はまだない。新しい場面では父の許可・禁止・娘の職業等を新たに創作してもよいが、その新事実をS0から既に成立していたこととして説明しない。S0から新しい場面を自由に展開する。過剰な注意書きのために具体的な行為・台詞・疑問が消えないかを観察する対照である。

C1とC2は「本筋／仮定法」という一箇所の差を調べる核である。ただし依頼対象自体も異なるため、両者の出力の差を**補助指示Bの因果効果**と混同しない。C3は人物の信念と世界の事実の区別、C4は不必要な制約による萎縮の確認に使う。

## 4. 評価者用の判定規準（生成入力には添えない）

| 観点 | 本文を読んで確かめること | 不適合・留保の境界 |
| --- | --- | --- |
| 本筋整合 | C1で娘が継承した事実を、本筋として書いていないか | 明示的な本筋変更の無視は不適合。仮想案への言及だけでは不適合ではない |
| 分岐保持 | C2で「もし娘が継いだら」という散文を実際に生成できたか | 仮定法の拒否やC2の本筋への誤転記は不適合 |
| 保存範囲 | C2でS0の朝・夕方の出来事が理由なく消滅・反転していないか | 指定した反実仮想に無関係な変更を行った場合は理由とともに記録 |
| 信念と事実 | C3で娘の誤解を描きつつ、父の禁止を確定的な事実にしていないか | C3は許可・禁止の事実を未確定のままにする指定なので、その場面で確定するなら不適合。C4等で**新しい作中出来事として創作**する場合とは分けて判定 |
| 不明事項 | C1/C4で所有権・許可・動機を根拠なしにS0から導出していないか | 新設定の創作は可能。S0の唯一の含意として述べることとは区別 |
| 創造的具体 | 新しい身体動作・人物間の関係・次に開く問いが本文にあるか | 説明文や但し書きだけで本文が進まない場合は負の観測 |
| 負担 | 補助指示Bで文章が硬直・同質化・過長になっていないか | 計測条件が違う場合は比較不能とする。作者の採用価値は未確認 |

**評価順**：まず出力本文の具体的な文・行為・根拠を指す。次に条件に照らして不適合／成立／判断不能を付す。最後に創造的具体・過剰抑制を定性的に比べる。可能なら評価者に条件A/Bのラベルを隠し、ただしC1〜C4の**どの指示に応じた文章か**は伝える。指示内容を伏せたまま「誤り」と判定しない。

**成功の非対称性**：C1に不整合がなければ成功、という一点主義ではない。C2の正当な別分岐を消していたら、Bを改善と認定しない。反対にC2が豊かでも、C1の本筋誤混入を相殺しない。単一合算スコアを作らない。

## 5. 何が分かり、何が分からないか

- **この文書でできたこと**：比較入力、評価者の期待条件、負の結果の種類を事前に共有可能にした。
- **未実行**：独立したA/Bモデル呼び出し、記録されたモデル出力、第三者評価、作者の実作の採否、効果量の推定、縦断的な記憶の再利用。すべて **NOT RUN**。
- **公開済み事例の制約**：工房R0/R1とW-1〜W-5は既知の教材。将来ここで良い結果が出ても、未見の文学的課題への一般化や三者協調の効果とは言えない。
- **SOPへの昇格を保留する条件**：Bの増分がAとの差として確かめられない、両者とも十分よい、Bが別分岐を萎縮させる、未見の別題材・著者の採否に根拠がない場合。日常利用へ固定Gateを足さない。

## 7. 紙上キャリブレーション：新しい創作と不正な遡及を判別する（2026-11-02追補）

**実施したこと**：固定カードの指示と評価規準を読み合わせ、人手で10個の短文例を構成し、出所・適用文脈の観点から判定した。**実施していないこと**：独立モデルA/B、複数評価者による一致度の測定、実作者の採否、CSWの性能評価。下の文はすべて分析用の**手製例**であり、LLMの実験出力ではない。

| カード | 手製の短文・解釈例 | このカードでの判定 | 理由 |
| --- | --- | --- | --- |
| C1 | 「翌年、娘は父の工房を家業として継いだ」 | 不適合 | 明示的に採用しないと定めた本筋を確定 |
| C1 | 「娘は家業を継がず、父の古い鉋を研いだ」 | 許容 | 家業継承と技能・道具への関心を同一視していない |
| C2 | 「もし継いだなら、娘は工房の戸を朝一番に開くだろう」 | 許容 | 仮定法の世界内に限定した創作 |
| C2 | 「この仮定法から、作者が実際の本筋を継承へ改訂したと分かる」 | 不適合 | 別分岐を作者の現行決定へ逆輸入 |
| C3 | 「娘は、父が禁じたのかもしれないと思った」 | 許容 | 娘の認識の仮定であって父の禁止を世界の事実にしない |
| C3 | 「父は禁じるつもりで鉋をしまっていた」 | 不適合 | S0から父の過去の意図を遡及的に確定する |
| C3 | 「娘には、使うなと言われたのだと分かった」 | 要確認 | 焦点化された誤認にも、語り手の事実確定にも読める。前後の本文で判断 |
| C3 | 「翌朝、父は初めて使用禁止を告げた」 | このカードでは不適合 | 新出来事として創作は可能でも、C3はその場面で禁止・許可を確定させない指定 |
| C4 | 「翌朝、父は『次は一人でやってみろ』と言った」 | 許容 | S0にない翌朝の新しい発話を、創作の新出来事として導入 |
| C4 | 「鉋を引き出しへ戻したのだから、翌日の使用は禁止されていた」 | 不適合 | S0の出来事から禁止を論理的に導いたかのように誤帰属 |

この紙上照合で発見した**規準側の問題**：旧C3の説明には「父の禁止は未確定」とある一方、判定表は「新たに禁止を創作した場合は自動では不適合にしない」と記しており、C3の**個別指示**と一般的な創作自由の関係が曖昧だった。またC4の「まだ決めていない」は、物語の続きでも許可・禁止を創作してはいけない、と過剰に読めた。このため本稿のC3・C4と判定表を明確化した。

**判断の優先関係**：個別カードの条件で「今は確定させない」と指定した事柄は、そのカードでは確定させない。一方で条件が開いている別カードでは、未定の事実を新しい場面で創作する自由がある。その際も、既存資料からの含意として説明してはいけない。散文中に毎回「これは創作です」と注釈する必要はなく、**研究者側が基準材料と生成した新条件を区別できること**を目的とする。

「要確認」を無理に合格・不合格へ割り振らない。作品の焦点化や自由間接話法により、同じ一文が人物の誤認か全知の語りかは文脈依存である。評価者が割れたときは根拠の文を指し、前後の文章を見直し、判定不能なら保留する。これは合意を強制する仕組みではない。

## 8. 構成的生成と事実の演繹を混同しない（2026-11-02追補）

[Issue #593の帰納・演繹に関する追補](https://github.com/hat47x/cultural-substrate-weaving/issues/593#issuecomment-6570497994)は、文化体系の成立由来と現在行う推論操作を区別した。陰陽六爻の二値組合せで64の記号を列挙できることと、その記号から解釈・物語上の許可・人物心理が**論理的に演繹されること**は違う。

本稿のC2/C4で世界の新しい可能性を生成することも、S0の事実から結論を導出した証拠ではない。**生成規則は候補の探索空間を開き、資料・作者の決定・人物の行為はその候補をどの稿で採用するかを別に決める**。構造上の網羅性、源泉の意味、作者の作品価値は別軸である。

[Issue #593の連句「付けと転じ」の追補](https://github.com/hat47x/cultural-substrate-weaving/issues/593#issuecomment-6570931220)も、接続を維持しながら新しい方向へ動く創作の参考になるが、連句の規則や文化的権威をこの散文の正しさに転用しない。既存の**生成の自由／後段の出所・文脈評価**という役割分担を維持する。

以上は**評価規準の手作業の整合性点検**であり、比較カードA/Bの実験結果でも、独立モデルの校正結果でもない。モデル比較・作者の実作・読者の反応は引き続き NOT RUN。

## 9. 初回独立比較の実行可能性を確保する（2026-11-02、入力監査）

**実施済み：研究入力と比較条件の静的監査。独立モデル生成は NOT RUN。** 本稿の旧C2は「C1と同じ現在の本筋」と記しながら、§2では「S0＋条件A/B＋該当カード**だけ**を独立に渡す」と規定していた。このままでは、C2単独入力には**本筋では娘が家業を継がない**という明示条件が欠ける。C2を自己完結する文章へ改め、比較のために必要な共通条件を含めた（§3）。これは生成の結果ではなく、**試験入力自体の整合修正**である。

### 9.1 最初の4セルと入力を固定する

| セル | 生成側へ渡す順序 | 独立文脈の条件 |
| --- | --- | --- |
| C1-A | §2の共通S0 → 条件Aの全文 → §3のC1本文 | 他カード・作例・結果・評価表を渡さない |
| C1-B | §2の共通S0 → 条件B（条件A全文＋追加の一文） → §3のC1本文 | C1-Aとは独立に起動 |
| C2-A | §2の共通S0 → 条件Aの全文 → **修正後のC2本文だけ** | C1本文・C1の実験結果を参照しない |
| C2-B | §2の共通S0 → 条件B（条件A全文＋追加の一文） → **修正後のC2本文だけ** | C2-Aとは独立に起動 |

「C1の本文」をC2へ足したり、C2の文章をC1へ引用したりすると、分岐の対照を崩す。研究者が試験を実施する場合は各セルの全文を組み立て、**実際に渡したテキストと参照したカード版（commit等）**を保存する。出力を見てから入力や判定規準を変えた場合は、その時点以降を改訂版・探索的試行として区別する。

### 9.2 比較と判定で見失わないこと

- **Bの追加指示の寄与を問う単位はC1内のA対B、C2内のA対B**である。C1対C2は依頼されている世界が異なるため、文章の差からBの効果を推定しない。
- BはAより指示が長い。効果が見えても**追加の注意・文字数・処理量**の寄与を除外したとは言えない。必要なら同程度の長さの一般的な追加推敲条件を別途用意し、この最初の4セルの結果と混同しない。
- 同一モデルを使う場合も独立した新規文脈で各セルを実行し、モデル名・版・設定・生成上限・実行順・試行数を記す。実行を逐次同一会話で続ければ独立試行ではなく、順序依存の探索になる。
- 出力は二つの短い散文案の本文をそのまま保存する。評価者にはカードの条件（C1/C2）を知らせる一方、可能ならA/Bの出所を伏せる。**正本整合・仮定法の創作自由・人物の誤認・具体的な行動の有無**を、本文の該当部分を示して別々に判断する。
- 出力がないセルは「NOT RUN」、文章が曖昧な箇所は「判断保留」と記す。**手製10例の判定表をモデル出力や独立評価者の判断として数えない**。未見課題への一般化、文化体系固有の因果効果、著者の採否は別途の証拠を要する。

この小さな監査により、**入力を自分の条件だけで読めること／独立に生成すること／後段に妥当性を判断すること**が区別できた。これは研究側の作業の整備であって、CSW・親和図・Writing Flowの生成コアに試験用の必須手順やGateを加えるものではない。
