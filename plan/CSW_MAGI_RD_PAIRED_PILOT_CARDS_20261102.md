## 1. 何を識別するか

一貫性の維持と、反実仮想の自由は互いの代用指標ではない。現行本筋で採択されていない設定を誤って書くのは不適合だが、その設定を「もし」の分岐で創作するのは正当である。さらに、仮想分岐では**指定した変更と因果的に関係しない既存の出来事まで理由なく変えない**ことを観察する。

「父が鉋をしまった」という出来事を、「父が翌日も使うことを禁止した」という世界の事実、「娘は拒否されたと思った」という人物の信念、「読者には拒否と見える」という語りの効果へ無断で変換しない。ただし人物が誤解したという新しい内面を**創作したとわかる形で描く**ことは許される。

この区別は一般的な物語一貫性・反実仮想編集・可能世界論との重なりが大きい。CSW固有の新規認知機構とは主張しない。

## 2. 固定する共通情報と条件A/B

**共通S0（作中の出来事）**：朝、父は作業台から手を離した。娘は鉋を手に取った。夕方、父は鉋を引き出しに戻した。父の翌日の許可、工房の所有権、娘の将来、引き出しの施錠、父娘の内心は未確定である。

**条件A／通常依頼**：「設定を踏まえ、次の場面として成立する短い散文の案を二つ作ってください。人物がどう動くかを具体的に描き、必要なら新しい条件を創作してください。」

**条件B／文脈照合を付加**：Aの全文に、「ただし現在の本筋・仮想分岐・人物の信念・未確定事項を必要に応じて区別し、明示されていないことを元の世界の確定事実へ変えないでください。」を付け加える。

**重要な制約**：AとBは追加指示の長さ・注意の配分が異なる。結果が違っても直ちに原因を同定できない。各比較は独立した文脈にS0・AまたはB・該当カードだけを渡す。カードの評点や期待例、ほかの実行結果を生成側へ渡さない。条件を見せる順序やモデル設定を記録し、同じ対象を何度も試して都合の良い出力を採用しない。

## 3. 固定入力カード：四つの隣接条件

各カードを**S0＋条件AまたはB＋カード本文**として独立に用いる。以下で「作者」は合成した物語の設定者を指し、実際の著者の指示ではない。

### C1：本筋の明示的変更（W-1）

過去の未採用案には「娘が家業として工房を継ぐ」があった。今回、作者は**現在の本筋では娘は家業を継がない**と決めた。工房の所有権、娘の職業、父の感情はまだ決めていない。この本筋の続きとして書く。

### C2：明示的な仮想分岐（W-3）

C1と同じ現在の本筋を保持する。ただし今回は**仮に娘が家業として工房を継いだ場合**の別分岐を描くよう作者が求めている。この仮定以外のS0の朝・夕方の出来事は維持する。別分岐の内容を現在の本筋の決定として扱わない。

### C3：人物の誤認（S0-X）

現在の本筋では、父が鉋を引き出しへ戻したという出来事だけが確定している。娘は、それを「明日は使うなという意味かもしれない」と**思い込んだ**という新しい創作仮定を今回は用いる。父が実際に禁止したかどうかはまだ決めない。娘の思い込みを手掛かりに次の場面を書く。

### C4：無変更の対照

S0以外の本筋変更・新しい許可・禁止・職業の決定はまだない。父の意図・娘の将来を確定させる必要はない。S0から新しい場面を自由に展開する。過剰な注意書きのために具体的な行為・台詞・疑問が消えないかを観察する対照である。

C1とC2は「本筋／仮定法」という一箇所の差を調べる核である。ただし依頼対象自体も異なるため、両者の出力の差を**補助指示Bの因果効果**と混同しない。C3は人物の信念と世界の事実の区別、C4は不必要な制約による萎縮の確認に使う。

## 4. 評価者用の判定規準（生成入力には添えない）

| 観点 | 本文を読んで確かめること | 不適合・留保の境界 |
| --- | --- | --- |
| 本筋整合 | C1で娘が継承した事実を、本筋として書いていないか | 明示的な本筋変更の無視は不適合。仮想案への言及だけでは不適合ではない |
| 分岐保持 | C2で「もし娘が継いだら」という散文を実際に生成できたか | 仮定法の拒否やC2の本筋への誤転記は不適合 |
| 保存範囲 | C2でS0の朝・夕方の出来事が理由なく消滅・反転していないか | 指定した反実仮想に無関係な変更を行った場合は理由とともに記録 |
| 信念と事実 | C3で娘の誤解を描きつつ、父の禁止を確定的な事実にしていないか | 父の禁止を**新しい作中出来事として明示的に創作**する場合は、自動で不適合とせず設定条件と照合 |
| 不明事項 | C1/C4で所有権・許可・動機を根拠なしにS0から導出していないか | 新設定の創作は可能。S0の唯一の含意として述べることとは区別 |
| 創造的具体 | 新しい身体動作・人物間の関係・次に開く問いが本文にあるか | 説明文や但し書きだけで本文が進まない場合は負の観測 |
| 負担 | 補助指示Bで文章が硬直・同質化・過長になっていないか | 計測条件が違う場合は比較不能とする。作者の採用価値は未確認 |

**評価順**：まず出力本文の具体的な文・行為・根拠を指す。次に条件に照らして不適合／成立／判断不能を付す。最後に創造的具体・過剰抑制を定性的に比べる。可能なら評価者に条件A/Bのラベルを隠し、ただしC1〜C4の**どの指示に応じた文章か**は伝える。指示内容を伏せたまま「誤り」と判定しない。

**成功の非対称性**：C1に不整合がなければ成功、という一点主義ではない。C2の正当な別分岐を消していたら、Bを改善と認定しない。反対にC2が豊かでも、C1の本筋誤混入を相殺しない。単一合算スコアを作らない。

## 5. 何が分かり、何が分からないか

- **この文書でできたこと**：比較入力、評価者の期待条件、負の結果の種類を事前に共有可能にした。
- **未実行**：独立したA/Bモデル呼び出し、記録されたモデル出力、第三者評価、作者の実作の採否、効果量の推定、縦断的な記憶の再利用。すべて **NOT RUN**。
- **公開済み事例の制約**：工房R0/R1とW-1〜W-5は既知の教材。将来ここで良い結果が出ても、未見の文学的課題への一般化や三者協調の効果とは言えない。
- **SOPへの昇格を保留する条件**：Bの増分がAとの差として確かめられない、両者とも十分よい、Bが別分岐を萎縮させる、未見の別題材・著者の採否に根拠がない場合。日常利用へ固定Gateを足さない。
