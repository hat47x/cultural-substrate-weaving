## 1. なぜこのスナップショットを保存するか

C2が以前「C1と同じ条件」を参照していたため、各セルを別コンテキストへ単独で渡すと本筋が伝わらない問題を修正した。今回、**S0＋A/B＋対応カード**を各セルへ展開し、実際に渡す文字列を固定した。後続の実験で原カードを改訂した場合、この入力を**旧版の試行から黙って置換せず、別の版として**明示する。

**試行単位**：独立した文脈で一度生成した結果を**1 run**と扱う。依頼は「散文案を二つ」であり、同じ応答に含まれる二案は相関し得るため**2 independent runsとは数えない**。最初の四セルを1回ずつ実行しても、得られるのは探索的な小試行であり、推定された一般的な効果ではない。

## 3. 生成後の観察と記録（生成側へ渡さない）

各セルで最低限、実際の**入力全文、応答全文、使用したモデルと版・設定、各セルの実行時刻と順序、独立コンテキストであったか、生成失敗時の取扱い**を必要な範囲で記録する。研究者が観察結果を見る前に入力を変更した場合は、その条件に相応しいスナップショットを使う。未実行なら明示的に **NOT RUN** とする。

- 判定者はまずC1/C2どちらの本筋・仮想分岐の依頼だったかを知り、二つの散文案**両方**について、事実の逆流、仮定法としての創作の可否、元S0の事実の維持、新しい動作・台詞・関係、余白の保持を確認する。A/Bラベルは可能なら伏せ、同じ回答から都合のよい案だけを選ばない。
- C1-A対C1-B、C2-A対C2-Bをそれぞれ比較する。C1対C2の差は依頼された世界自体の差を含むため、Bの有効性を直接示さない。BはAより指示文が長くなるため、注意喚起・文字数・生成予算の差も交絡になり得る。
- 「Bで本文が慎重になった」という観測は、既存の条件を守ったという正の観点と、未確定の事柄を創作する自由を縮めたかもしれない負の観点の両方から読む。作品上の新しい出来事と、過去の事実を勝手に演繹した断定を分ける。
- 判定者が複数いる場合は、作品本文の根拠部分と**判断保留**を残す。AI自身の評点や手製10例は独立評価ではない。独立の再現・著者採否・実作品での価値は別途の証拠とする。
