# CSW 三役協調・継続改善構想（計画案）

- 状態: **計画案 / 未実装 / 設計検討継続**
- 作成日: 2026-10-26
- 位置づけ: 執筆向けCSWの将来協調方式を検討する計画文書。現行の3つの `skills/*/SKILL.md` を置き換えない。
- 仮称: **CSW-MAGI**。作品『新世紀エヴァンゲリオン』の三者合議に着想を得た呼称であり、正式名称・対外表記は未決。
- 適用範囲: 当面は執筆での文化的体系の交差・創造・検証・統合を扱う。執筆以外への一般化は将来の仮説であり、今回の導入対象にはしない。

## 1. 背景と目的

旧版のCSWでは「探索 → 検証 → 変換」の反復、四評価観点（対象固有性・可視性・生成性・非競合性）と五つの必須制約が整理されていた。これらは本構想の参考となるが、現行 `skills/cultural-substrate-weaving/SKILL.md` の規則と同一ではない。現行版は著者の意図、原稿への還元、体系固有の意味、着想と事実の区別を重視する。本計画はその稼働手順を変更しない。

一方、探索の内部に批評・採否を早期に持ち込むと、異質な発想を生み出す余地を狭める可能性がある。そこで、認知的役割を論理的に分離し、協調の規範で結合する。役割ごとの自律的な改善と、横断的な三者鼎談によって、成果と創造方法の両方を進化させる。

**主目的**: 独立性を維持した三者が共通目的に協調し、発想の多様性、建設的な批評、創造的統合、知見の蓄積を実現する。

## 現行の3 Skillと、提案する三役の関係

現行リポジトリは、`skills/cultural-substrate-weaving/`、`skills/affinity-synthesis/`、`skills/writing-flow/` の3つの独立した執筆向けSkillを持つ。**これは本計画の「生成者・批評者・媒介者」という三役と一対一対応する構成ではない。**

- 文化的体系の探索は、現行CSWが担当する。本計画の「生成者」はその能力を生かす役割の候補であり、直ちに独立Skillを追加する指示ではない。
- 親和的な束ね・表札・関係図・元材料への戻し検査は、現行 `affinity-synthesis` の責任である。媒介者がKJ法を選択しても、その内部手順をCSW側に再実装しない。
- 執筆の進行、必要な方法の切替えは現行 `writing-flow` が担う。媒介者に似た面はあるが、三者合議の進行やSOPの保守が実装済みという意味ではない。
- 「批評者」は横断的な認知的役割の案であり、現行リポジトリに対応する独立Skillがあるとは主張しない。
- 三者合議・記憶・自動手順改訂の実装も未存在である。どのSkillまたは呼出し側が担うかは未決とする。

現行の「必要な方法だけ使う」「固定順序・記録書式を必須にしない」という原則を守る。実際の作品・原稿への効果は、著者の評価と具体的な変更に基づいて確かめる。

## 2. 三役と責任境界

| 役割 | 主責任 | 許される横断的貢献 | 越えてはならない境界 |
|---|---|---|---|
| Generator（生成者） | 文化的体系の内部論理、象徴、偶然性、類推を利用した自由探索・体系の交差・再発想 | 批評に応答し論理的改善も行う | 自説防衛を目的にしない。仮説を検証済み事実として提示しない |
| Critic（批評者） | 根拠、対応関係、反例、文脈、適用限界の分析と**建設的改善提案** | 文化的体系の組合せ方、抽象階層の切り分け等について新案を提起 | 単なる棄却や早期の発想封殺を使命としない。議論の採否を独占しない |
| Mediator（媒介者） | 問題領域に応じた方法選定、双方の意見聴取、進行、構造化、創造的統合、記録・レビュー設計 | 自身も仮説を提案し、KJ法以外の方法を設計・組み合わせる | 手続的決定権を事実の真偽やユーザーの最終採否判断と混同しない |

「右脳的」「左脳的」は認知的役割の比喩であり、神経科学上の左右脳分業の主張ではない。**認知能力は共有し、責任を分離する**。役割の独立は、硬直した立場の擁護を意味しない。

## 3. 協調契約（論理仕様）

1. **共通目的を優先**: 自説の勝利・他役割への優越より、対象にとっての成果を目指す。
2. **批評は主張に向ける**: 反証・疑義は具体的な仮説、証拠、適用条件に対して行い、相手の能力や役割を否定しない。
3. **建設的な改善**: 可能な範囲で問題指摘に代替案・修正方向・識別条件を添える。改善案が得られないことだけを理由に重要な誤りを黙認しない。
4. **立場より役割に忠実**: 生成者は仮説に固執しない。批評者は否定に固執しない。媒介者は当初選んだ方式に固執しない。
5. **盲目的合意を拒む**: 協調は迎合でなく、根拠のある異論・未解決の緊張を保持する。
6. **初期独立性を確保**: 必要に応じ、生成と批評観点の初期形成を独立させ、後に相互参照を解禁する。具体的な隔離機構は未決。
7. **説明可能な進行**: 媒介者は生成者・批評者から方式に対する意見を聴いた上で自身の責任で決定し、採用理由、変更条件を記録する。
8. **採否の境界**: 媒介者は手順を決めるが、真偽は証拠で検討し、成果物の最終採否はユーザー・対象領域の責任者に委ねる。

## 4. 媒介・三者鼎談の実行モデル

### 4.1 動的ファシリテーション

媒介者は課題の性質に応じて KJ法・親和図、形態分析、対応関係マッピング、弁証法的対話、システム思考、シナリオ比較等を選択・組み合わせる。KJ法は重要な候補であって唯一の方式ではない。標準が未定義なら、媒介者が暫定方式を規定して試行する。

### 4.2 協調モード（候補）

- Solo: 短い探索または確認。
- Review: 生成案に対する建設的批評。
- Iterative: 生成・批評・再生成を反復。
- KJ Synthesis: 多数の着想・異論を関係づけて新しい構造を発見。
- Triadic Deliberation（三者鼎談）: 三者が前提・交差方法・矛盾・手続を深く議論。
- Method Research: 方法論自体の改善を主目的にする。

重要なテーマ、特に「文化的体系をどのように効果的に交差させるか」は三者鼎談の優先候補とする。媒介者は議題、方式、深度、終了・再開を決める。第三者的立場の維持とは、無色の折衷を意味しない。対立の保持、新概念の生成、解消不能な問いの保存も正当な結果となる。

### 4.3 二つの循環

- **対象についての創造**: 問題を解くための探索・批評・統合。
- **方法についての創造**: 交差技法、手順、三者の協調様式そのものを振り返り改良。

個別問題のたびに全面的な方法論討議を強制しない。イベント駆動および一定の蓄積後のレビューを使い分ける。

## 5. 各役割の初期標準手順（SOP v0.1 提案）

### Generator

1. 対象と目的を把握するが、最初から可能性空間を過度に絞らない。
2. 文化的体系の内部構造、象徴、異質性から複数の連想・交差仮説を生成する。
3. 初期生成案では事実・比喩・占断的発想の性格を区別し、採否判断は早急に行わない。
4. 批評者の指摘を新たな探索材料として利用し、改案と別案を生成する。
5. 良い成果について本質・生成機構の競合仮説を発想し、発想を阻害した条件も記録する。

### Critic

1. 対象の事実、目的、意図、領域条件、採用上の必須制約を確認する。
2. 生成案の有効な部分と、根拠に欠ける部分を分ける。
3. 体系間の意味対応、抽象階層、飛躍、代替説明、負例を検討する。
4. 棄却だけでなく、組合せの改善方法・追加観察・識別試行を提案する。
5. 批評が成果を良くしたかを振り返り、過剰抑制や迎合を検出する。

### Mediator

1. 問題の目的、制約、評価すべき価値を明確にする。
2. 二者から進行方式に関する意見を聴き、自ら方式と見直し条件を決定する。
3. 三者間の対話を進行し、必要なら鼎談を開く。結論を強制せず差異を保持する。
4. 成果、根拠、未解明の問いを構造化する。未規定の記録方法は暫定設計して試す。
5. 再利用候補と SOP 改善案を整理し、役割別改訂と三者レビューを調整する。

三つの SOP は役割別の所有物として改善し、相互作用への影響がある変更を三者鼎談でレビューする。人間・生成AIによるレビューを許容し、版・根拠・未解決異論を保全する。

## 6. 記憶・経験の蓄積（利用可能な場合）

永続記憶が使用可能な場合、次の論理領域を区別する。物理保存先と API は未決である。

1. **Episodic Memory**: 公開可能な入力参照、外部から観察できる提案・修正・異論・成果・評価、実行条件。モデルの非公開の内部推論を取得・保存することは想定しない。
2. **Pattern Memory**: 有効だった文化的交差方法、適用条件、反例、再利用優先度。
3. **Procedural Memory**: 各役割 SOP と共通協調契約の版、変更理由、レビュー、ロールバック条件。
4. **Insight Dossier**: 成果の本質に関する仮説、競合仮説、未知、何が分かれば理解が進むか、次の識別試行。

永続記憶がない場合はセッション内の一時記録や著者へ渡す成果物で代替する。原稿・私的メモ・個人情報は公開リポジトリへ保存しない。保存成功と次回の検索可能性は分けて確認する。保存していない知識を「学習済み」と呼ばない。

### 6.1 Insight Dossier の最小項目

- 観察された成果と評価者・評価観点。
- 何が価値を生んだかという本質仮説（単一の本質を前提としない）。
- 競合仮説・代替説明・反例・根拠と不確実性。
- 解明できていない事項と、必要な情報・観察・比較。
- 仮説を識別できる条件、次の試行、優先順位。
- 参照元の試行 ID、SOP の版、レビュー履歴、更新可能性。

「高成果・低理解」は重点探究対象とし、早期の一般規則化を避ける。事実としての試行記録、更新可能な解釈、改訂される手順を分ける。過去の解釈を上書きして証拠の来歴を失わない。

### 6.2 優先再利用と探索の自由

- 成功例の再利用は**条件付きの優先候補**とする。過去の成果が別問題でも最適であるとは断定しない。
- 探索の余地を残す。必要なら「過去記憶を使わない初期生成」と「記憶活用後の再探索」を比較する。
- 成果の再利用と SOP への標準昇格を分離する。
- 成功例だけでなく、失敗例・不適合条件・未解決の緊張も保存する。

### 6.3 昇格過程（仮）

`Observed`（試行） → `Candidate`（再利用候補） → `Validated`（追加検証） → `Promoted`（SOP へ昇格）。

各段階の閾値、承認権限、証拠要件は未決。否定的な追試が出れば降格・留保・撤回を可能にする。成功実績の数だけで一般化せず、領域差・比較対象・実行コストを検討する。

## 7. 評価の観点と負例

成果の良さと、その本質に対する理解度を分けて評価する。初期の評価観点は、発想の多様性、実際に得られた新しい関係、建設的批評の寄与、媒介による付加価値、異論の保持、転用可能性、実行負荷、再現性、継続改善の品質。旧版の四評価観点・五必須制約は参考として現行の著者意図・原稿保持の原則と再照合する。未採用の旧規則を、現在の必須要件として自動的に復元しない。

主要負例：

- **早期抑制**: 生成前に批評・制約が過剰に作用して新しい着想が消える。
- **否定合戦**: 批評者・生成者が自説の防衛に回り、改善しない。
- **迎合・偽の合意**: 相互に根拠なく賛同して見逃しが生じる。
- **偽の統合**: 媒介者が異質性を消し、平均的な折衷だけを出す。
- **過学習**: 過去の成功例だけを選び、探索が先細る。
- **根拠の格上げ**: 比喩や生成仮説が伝統・歴史・科学の確定的事実として扱われる。
- **記憶の誤認**: 保存や検索が未成功なのに継続学習済みと宣言する。

## 10. 交差機構の識別と検証設計（2026-10-27追補）

## 13. 相互変換の認定を保留できる研究設計（2026-10-29追補）
