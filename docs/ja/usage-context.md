# 呼ぶ側が用意するもの

## このスキルが提供する能力

cultural-substrate-weavingは、**文化的体系による構造候補の供給**と、**KJ法による断片統合・空白探索**を提供します。

本スキルは、執筆、経営、ソフトウェア開発、法務などに必要な専門知識や領域スキルを代替しません。専門的な正確性、品質基準、実装方法、成果物の形式は、呼ぶ側のコンテキストまたは併用する領域スキルで指定してください。

## 推奨する組み合わせ方

```text
【対象と材料】
（分析対象、資料、制約）

【領域側の基準線】
（専門スキルまたは通常手法でまず分析する）

【cultural-substrate-weavingの役割】
文化的体系とKJ法から、基準線になかった問い・関係・状態・遷移・空白を探索する。

【領域側の最終検証】
追加所見を専門知識・資料・規格・実務条件で検証する。
```

複数のスキルを使える環境では、領域固有スキルを外すのではなく、**領域スキル + cultural-substrate-weaving**として併用することを推奨します。

## 向いている問題

- 問題空間が開いており、到達点そのものがまだ定まっていない
- 異なる種類の材料、主体、時間、関係が絡み合っている
- 通常の分析が一つの筋へ収束しており、別の探索方向を加える価値がある
- 得られた候補を、対象側の資料や条件へ戻して検証できる

## 向いていない問題

- 正解や候補を列挙し尽くせる閉じた問題
- 単純な校正、翻訳、計算、形式変換
- 局所的なバグ修正や、既知の手順をそのまま実行する作業
- 対象側で仮説を検証する材料がない問題

## Taihekiについて

Taihekiは特例として残しています。人間が登場するという理由だけでは自動適用しません。明示的な指定がある場合、または身体的一貫性や緊張・弛緩時の反応そのものが探索対象である場合に、文化的・身体論的な外部類型として限定的に適用します。診断や人格上の事実としては扱いません。

## 効果検証について

公開済みのv0.4.0方法論を対象に、Web Chat Living Labで実作業を前向き（prospective）に観測しています。通常は、作業そのものを止めずに観測する`natural_work`を使います。方法変更の判断、確認された不利益の切り分け、重要な回帰確認など、より強い比較が必要になった場合だけ、`paired_check`で領域側の基準線とCSW併用側を比較します。

文化的体系を開かなかった場合は、`activation_scope: non_activation`として、そのラウンドで実際に起きた状態を記録します。それだけを根拠に、「使わない方がよかった」「有用だった」「害を避けた」とは判断しません。評価や解釈を残す必要がある場合は、観測された状態とは分け、誰がどの根拠からそう判断したのかを後からたどれる形で記録します。

公開観測はまだ限定的であり、現時点では本スキルの有効性が確立したとは扱いません。詳細は **[Web Chat Living Lab](experiments/web-chat-living-lab.md)** を参照してください。
