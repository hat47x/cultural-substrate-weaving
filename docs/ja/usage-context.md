# 呼ぶ側が用意するもの

## このスキルが提供する能力

cultural-substrate-weavingは、**文化体系を一時的な認知の場として使い、問い・関係・状態・遷移・空白の候補を探ること**と、**その候補の由来を保ちながら対象に照らし合わせ、検証につなげること**を支援します。種類の異なる多数の資料を一度にまとめる場合は、利用可能であれば`affinity-synthesis`か互換性のある実装にその処理を委ねます。複数回にわたる検討を、前回からの差分を基に再開する場合も、`iterative-inquiry-synthesis`か互換性のある実装に委ねます。

本スキルは、執筆、経営、ソフトウェア開発、法務などに必要な専門知識や領域スキルを代替しません。専門的な正確さ、品質基準、実装方法、成果物の形式は、依頼の文脈か、併用する専門領域のスキルで定めてください。

## 推奨する組み合わせ方

```text
【対象と材料】
（分析対象、資料、制約）

【領域側の基準線】
（専門スキルまたは通常手法でまず分析する）

【cultural-substrate-weavingの役割】
文化的体系から、基準線になかった問い・関係・状態・遷移・空白・構成候補を探索し、対象由来・体系由来・接触から生じた候補の来歴を保つ。多数・異種の材料を親和統合する必要がある場合は、CSW自身の内部手順として抱え込まず、compatibleな`affinity-synthesis`へ接続する。

【目的別の出口】
調査・診断では、対象について所見に進める候補を専門知識・資料・規格・実務条件で検証する。生成・構成では、文化体系から生じた構造を構成資源として採用できるが、対象についての事実とは区別する。
```

複数のスキルを使える環境では、専門領域のスキルを外すことなく、**専門領域のスキルとcultural-substrate-weavingを併用すること**を勧めます。

## 特に価値が出やすい状況

- 問題空間が開いており、到達点そのものがまだ定まっていない
- 異なる種類の材料、主体、時間、関係が絡み合っている
- 通常の分析が一つの結論に集まりつつあり、ほかの方向も探る価値がある
- 得られた候補を、調査・診断では対象側の資料や条件へ戻して検証できる、または生成・構成では来歴を保った構成資源として扱える

## 単独で使う理由になりにくい状況

- 正解や候補を列挙し尽くせる閉じた問題
- 単純な校正、翻訳、計算、形式変換
- 局所的なバグ修正や、既知の手順をそのまま実行する作業
- 調査・診断で対象について所見へ進みたいのに、仮説を対象側で検証する材料がない問題

これらの状況に当てはまっても、CSWを自動的に使わないと決めるわけではありません。使うかどうか、どこまで使うかは、課題の種類だけでなく、依頼者の指示やスキル外で与えられた設定・委任に従います。明示的な指定がある場合は、少なくとも適用する範囲を限定し、通常の分析との違いを確かめます。

## 体癖（Taiheki）について

体癖は特例として残しています。人間が登場するという理由だけでは自動適用しません。明示的な指定がある場合、または身体的一貫性や緊張・弛緩時の反応そのものが探索対象である場合に、文化的・身体論的な外部類型として限定的に適用します。診断や人格上の事実としては扱いません。

## 効果検証について

公開済みのv0.4.0方法論を対象に、Web Chat Living Labで実作業を観測しています。公開記録では、観測の仕組みをあらかじめ用意して得た記録（prospective）と、通常の作業を後から匿名化・抽象化した記録（retrospective）を区別しています。通常は、作業を中断せずに観測する`natural_work`を使います。方法の変更を判断する場合や、確認された不利益の原因を切り分ける場合、重要な変更後の再確認を行う場合など、より厳密な比較が必要なときに限り、`paired_check`で通常の分析とCSWを併用した分析を比べます。

文化的体系を開かなかった場合は、`activation_scope: non_activation`として、そのラウンドで実際に起きた状態を記録します。その記録だけから「使わない方がよかった」「有用だった」「害を避けた」とは判断しません。評価や解釈を残す必要がある場合は、観測された状態とは分け、誰がどの根拠からそう判断したのかを後からたどれる形で記録します。

公開観測はまだ限定的であり、現時点ではこのスキルの有効性が確立したとは扱いません。詳細は **[Web Chat Living Lab](experiments/web-chat-living-lab.md)** を参照してください。
