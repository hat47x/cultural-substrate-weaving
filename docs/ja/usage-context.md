# 呼ぶ側が用意するもの

## このスキルが提供する能力

cultural-substrate-weaving は、**文化的体系による構造候補の供給**と、**KJ法による断片統合・空白探索**を提供します。

本スキルは、執筆、経営、ソフトウェア開発、法務などの専門家や領域スキルを代替しません。専門的な正確性、品質基準、実装方法、成果物の形式は、呼ぶ側のコンテキストまたは併用する領域スキルで指定してください。

## 推奨する併用形

```text
【対象と材料】
（分析対象、資料、制約）

【領域側の基準線】
（専門スキルまたは通常手法でまず分析する）

【cultural-substrate-weaving の役割】
文化的体系とKJ法から、基準線になかった問い・関係・状態・遷移・空白を探索する。

【領域側の最終検証】
追加所見を専門知識・資料・規格・実務条件で検証する。
```

複数スキルを使える環境では、領域固有スキルを外すのではなく、**領域スキル + cultural-substrate-weaving** として使うことを推奨します。

## 向く問題

- 問題空間が開いており、到達点そのものが未定
- 異種の材料・主体・時間・関係が絡む
- 通常分析が一つの筋へ収束し、別の探索方向を入れる価値がある
- 得られた候補を対象側の資料や条件で検証できる

## 向かない問題

- 正解や候補を列挙し尽くせる閉じた問題
- 単純な校正、翻訳、計算、形式変換
- 局所的なバグ修正や既知手順の実行
- 対象側で仮説を検証する材料がない問題

## Taihekiについて

Taihekiは特例として残しています。人間が登場するだけでは自動適用しません。明示指定がある場合、または身体的一貫性・緊張／弛緩時の反応そのものが探索対象である場合に、文化的・身体論的な外部類型として限定適用します。診断や人格上の事実として扱いません。

## 効果検証について

現行版は、領域スキル単独と「領域スキル + 本スキル」の比較で検証します。
