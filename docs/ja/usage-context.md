# 呼ぶ側が用意するもの

このスキルは、**文化的体系に基づく構造供給の能力**を生成AIへ与えます。それが役割のすべてです。

役割の外にあるもの——依頼の立て方、モデルの既定の傾向の補正、作品としての出来——は、**スキルを呼ぶ側のコンテキストが担います。** この文書は、その側で何を用意するかを書いたものです。

用意しなければ、スキルは働きますが、**あなたが期待したものとは別のところで働きます。**

## スキルがすること／しないこと

| する | しない |
|---|---|
| 対象を見る前に定義された位置の集合を持ち込む | あなたの依頼文が何を前提しているかを疑う |
| その位置へ対象を割り当て、遷移を走らせ、空いた位置を検出する | モデルの既定の文体・傾向・偏りを補正する |
| 体系の語彙を全部消しても成立する所見だけを残す | 出来上がったものが良いかどうかを判定する |
| 材料が尽きたかを判定する | いくらまで使ってよいかを判定する |

## 1. 依頼文に埋まっている態度を、自分で決めてください

**依頼の言葉は、既に態度を決めています。**

| 依頼文 | 既に含意している態度 |
|---|---|
| 「廃業する一年を描く」 | 廃業は喪失である |
| 「この設計を改善する」 | 現状は悪い |
| 「なぜ失敗したか分析する」 | 失敗した |
| 「この製品の価値を高める」 | 価値は高いほうがよい |

スキルはこれを疑いません。**態度は選ばれるのではなく、依頼文から引き継がれます。**

実際に測りました。同じお題を三つの独立したエージェントに与えたところ、**三案とも「廃業＝喪失」を一度も疑わずに書きました**（[適用事例](examples.md)事例3）。方法論を全体適用した腕も、12周・212Kトークン回して、ここには届いていません。

対策は簡単です。**依頼文に、態度を明示的に書いてください。**

```text
この工場の廃業を、喪失としてではなく、
誰かの受注増と、続く技能の移動として書いてください。
```

あるいは、態度そのものを検討対象にすると宣言してください。

```text
まず、この依頼文が何を前提しているかを列挙してください。
そのうえで、採る前提と採らない前提を分けてください。
```

## 2. モデルの既定の傾向は、あなたが指定してください

スキルはモデルの癖を直しません。よく効く指定を挙げます。

- **均衡させない**：「双方に問題がある」形へ機械的に均そうとする傾向があります。力関係・責任・被害の非対称が実在するなら、対称に書かないよう指定してください。
- **弱めない**：材料が持っていた強さを、配慮として弱めることがあります。断定が推量へ下がる、行為者が消えて出来事が独りでに起きた形になる、といった形で現れます。
- **説明を足さない**：言い切った直後にもう一言説明を加える癖があります。
- **標準解に落ちる**：どの題材にも「真面目に取り組めば八割方そこへ行く」既定解があります。それを避けたいなら、そう言ってください。避けたくないなら、言わなくて構いません。

## 3. 打ち切りは、あなたの判断です

スキルの停止条件は**材料が尽きたか**だけです。コストでは止まりません。これは意図的な設計です。

> 本方法論の目的は、同じ手を繰り返すだけでは頭打ちになる地点を越えることであり、同一のトークン量でより良い結果を出すことではない。

したがって次を用意してください。

- **上限のない環境**が本来の想定です。利用量の上限が厳しい環境では、**周回数か予算を先に決めて渡してください。**
- 中断された場合、その時点の出力は結果ではありません。**再開できるなら再開してください。**

実測では、単発の実行に対して**3〜4倍のトークン**を要しました。

## 4. 適用してよい対象を選んでください

スキルは**開かれた問題空間**でのみ働きます。

| 向く | 向かない |
|---|---|
| 産業構造の分析、製品価値の設計、まだ形の無い制作物の構想 | バグの特定、仕様適合の確認、既知手順の実行 |
| 到達点そのものを決めることが作業の一部 | 正解が確定でき、候補を列挙し尽くせる |

閉じた問題空間では通常手法で足ります。**構造を持ち、次元が相互作用し、検証可能であっても、それだけでは足りません。**

これも実測で確かめています。閉じた問題空間へ適用した記録が[事例1](examples.md)にあり、**誤用の記録**として残してあります。

## 5. スキルから外した判断——必要なら、あなたが指定してください

以前はスキル本体に入っていた項目です。**能力の遂行を支えないため、本体からは完全に除去しました。** 必要な場合は依頼側で指定してください。

**受け手への配慮**

- **可視性**：受け手が、自分の位置、現在の状態、次に起こり得ることを判断できるようにする。明示による理解の増加と、明示による損失の双方を見る。
- **受け手の判断余地**：判断に必要な輪郭、選択肢、結果を、結果発生前に確認できるようにする。
- **明示度の上限**：晒す、逃げ場をなくす、直視を強制する表現は、別種の作用として明示的に扱う。
- **強い負荷を持つ表現の評価**：導入機能（受け手を導くために必要か）／離脱可能性（距離を取れる経路があるか）／到達点（全体として到達点が示されているか）／精度（目的に必要な水準に収まっているか）。

**成果物の価値**

- **生成性**：超過性（割り当てられた機能を超えて働く）／自律性（作成者不在でも機能する）／再生成性（再読のたびに新しい理解を生む）。
- **非競合性**：共有によって価値を維持・拡大できるものが増えたか。
- **資源との併記**：消費される資源（当事者や受け手の注意、心理的余力、作業時間、運用負荷、後処理コスト）。

**モデルの既定の傾向の補正**

- **均衡させない**：「双方に問題がある」形へ機械的に均さない。権力、責任、被害の非対称が実在する場合、対称に書くことがその非対称を消す。
- **自分の構えを検査する**：分析者自身の価値観や既定の構えも、対象の外から持ち込まれた構造として扱う。制約のために記述を弱める・ぼかす・削る場合は、変えたことと失われたものを書く。**削った損失を、加えた損失と同じ扱いで数える。**
- **委ねられた範囲**：勝手に広げず、過度の自制で勝手に狭めもしない。判断を任された場面で判断を返さないことは、任されていない判断を下すことと同じ。
- **同調から距離を置く**：目的、信念、組織内合意が強い領域ほど、利害や感情的同調から距離を置いて確認する。

**創作の補助パターン**（旧`07-creative-patterns`）

- **経験への変換**：身体・感覚／認知／行動・関係／環境・構成の四経路へ分散する。実在する他者の被害は、構造として表現する方法を先に検討する。
- **既存機能への統合**：新規要素を追加する前に、既存の文・行動・会話・機能・手順へ役割を統合できるかを確認する。
- **反復と明示度**：反復するたびに関係または機能を変える。明示度は潜在／示唆／明示の三段階で制御する。
- **時間構造**：蓄積と回帰／時機／与件と課題。必然、宿命、運に相当する構造は、兆候、反復、符合、周期変化として実装する。
- **笑い**：不一致／優越／解放の三機構を区別する。各機構の倫理的帰結を確認する。人を裁かない設計では、優越以外の機構を主に使う。
- **感情**：感情名ではなく、発生機構、効果、実例、配置によって分類する。先に配置した感情が、後続する感情の強度と解釈を変える。
- **連作**：受け手の記憶減衰を前提に、必要な情報を再導入する。各回に独立した導入経路を持たせる。
- **異分野の語彙による再記述**：受け手ごとに異なる導入経路を作る。語彙は構造の一致で選ぶ。

**出力の設計**

- 受け手が判断するために必要な明示度を確保する。異なる受け手には、同じ中心内容へ到達できる複数の導入経路を用意する。
- 前提知識が少ない段階には低負荷の導入情報を置く。要点、最小実行単位、中断位置、再開位置を明示する。

## 6. 作品としての出来は、別の話です

スキルが保証するのは「体系が供給した構造のうち、対象へ返して生き残ったものだけを報告する」ことです。**それが良い成果物になるかは保証しません。**

三腕の対照実験では、方法論なしで推敲を繰り返した腕も局所最適を脱出しました。脱出の**仕方**は違いましたが（一方は器ごと取り替え、一方は器を保って中心をずらす）、盲検の判定者は両者を「弱くなく、依存先が違うだけ」と評価しています。

**文章の質を上げたいなら、そのための指定を別に与えてください。** スキルはそこを担当しません。

## 最小の型

```text
/cultural-substrate-weaving-ja:weave

対象：<対象>

この依頼文が含意している態度：<態度>。これを採る／採らない。

避けたい既定の傾向：<あれば>

予算：<周回数または上限>。材料が尽きるまで回してよい。

出来については別途指定する。
```
