# 呼ぶ側が用意するもの

## このスキルは何をするか

**昔からある考え方の枠組みを使って、あなたの題材の「抜けている場所」を探します。**

五行、易、KJ法のような枠組みは、中身を見る前から「置き場所」が決まっています。その置き場所にあなたの題材を当てはめると、**埋まらない場所が出てきます。** そこが探すべき抜けです。

最後に枠組みの名前をすべて消して、それでも成り立つ話だけを報告します。**枠組みが正しいかどうかは問いません。あなたの題材について何か言えたかどうかだけを見ます。**

## このスキルがしないこと

ここが大事です。**スキルは能力だけを提供します。** 次の四つは**あなたが指定しないと、誰もやりません。**

| スキルがすること | あなたが指定すること |
|---|---|
| 枠組みを当てて、抜けを探す | 依頼文が何を決めつけているか |
| 抜けが本当にあるか題材で確かめる | AIの直したい癖 |
| 材料が尽きたら止まる | いくらまで使ってよいか |
| — | 文章や成果物の出来 |

## まず、これをコピーして使ってください

```text
/cultural-substrate-weaving-ja:weave

【題材】
（ここに対象を書く）

【この依頼文の決めつけ】
（例：「廃業を描く」と書いたが、廃業＝損失とは決めつけない）

【避けたいAIの癖】
（例：どっちもどっち、という書き方にしない）

【予算】
（例：10周まで。または「材料が尽きるまで回してよい」）

【出来について】
（別途指示する ／ 今回は問わない）
```

四つとも空欄でも動きます。ただし**空欄にした分は、AIが勝手に決めます。**

---

## 1. 依頼文の決めつけ

依頼の言葉は、書いた時点で答えの向きを決めています。

| こう書くと | こう決まる |
|---|---|
| 「廃業する一年を描く」 | 廃業は悲しいこと |
| 「この設計を改善する」 | 今の設計は悪い |
| 「なぜ失敗したか」 | 失敗した |

**スキルはこれを疑いません。** 疑ってほしければ、そう書いてください。

実際に試しました。同じお題を三つのAIに別々に渡したところ、**三つとも「廃業＝損失」を一度も疑いませんでした。** スキルを使った回も同じでした。

書き方の例：

```text
廃業を、損失としてではなく、
同業他社の受注増と、他社へ移る職人の技能として書いてください。
```

## 2. AIの癖

スキルは癖を直しません。よく効く指定を挙げます。

- **どっちもどっち、にしない** — 力関係や被害に偏りがあるとき、対等に書くと偏りが消えます。
- **弱めない** — 「〜した」が「〜したとされる」に、「Aさんが決めた」が「そうなった」に変わることがあります。
- **言い切ったあと説明を足さない** — いい一行の直後に、余計な一行を付ける癖があります。
- **無難な答えに落ちない** — どんなお題にも「まじめにやると八割方そこへ行く」定番の答えがあります。避けたければ、そう言ってください。

## 3. 予算

**このスキルはコストでは止まりません。材料が尽きたときだけ止まります。** これは意図した設計です。

同じことを繰り返すだけでは行き詰まる地点があります。**そこを越えるのが目的で、少ないトークンで良い結果を出すことは目的ではありません。**

- 実測で、一回書くだけの場合の**3〜4倍**を使いました。
- 利用上限の厳しい環境では、**周回数か予算を先に伝えてください。**
- 途中で止まった場合、その時点の出力は**結果ではありません。** 再開してください。

## 4. 向く題材・向かない題材

| 向く | 向かない |
|---|---|
| 業界の分析、製品の価値づくり、まだ形のない企画 | バグ探し、仕様どおりか確認、手順どおりの作業 |
| 何を目指すか自体を決めるところから | 正解がはっきりしていて、選択肢を数え上げられる |

**答えが決まる問題なら、普通のやり方で足ります。** 構造があって、複雑で、検証できても、それだけでは足りません。

閉じた問題に使ってしまった記録が[適用事例](examples.md)の事例1にあります。**誤用の記録**として残してあります。

## 5. 出来については指示してください

スキルが約束するのは「枠組みを消しても残った話だけを報告する」ことだけです。**それが良い文章・良い設計になるかは約束しません。**

三つのAIで比べた実験では、**スキルを使わずに推敲を繰り返した回も、定番の答えから脱出しました。** 脱出の仕方は違いましたが、目隠しで読んだ評価者は「どちらも弱くない」と判断しています。

出来を上げたいなら、そのための指示を別に出してください。

## 付録：スキルから外した判断の一覧

以下は以前スキル本体に入っていた項目です。**能力そのものではないため外しました。** 必要なら依頼側で指定してください。

<details>
<summary>受け手への配慮</summary>

- 受け手が「自分の位置・今の状態・次に起こること」を判断できるようにする
- 判断に必要な情報を、結果が出る前に見せる
- 逃げ場をなくす表現、直視を強いる表現は、別扱いにする
- 重い表現は次で測る：導入に必要か／距離を取れるか／行き先が示されているか／必要以上に強くないか

</details>

<details>
<summary>成果物の価値</summary>

- **超過性**：ひとつの要素が、与えた役割を超えて働くか
- **自律性**：作った人がいなくても機能するか
- **再生成性**：読み返すたびに新しい理解が出るか
- **非競合性**：共有しても減らない価値が増えたか
- 消費されるもの（注意、気力、作業時間、運用の手間、後始末）も併せて書く

</details>

<details>
<summary>AIの癖の補正（詳細版）</summary>

- 対立を「どっちもどっち」にしない。力・責任・被害の偏りが実在するなら、対等に書くとその偏りが消える
- AI自身の価値観も、外から持ち込んだものとして疑う。配慮のために記述を弱めた場合、**何を変えて何を失ったかを書く**
- 任された範囲を、勝手に広げない。**遠慮して勝手に狭めもしない**
- 目的や信念の強い領域ほど、同調から距離を置いて確認する

</details>

<details>
<summary>創作の技法</summary>

- **経験にする**：身体／認知／行動・関係／環境の四経路に散らす。実在の人の被害は、まず構造として書く方法を考える
- **既存のものに役割を足す**：新要素を足す前に、既にある文・行動・会話に役割を追加できないか見る
- **繰り返しは毎回変える**：出すたびに関係か機能を変える。はっきり書く度合いは、隠す／ほのめかす／明示の三段階で
- **時間**：積み重なるもの／頃合い／与えられた条件と課題。運命めいたものは、兆し・繰り返し・符合・周期として書く
- **笑い**：ずれ／見下し／解放の三つを区別する。人を裁かない話なら、見下し以外を使う
- **感情**：感情の名前ではなく、どう起きるか・何を起こすか・どこに置くかで分ける。先に置いた感情が後の感情を変える
- **続きもの**：読者は忘れる前提で、必要な情報を出し直す。毎回、独立した入口を作る
- **別分野の言葉で言い直す**：読者ごとに違う入口を作る。言葉は構造が一致するもので選ぶ

</details>

<details>
<summary>出力の設計</summary>

- 読み手が判断できるだけの情報量を確保する。読み手が複数なら、同じ結論に至る入口を複数用意する
- 前提知識が少ない段階には軽い情報を置く
- 要点・最小の実行単位・中断できる場所・再開する場所を明示する

</details>
