# はじめに

このリポジトリには、方法論を利用する方向けの資料と、方法論を保守・配布する方向けの資料があります。

## 利用環境

本方法論は、与えられた資料だけでも利用できます。現在の事実を確かめる必要がある課題、外部の文脈を補う必要がある課題、追加の出典を探す必要がある課題では、Web検索（ブラウジング）を利用できる環境が役立ちます。

Web検索を使えない場合は、与えられていない事実を推測で補わず、不足している資料や今後の探索候補として残します。Web検索を有効にする方法は、各プラットフォームのガイドを参照してください。

## 方法論を利用する方

GitHub Releasesから、自分が使う言語とプラットフォームに対応したZIPを取得します。リポジトリそのものを編集する必要はありません。

- 日本語: ファイル名に`ja-JP`
- English: ファイル名に`en-US`

同じ環境に両言語版を同時に入れると、似たスキルが競合する可能性があります。通常は、利用する言語を一つ選びます。

## 方法論を保守・配布する方

- 意味上の正本: `src/ja-JP/`
- 英語翻訳: `src/en-US/`
- 翻訳状態と正本ハッシュ: `i18n/translation-manifest.json`

正本を変更した場合は、対応する翻訳を更新してから`make check`を実行します。各プラットフォーム向けのファイルは、ビルド処理から生成します。

## どの環境を選ぶか迷った場合

- ChatGPT上で対話を中心に幅広く使う: ChatGPT custom GPT
- コーディングやリポジトリ分析と組み合わせる: CodexまたはClaude Code
- Microsoft 365内の文書やSharePointと組み合わせる: Microsoft 365 Copilot Agent
- 複数のAI環境で同じ方法論を使う: このGitリポジトリを正本として維持する
