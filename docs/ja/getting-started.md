# はじめに

このリポジトリには二つの利用者像があります。

## 方法論を使う人

GitHub Releasesから、自分の言語とプラットフォームに対応するZIPを取得します。リポジトリを編集する必要はありません。

- 日本語: ファイル名に`ja-JP`
- English: ファイル名に`en-US`

同じ環境へ両言語版を同時に入れると、似たスキルが競合する可能性があります。通常は利用する言語を一つ選びます。

## 方法論を保守・配布する人

- 意味上の正本: `src/ja-JP/`
- 英語翻訳: `src/en-US/`
- 翻訳状態と正本ハッシュ: `i18n/translation-manifest.json`

正本を変更した場合は、対応する翻訳を更新してから`make check`を実行します。各プラットフォーム向けファイルは自動生成します。

## 迷った場合

- 定額チャットで広く使う: ChatGPT custom GPT
- コーディングやリポジトリ分析: CodexまたはClaude Code
- Microsoft 365内の文書やSharePointと組み合わせる: Microsoft 365 Copilot Agent
- 複数AIへ同じ方法論を供給する: このGitリポジトリを正本として維持
