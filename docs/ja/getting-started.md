# はじめに

このリポジトリには、方法論を使う人のための資料と、方法論を保守・配布する人のための資料があります。

## 利用環境

この方法論は、与えられた資料だけでも利用できます。現在の事実の確認、外部の文脈の調査、追加の出典の探索が必要な課題では、Web検索を使える環境が役立ちます。

Web検索を使えない場合は、資料にない事実を推測で補いません。不足している資料や今後調べるべき事項として残します。Web検索を有効にする方法は、各プラットフォームのガイドを参照してください。

## 方法論を利用する方

GitHub Releasesから、使う言語と実行環境に対応するZIPファイルを取得します。リポジトリそのものを編集する必要はありません。

- 日本語: ファイル名に`ja-JP`
- English: ファイル名に`en-US`

同じ環境に日本語版と英語版を両方導入すると、似たスキルが競合する可能性があります。通常は、利用する言語を一つに絞ります。

現時点のMicrosoft 365 Copilot版では、`instructions.txt`に書かれた範囲だけを実行指示として扱います。方法論全体を実行する必要がある場合は、[Microsoft 365 Copilot向けガイド](platforms/microsoft-copilot.md)に記載した制約を確認してから、利用環境を選んでください。

## 方法論を保守・配布する方

- 意味上の正本: `src/ja-JP/`
- 英語翻訳: `src/en-US/`
- 翻訳状態と正本ハッシュ: `i18n/translation-manifest.json`

日本語の正本を変更した場合は、対応する翻訳も更新したうえで`make check`を実行します。各実行環境向けのファイルは、ビルド処理で生成します。

## どの環境を選ぶか迷った場合

- ChatGPT上で対話を中心に幅広く使う: ChatGPT custom GPT
- コーディングやリポジトリ分析と組み合わせる: CodexまたはClaude Code
- Microsoft 365内の文書やSharePointと組み合わせる: Microsoft 365 Copilot Agent。ただし、現行アダプターの実行指示は`instructions.txt`の範囲に限られるため、方法論全体が必要な場合は他の対応環境も検討する
- 複数のAI環境で同じ方法論を使う: このGitリポジトリを正本として維持する
