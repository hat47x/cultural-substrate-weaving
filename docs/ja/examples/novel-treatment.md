## 0. 適用範囲の定義（01-scope-and-facts §1）

| 軸 | 選択 |
|---|---|
| 制作か読解か | **制作**。構造の生成と統合を行う |
| 受け取られる対象か使われる対象か | **受け取られる対象**（短編小説） |
| 現実に対する姿勢 | **写す**を主とし、**規則を一つ変更して試す**を従とする。「差異を示す」「目標状態を示す」「警告する」は採らない |

姿勢の理由：廃業は現在進行で各地に実在する。受け手の多くはこの事象をニュースの語彙（後継者不足、人手不足、地域経済の衰退）で既に知っている。**知っている語彙で覆われている対象には、差異の提示より、その語彙が取りこぼしている具体の写しが効く。** 「規則を一つ変更して試す」を従に置くのは、廃業という終わりを、当事者が終わりの日付を自分で決められる終わり方として扱う一点においてである（この一点は後述の体系適用で確定した）。

対象の主要な変化構造（一文）：
> **稼働している設備と人の関係が、日付を当事者自身が指定して停止され、設備は資産として散り、人は各自の次へ分かれ、建屋と床と土地だけが残るまでの一年。促進するのは受注の減少・身体の限界・資産価値の残存であり、抑制するのは仕事の継続そのものが持つ慣性と、停止の日付を口に出すことの遅延である。**

## 1. 基準線（この方法論を使わず、通常の創作手法だけで書ける構想）

**注記**：これは要約ではない。方法論を適用する前に、通常手法だけで実際に到達した構想を成果物の形で書き切ったものである（01-scope-and-facts §2 の要求）。以後の増分は、この基準線に対して測る。

### 1-1. 舞台

北関東の人口約11万の市。旧市街から用水路沿いに三キロ外れた一角。工業団地ではなく、住宅と畑と小工場が混在する「町場」。工場は木造軸組にスレート屋根、間口十二メートル、奥行き二十メートル。前面に軽トラ二台分の砂利敷き。

### 1-2. 工場

**三ツ木製作所**。創業一九六一年。アルミの重力鋳造と、その後の機械加工。従業員六名。取引先は自動車部品の二次下請け三社、農機具メーカー一社、地元の看板業者一社。売上は最盛期の七千八百万円から五千二百万円へ落ちている。借入は残っているが延滞はない。倒産ではなく自主廃業。

### 1-3. 登場人物

| 氏名 | 年齢 | 立場 | 基準線での役割 |
|---|---|---|---|
| 三ツ木邦夫 | 68 | 二代目社長 | 視点人物。決断する側 |
| 三ツ木久子 | 65 | 妻・経理 | 決断を先に察している側 |
| 沢田正一 | 62 | 職長・勤続四十一年 | 無口な職人。技能の体現 |
| 大類ミチ | 58 | パート、バリ取りと検査 | 近所の人。感情の担当 |
| グエン・ヴァン・トアン | 26 | 特定技能二年目 | 外から来た若手 |
| 三ツ木美佐 | 41 | 娘・さいたま市在住 | 継がない次世代 |
| 木村隆 | 51 | 得意先の調達担当 | 外圧の伝達役 |

### 1-4. 時間構造（四季四章）

**第一章・春（決断）**
- S1／四月十日　金融機関の担当者が来訪。返済は問題ない。設備更新の融資提案を邦夫が断る。
- S2／四月下旬　美佐から電話。孫の入学の報告。継ぐ話は互いに出さない。
- S3／五月中旬　木村が来訪。来期の内示が前年の半分。
- S4／六月初旬　邦夫、市の健診。腰椎の所見。

**第二章・夏（通知）**
- S5／七月一日　邦夫が久子に廃業を告げる。久子は驚かない。
- S6／七月中旬　従業員へ通知。沢田は黙る。ミチは泣く。グエンは「いつまでですか」と聞く。
- S7／八月・盆　工場を止める。近所の夏祭り。
- S8／八月下旬　取引先への挨拶回り。

**第三章・秋（最後の仕事）**
- S9／十月初旬　最終ロットの受注。
- S10／十一月中旬　最後の鋳込み。
- S11／十一月末　最終出荷。
- S12／十二月末　従業員の最終出勤日。

**第四章・冬（撤去）**
- S13／一月中旬　中古機械業者が下見に来る。
- S14／二月中旬　機械の搬出。
- S15／三月中旬　産業廃棄物の処理、床の油、明渡しの準備。
- S16／三月末　空の建屋。美佐が来る。

### 1-5. 主題（基準線）

手仕事の終わり。継承の断絶。地方都市の縮小。「作れるのに、作る先がない」。

### 1-6. 結末の方向（基準線）

三月末、機械の搬出が終わった空の建屋に邦夫が立つ。床のオイルの染みだけが機械の位置を示している。美佐が来て、並んで立つ。邦夫が「ここに炉があった」と言う。静かな余韻で終わる。

### 1-7. 基準線の自己評価

この構想は成立する。だが構造は既知である。四季四章、決断→通知→最後の仕事→撤去という単調増加の一方向、床の染みで終わる結び。**探索が一つの筋へ固まっている。** どの場面も「終わりに向かっている」ことだけを担当しており、二つ以上の働きを持つ場面が無い。

## 2. 変更後も壊してはならないもの（保持事項）

01-scope-and-facts §2 の要求により、体系を当てる前に列挙する。**本方法論の検査は欠落と不適合を探す方向へ働くため、これを明文化しないと局所の修正が全体へ波及して固有の変動を平滑化する。**

1. **廃業は倒産ではない。** 自主廃業であり、債務を返して終える。悲劇へ落とさない。
2. **従業員六名の帰結を曖昧にしない。** 各自の次の行き先を、たとえ一行でも確定させる。
3. **邦夫の決断を単一原因にしない。** 受注減、身体、資産価値、慣性が同時に働く。
4. **グエンを「かわいそうな外国人」にしない。** 彼には彼の計算がある。
5. **美佐を「帰ってきて継ぐ」にしない。** 継承の回復で終わらせない。
6. **声**：地の文は乾いた三人称一元（邦夫）。比喩を多用しない。工程の語は正確に使い、注釈で説明しない。
7. **意図的な不均一**：第三章だけ時間の刻みを細かくする（日単位）。他章は週・月単位。この不均一は「均す」対象にしない。
8. **季節は情感として使わない。** 作業条件（湿度＝錆、気温＝湯の流れ、日照＝停電時の可視性）として使う。
9. **廃業の手続きは正確に。** 実務の日付・順序を情緒のために動かさない。

## 3. 断片統合（10-integration）

材料が多数・異種であり、主要構造が未確定のため、体系選定より先に実施した（ROUTER「全体適用」の読み込み順）。**この手順の主産物は整理された結論ではなく、そこに無いものの発見である。**

**カード群の共通欄**（同じ値が続く欄はカード群の側に一度書く）：採取者＝本作業者／採取時＝本セッション。

### 3-1. カード（一件一枚・動詞で終わる文・名詞止め禁止）

**出所＝お題文**（段階：材料から直に起こした）
- C01　お題は「廃業する」と現在形で書き、一年が廃業の前なのか後なのか決めていない。
- C02　「その一年」は、廃業の日を起点とする一年だと読める。
- C03　「その一年」は、廃業の日を終端とする一年だと読める。
- C04　「小さな」が、従業員数なのか売上なのか敷地なのか建屋なのか決まっていない。
- C05　「地方都市」は村でも大都市でもなく、駅と病院と高校がある規模を指している。
- C26　「描く」という語は、記録ではなく像を作れと言っている。

**C02とC03は対立する見方である。一枚の中で均さず、別々の札として立てた**（10-integration：個別のカードで均衡させると、図解に描くべき対立の極が入力の時点で消える）。

**出所＝基準線（前周回の外部化物を再材料化）**（段階：束から立てたのではなく、成果物から直に起こした）
- C06　基準線は四季で章を切り、季節の順序に物語の順序を預けている。
- C07　基準線の十六場面は、すべて「終わりへ一歩進む」働きしか持っていない。
- C08　基準線は床のオイルの染みで終わり、痕跡が残ることを慰めにしている。
- C09　基準線では邦夫だけが決め、他の六人は決められた側に置かれている。
- C10　基準線は最終出勤日と明渡し日を三か月離しており、その間に人が居ない。
- C11　基準線は廃業を七月一日に告げると置き、告げる前の時間を四場面しか持っていない。
- C12　基準線の従業員六名のうち、次の行き先が書かれているのは零名である。
- C13　基準線は娘が継がないことを決めているが、娘が何を相続するかを決めていない。
- C14　基準線には工場の建屋と土地の所有者が書かれていない。
- C15　基準線には、廃業を止めようとする人物が一人も居ない。
- C16　基準線は季節を作業条件として使うと宣言しながら、場面表にその実装が現れていない。

**C12は、保持事項2（従業員六名の帰結を曖昧にしない）を基準線自身が既に破っていることを示す。カードを弱めずに立てる。**

**出所＝書き手の一般知識（未検証・自己申告）**（段階：材料から直に起こした／発見経路＝執筆者の既有知識）
- C17　解雇予告は少なくとも三十日前に行う必要があり、廃業の日付が人事の日付を先に縛る。
- C18　機械は据付けのアンカーで床に留められており、外すと床に穴が残る。
- C19　溶解炉は止めた後も内張りの耐火物が残り、産業廃棄物として費用が出る。
- C20　中古工作機械には値が付き、廃業の日付は資産が値崩れする前かどうかで動く。
- C21　法人を畳むには解散登記と清算結了登記が要る。
- C22　特定技能の在留資格は受入れ機関に紐づいており、工場が消えると在留の根拠が消える。
- C23　木型は使わなくなると湿気を吸って反り、二度と同じ寸法が出なくなる。
- C24　取引先は廃業を知ると、最後の一年に在庫を積み増して発注する。
- C25　工場を止めた後も、動力の電気契約と火災保険は建屋がある限り続く。
- C27　廃業する工場の外に、廃業を待っている人が居るかもしれない。

**C27は理由の言えない注意である。理由が言えないまま一枚にした**（10-integration：後付けの理由で仮説へ格上げせず、説明できないことを理由に捨てもしない）。

**一段目（2〜3枚）**

| 束 | 構成 | 表札 |
|---|---|---|
| A | C01,C02,C03 | 一年の起点をどこに置くかを、まだ誰も決めていない |
| B | C17,C20,C21 | 法が日付の下限を、資産価値が上限を出し、当人はその間から選んでいる |
| C | C18,C19,C25 | 機械を止めても、建屋は費用を出し続ける |

| F1 | C06,C07 | 季節の順に並べたので、場面が順番以外の働きを持てなくなっている |
| F2 | C08,C16 | 痕跡で締めることに寄りかかり、宣言した物理条件を使っていない |
| G | C09,C15 | 決める人が一人しか居ないので、反対が物語に入ってこない |
| H | C10,C11 | 告げる前と、片づけの後に、人の居ない時間が置き去りになっている |

**孤立札（どの束にも入らない）**：C26、C27。

**表札Bの戻し検査で修正が生じた。** 当初の表札は「法と資産価値が先に候補を出し、当人はその中から選んでいる」だったが、C17へ戻すとC17は候補ではなく**下限**を言っている。修正して「法が下限を、資産価値が上限を出す」とした。**修正後のほうが強い。「資産価値が上限を出す」＝機械が値崩れする前に売らねばならない、という判断がここで新しく出た。**

**二段目（5束へ畳んだ）**

| 束 | 構成 | 表札 |
|---|---|---|
| α | A + B | 一年の始まりと終わりは、当人の気持ちではなく、外の期限表が先に決めている |
| β | C + E | 止めた後にも動き続けるものがあり、それは増やす方にも損なう方にも働く |
| γ | D + I | 工場が消えると、それにぶら下がっていた別々の根拠が、それぞれ違う日に切れる |

**表札の可搬性検査**：αを束βに載せると成立しない。γを束Eに載せると成立しない。δを他へ載せると成立しない。→ 分類名ではない。**通過。**

**戻し検査（二度独立に実施）**：一度目、束γの表札を C13（娘の相続）へ戻すと「根拠が切れる」ではなく「根拠が定義されていない」と返った。二度目も同じ箇所で同じ躓き方をした。→ **10-integration の規定により、直すべきは表札ではなく束である。** C13を束γから外し、束Iへ移した。移した後の束γ（C22,C12）は二枚となり、表札は成立した。

### 3-3. 配置（因果・相互・対立・時間の前後を区別し、引かなかった関係も描く）

```
        [α 外の期限表が日付を決める]
              │因果（下向き）
              ▼
   [γ 別々の根拠が別々の日に切れる]◀──相互──▶[β 止めた後も動き続ける]
              │                                      │
              │時間の前後                            │対立
              ▼                                      ▼
   [ε 決まる前と後に語り手が居ない]           (C27 廃業を待っている人)
              │
              │（引かなかった関係：εとδの間に線を引かない。
              │  δは基準線の欠陥であって対象の構造ではない）
              ▼
        [δ 基準線が順序と結末を外注している]

   (C26 「描く」＝像を作れ)  ← どの束とも線が引けない。孤立のまま置く
```

**対立の極**：βと C27。工場が止まった後も動き続けるもの（費用・湿気・契約）と、止まったことで得をする者。**この対立は基準線に一本も無い。**

### 3-4. 叙述（図に無い順序で語らない）

外の期限表が日付を先に決める。決まった日付から、別々の根拠が別々の日に切れていく。切れた後も動き続けるものがあり、その一方に、止まったことを待っていた者が居る。決まる前と、片づいた後には、語り手が置かれていない。

**双方向照合**：図解にあって叙述で落ちたものは無い。叙述にあって図解に無いものも無い。**ただし差分ゼロは媒体間の追跡可能性を示すだけで、対象の完全性を示さない。**

## 4. 適用した体系・用途・割当・遷移試行

### 4-0. 候補調査と不採用

| 候補 | 構成要素／分類原理 | 遷移規則 | 判定 |
|---|---|---|---|
| 忌日・中陰（十三仏系） | 死からの経過日数で区切る九位置 | 七日ごとの審判・差戻し・確定 | **採用（遷移モデル）** |
| 二十四節気（本朝七十二候） | 太陽黄経15度ごと二十四位置 | 単一巡回・分岐なし | **採用（時間モデル）** |
| 五行（相生・相剋） | 素材五位置 | 有向辺10本・分岐あり | **採用→後に棄却** |
| 通過儀礼三段階（分離・過渡・統合） | 三位置 | 順序 | **不採用**。どんな廃業にも適合し、不採用となる結果を定義できない（02：どの結果にも適合する体系は仮説の確証だけを増やすため探索候補から外す） |
| 能の五番立・序破急 | 五位置 | 上演順のみ | **不採用**。割当が類似判断にしかならず、体系全体が解釈語の層へ落ちる |
| 式年遷宮 | 二十年周期 | 建替え一種 | **不採用**（粒度が粗すぎる）。ただし対比軸「建て替えて続ける／建て替えずに終える」を補助模型として保持 |

**当てられなかった体系（能・式年遷宮）は、当てて欠落が出なかった体系とは分けて記録する**（02a：割当の手続きが作れずに使えなかったことを、欠落が再現しなかった証拠に数えない）。

### 4-A. 体系A：忌日・中陰の体系　／　用途：**遷移モデル**

**系統の宣言**：日本の十三仏信仰（室町期成立）を採る。原型は中国の十王信仰（『仏説地蔵菩薩発心因縁十王経』、唐末〜五代成立の偽経）で、十忌に十王を配当する。十三仏はこれに七回忌・十三回忌・三十三回忌を加えた拡張である。
**別系統とその相違**：浄土真宗は追善供養を教義上採らず、忌日を故人を偲び法を聞く日とする。**相違は「審判があるか」「生者の行為が死者の行き先を変えられるか」である。** 本稿は十三仏側（審判あり・追善で動く）を採る。理由は、廃業の一年に「一度決まったことが後から持ち出されて再度決まる」出来事が実在するかを検査したいからである。
**自己申告の範囲**：一次資料（『十王経』本文、十三仏の各配当）には当たっていない。**記憶と検索による自己申告である。** 反証条件＝忌日の日数体系または十三仏の成立時期が上記と異なることが一次資料で確認された場合。

**位置の層（一年内に入る九位置）**：7n（n=1..7）、100、365。

**導出できる部分の外部化と機械検査**：要素数9。順行遷移8本＋差戻し辺（各中陰忌日から次の忌日へ、および 49→100、100→365）。日数から忌日番号は一意に逆算できる（7で割り切れるか／100か／365か）。**存在しない接続の検査で、決定的な事実が出た。命日より前に位置が一つも無い。** 検査通過。

**割当の外部規約（体系からも対象からも出てこない取り決めを名指して分離する）**

- **規約R1：「命日」を、最終操業日（最後の製品を出荷し、主電源を落とした日）とする。**
  代替案は「解散決議の日」「明渡しの日」「従業員の最終出勤日」。
  **逆に決めたら結果がどれだけ動くか（実測）**：解散決議日を命日にすると、法定手続きの三か月半が中陰の内側にほぼ収まり、忌日と法定期限が重複しすぎて格子が識別力を失う。明渡し日を命日にすると一年の大半が「死の前」になり、九位置のうち七位置が空になる。**最終操業日を採ると、九位置中八位置が埋まる。**
  → **取り決めが結果を大きく動かす。したがって以後の結論は「対象について」ではなく「最終操業日を命日と置いたときの対象について」である。この限定を落とさない。**
- **規約R2**：割当対象は基準線の場面表 S1〜S16 が持つ日付とする。**割当確定前に新設場面を足さない**（解釈語の読みが割当を変えることを禁じる）。
- **規約R3**：日数は命日当日を第一日と数える。第七日が休業日に当たっても繰り下げない。

**述語の型**：**計算述語**（暦の日数計算。分析者の判断が入らない）。**適用する層**：語られた出来事の層（語る行為の層ではない）。

**独立に二度割り当てた結果**：九位置中、二度とも同じ位置に落ちたのが八。**割れたのは「四七日（28日目）」一位置**。基準線S13（一月中旬・中古機械業者の下見）を四七日に置くか、規約外の「三七日寄り」に置くかで割れた。→ **割れた位置の上に立てた解釈は結論に書かない。** 中古機械業者の場面から得た所見は成果に計上していない。

**当たり方の二重計測**（02a：片方だけを出さない）
- 規約の語彙（九位置）のうち一件でも当たった割合：**8／9 ＝ 89%**
- 対象の主要事象（20件）のうちいずれかの位置に落ちた割合：**10／20 ＝ 50%**
→ **前者が高く後者が低い。体系が触れたのは対象の半分であり、残りは位置の外にある。** 位置の外にあるのは、月次の家賃、四半期の申告、盆、正月、雪、隣人である。

**(a) 到達しない状態：「二七日」一件。**
分類の判別：対象がその状態を持たないのではなく、**入口が記述されていない**。連休に誰も来ない期間は実在する。→ **空白として登録し、次に取りに行くものが決まった。** 埋め方は §5-2 に記す。

**(b) 一度も起きない遷移：零件。ただしこれは体系Aの強さではない。**
体系Aの遷移は基本が線形であり、線形鎖では「起きない遷移」が原理的に出にくい。**差戻し辺**（審判が確定せず後の忌日へ持ち越される辺）だけが分岐であり、これは対象で観測された：
- 官報公告に対する債権の申出があると、清算が止まって差し戻る。

- **「木型」**。搬出もされず返却もされず、焼却の判断だけが保留される。**木型は湿気を吸って反り、二度と同じ寸法を出さない（C23）。焼けば戻らず、焼かなくても戻らない。どちらでも戻らない。**

**3. 遷移試行が出した最大の産物**

格子を敷いた時点で、お題の読みの対立（C02／C03）が格子上の問題として可視化された。
- 読みα（廃業日を起点）：中陰も一周忌も入るが、決断の過程が窓の外へ出る。
- 読みβ（廃業日を終端）：**忌日が一つも物語に入らない。中陰がまるごと空になる。**
- 読みγ（廃業日をまたぐ）：**基準線が無自覚に選んでいた読み。一周忌が窓の外に落ち、位置9が到達しない状態になる。**

さらに、格子を敷いた結果、**対象の側の過剰**が出た。

> **忌日体系は命日を一意と仮定する。だが事業の死は少なくとも三つの日付を持つ。**
> 命日0＝最後の受注を断った日／命日1＝最後の製品が出た日／命日2＝法人が消えた日。

**これは体系の側の禁則ではなく、対象の側の事実である**（02a：体系の側の禁則と対象の側の欠落を分けて記録する。ここは逆方向の不一致である）。

**4. 格子の被覆**：50%（上述）。**低い。格子が覆ったのは対象の半分である。**

#### 4-A-3. 採用後の四検査（02a §3b）

**反転検査**：「廃業の一年は忌日の格子で読める」を自分で反証しに行った。
反例＝**廃業には喪主が居ない。** 法人の死に遺族は居ない。従業員は遺族ではなく、社長は喪主でも故人でもある。
→ **反例が実在した。吸収せず、主張を縮小して残す。**
縮小後の主張：「廃業の一年を、終わりの日から数えた日数という一本の物差しで測ると、当事者ごとに『いつ終わったか』が別々の日にずれることが可視化される。」

**代替検査**：中心の発見「死の前に位置が無い」は別の体系でも出るか。
- 二十四節気：**出ない**（循環に前後は無い）。
- 五行：**出ない**（時間の起点を持たない）。
- 会計年度（制度であって文化的体系ではないが検査した）：**出る。** 期首の前に位置は無い。
→ **「起点を持つ一方向の暦」なら何でも出る。この欠落について、忌日体系でなければならない理由は無いと記録する。発見自体は有効である。**

**不適合の記録**
*(i) 対象を見る前に書けた不適合（先に列挙して後で差し引く）*
1. 忌日体系は金額を扱わない。
2. 忌日体系は複数人の異なる帰結を扱わない（故人は一人）。
3. 忌日体系は「終わりの日を自分で決める」場合を扱わない。
4. 忌日体系は法人を扱わない。

*(ii) 当てた後に出た不適合（(i) を差し引いた残り）*
5. **忌日体系は死の前に位置を持たないが、廃業では準備が死を規定する。** 解雇予告三十日と官報二か月が、死の日付を先に縛る（束α）。((i)3 と近いが、こちらは「決めた日から逆算して前の期間が構造化される」という別内容であり、差し引き後も残る。)
6. **忌日体系は喪主と故人を分けるが、廃業では同一人物である。**
7. **卒哭忌（百箇日＝泣くのをやめる日）に、対象では清算結了が来た。感情の位置と法の位置が同じ日に落ちた。** ——これは当てる前には書けない。**そして最も有用な不適合である。対象を読み直させるからである：法的に消える日に、当事者は何も感じない。書類が返ってくるだけである。**

**除去検査**：§6 に集約。

**体系Aの置き場所：内部足場。** 成果物に体系名も忌日名も一切現れない。しかし時間構造の反転はこれが産んだ。

### 4-B. 体系B：二十四節気（本朝七十二候）　／　用途：**時間モデル**

**系統の宣言**：本朝七十二候（渋川春海『貞享暦』1685年、のち明治『略本暦』で改訂）を採る。
**別系統とその相違**：中国の七十二候（『逸周書』時訓解〜『礼記』月令系）。**相違は、日本版が日本の気候・動植物へ置き換えられ、中国版にある「鷹化為鳩」「田鼠化為鴽」のような変化譚（あるものが別のものに化す候）を大幅に減らしている点である。**
**自己申告の範囲**：一次資料未確認。

**同種性の判定（層ごとに宣言する）**
- **気象条件の層**（湿度・気温）に対して：**同種に近い**。太陽黄経は気温・湿度の主因である。
- **事業の暦の層**（決算・受注・法定期限）に対して：**異種**。分類原理が違う（太陽黄経／会計年度と法定期間）。
→ 異種側では欠落導出に使わない。**用途を「対比軸の設定」と「表現候補の生成」へ切り替えた**（02の指示どおり）。

**得られた対比軸：戻る時間／戻らない時間。** 節気は一年で必ず戻る。忌日は戻らない。**物語の一年は、この二つの時間が同じ日付の上を走る。一周忌の日は、去年と同じ節気の日である。同じ節気に戻ったのに、同じ場所に戻っていない。**

**表現候補**：候名から、対象へ返して生き残るものだけを採った。「土脉潤起」（砂が湿気を吸う）、「霎時施」（スレート屋根を打つ小雨）、「閉塞成冬」（空が塞がる）は生存。「腐草為蛍」は変化譚であり、本作の姿勢（写す）に合わないため棄却。
**ただし候名は作中に一つも書かない。** 明示度を三段階（潜在／示唆／明示）のうち**潜在**に置く。候名を書くと体系が成果物に現れ、対象固有性を損なう。

**体系Bの置き場所：内部足場。**

### 4-C. 体系C：五行の相生・相剋　／　用途：**遷移モデル（素材の層）**　→　**棄却**

**系統の宣言**：相剋（相勝）は鄒衍の五徳終始説（戦国末）に、相生の順序は『春秋繁露』五行相生篇（前漢・董仲舒）に遡る。
**別系統とその相違**：『白虎通』『五行大義』（隋・蕭吉）系では配当（五音・五方・五祀）が異なる。**相違は「配当表に複数系統が併存し、どれが正統か定まらない」ことそのものである。**
→ ゆえに**配当表は解釈語の層として扱い、割当には使わない。割当に使うのは五位置名と十本の辺だけである。**
**自己申告の範囲**：一次資料未確認。

**導出部の機械検査**：位置5。相生辺5（木→火→土→金→水→木）。相剋辺5（木→土→水→火→金→木）。計10本、すべて相異なる。相生の逆をたどると元へ戻る。木→水の直接辺は存在しない。**検査通過。**

**割当の外部規約（対象を見る前に固定した素材語彙表）**
木＝木型／型／材木／パレット／桟／板　｜　火＝炉／火／熱／湯／溶かす／焼く／溶接
土＝砂／砂型／土／地面／土地／研磨／粉／埃　｜　金＝金属／鉄／アルミ／鋳物／刃／削り屑／ボルト／アンカー／機械　｜　水＝水／油／液／雨／雪／湿気／結露／用水路

**名指して分離すべき取り決め**：「機械」を金に入れたのは体系からも対象からも出てこない取り決めである。**逆に決めた（機械を除いた）場合、金の件数が大きく落ち、金は「鋳物と削り屑」だけになる。動きは大きい。** よってこの規約に依存する結論は限定付きでしか書けない。

**遷移試行**：調査で確定した実工程は 木型製作（方案＝湯道・押湯）→ 砂を込めて**木型を抜く** → フラン樹脂＋硬化剤で造型 → 溶解炉で720〜780℃・脱ガス・フラックス → 鋳造 → 熱処理 → バリ取り → 検査 → 出荷。
格子上では **木 → 土 → 火 → 金 → 水**。体系の相生順（木→火→土→金→水）と**位置2と3が入れ替わっている。**

| 辺 | 体系での種別 | 対象で観測されるか |
|---|---|---|
| 木→土 | 木剋土 | 実在（木型が砂を押しのけ、抜かれて空洞を残す） |
| 土→火 | **体系の十辺に無い** | 実在（造型が済んで炉へ移る） |
| 火→金 | 火剋金 | 実在（炉が金属を溶かす） |
| 金→水 | 金生水 | 実在（冷却・切削油） |
| 水→木 | 水生木 | 実在。**ただし体系は養育と読み、対象では破壊として働く（木型が湿気を吸って反る）** |
| 金剋木 | 相剋 | 実在（木型が砂と金属で摩耗する） |
| 水剋火 | 相剋 | 実在。**ただし体系は制御と読み、対象では禁止事項である（溶湯に水が入ると水蒸気爆発）** |
| 土剋水 | 相剋 | 実在（砂が水分を保持する） |
| **木生火** | 相生 | **廃業時にだけ実在する。通常操業では四十年間一度も起きない** |
| 火生土 | 相生 | 実在（鋳込み後の砂が焼けて再生砂になる） |
| 土生金 | 相生 | 実在（砂型が鋳物の形を与える） |

**棄却の判定**：十本の辺を一本ずつ反証しに行き、**全部が支持証拠として吸収された。** 02a 反転検査の規定——「反証の試みが『実は支持証拠だった』という形に吸収された場合、その体系をその対象に対して棄却する」——により、**体系Cを棄却する。**

**ただし縮小して残す主張が一件ある。** 「木生火」だけは他の十辺と性質が違い、通常操業では起きず畳むときにだけ起きる。02a は「反例が実在した場合は、吸収せず主張を縮小して残す」と言う。→ **残す。**

**格子の被覆**：物に限れば高被覆（八割超）。だが**人・書類・金額・時間は一件も落ちない。層を宣言せずにこの体系を使うと、人と金が見えなくなる。**

**体系Cの置き場所：不採用（棄却）。ただし産んだ生存所見は対象に帰属したまま残る**（02a：不採用は所見の取り消しではない）。

### 4-D. 複数体系のリスク検査（03）

1. **不採用条件のない体系が確証を増やしていないか**：体系Cがまさにこれに該当し、棄却した。A・Bには不採用条件を事前定義してあり、Aは差戻し辺の実在で、Bは同種性の層分けでクリアした。
2. **体系間の一致が対象由来か変換規則由来か**：A（忌日）とC（五行）は同じ「不可逆」を指したが、Aは日付の不可逆、Cは物の不可逆であり、**変換規則の共有によるものではない。** 独立と判定する。
3. **対象の事実に結び付かない記号が既存理解の言い換えを生んでいないか**：B の候名がこれに該当しかけたため、作中への記載を禁じ、対比軸のみを取った。

**軸の独立性**：A＝死からの経過日数、B＝太陽黄経、C＝素材の物質。三者とも分類原理が異なる。**独立。**

木型棚に「三六」の桟が一つ残っている。六月七日に決めきれなかったものである。**一年前に保留した一件が、一年後にもう一度出てくる。** 彼はそれを焼く日を決める。**焼くところは書かない。決めるところで終わる。**

- **経験への変換（四経路へ分散）**

- **既存機能への統合**：新規要素を足す前に、既存の物へ役割を統合した。**「木型」が五役を兼ねる**——素材／初代の痕跡／不可逆の体現／保留された判断／最後に焼かれる一手。**一つの物が五つの機能を持つ**（04：複数の機能を一つの仕組みで実現する統合要素）。
- **反復と明示度**：**分電盤のブレーカーを三度出す。** 一度目＝落とす（四月二十日）。二度目＝五月三日、まだ電気が通っていることに気づく（動力契約が続いている）。三度目＝解約書類にブレーカーの番号を書く。**同じ物が停止／継続／抹消の三つの働きをする。反復するたびに機能を変える。**
- **深層の層（三層を区別し、最上位は一度かつ低い明示度で示す）**

## 8. 冒頭本文（**初版**・約一九〇〇字。**改訂版は §14**）

### 押湯

#### 一　四月二十日

　四月二十日の朝も、三ツ木邦夫は五時半に目を覚ました。四十一年、目覚ましを掛けたことがない。掛ける必要がないというより、掛けても五時半より先に目が開くので意味がなかった。

　台所の電気がもう点いていた。久子が薬缶を火にかけている。邦夫は流しで顔を洗い、タオルを使わずに手のひらで水を切った。爪が薄くなって、拭くと繊維が引っかかる。
「何時に出るの」
「いつもと同じだ」
　久子は振り返らなかった。振り返らないのも、いつもと同じだった。

　工場までは歩いて四分ある。用水路に沿って、花の終わった桜の下を行く。杉村の家の前で、二階の雨戸がまだ閉まっているのを見た。あの家の雨戸は、いつも工場の音が始まる前に開く。

　シャッターを胸の高さまで上げて、下をくぐった。中には前の晩の温度が残っている。壁の分電盤を開けて、動力の主幹を上げた。低い唸りが床から立ち上がり、耳の奥の音と重なった。耳鳴りは十年前からある。医者は治らないと言った。工場を辞めれば治りますかと訊いたら、それとこれとは別だと言われた。

　六時十分に沢田が来た。作業着は洗ってあって、糊の匂いがした。
「炉、上げます」
「頼む」
　それだけだった。四十一年、朝の会話はだいたいこれで足りている。

　この日の品は、農機具メーカーのミッションケースだった。二十年作っている。木型は初代の代からのもので、桟に「三六」と焼き印が入っている。昭和三十六年の三六ではなく型番の三十六番だと父から聞いた覚えがあるが、父はもう居ないので確かめようがない。

　沢田が定盤に下枠を据え、木型を伏せて、砂を込めた。フラン樹脂と硬化剤の匂いが立つ。硬化を待って、木型を抜く。
　抜く手の速さは、いつもと同じだった。木は砂の中に何も残さない。残るのは、木があった形の空洞だけである。そこへ湯を流す。製品になるのは木型ではなく、木型が居なくなった場所のほうだった。

　溶解炉は七百四十度で落ち着いていた。脱ガスをして、フラックスを入れ、湯面の皮を掻き寄せる。取鍋に汲み、湯道へ落とす。押湯まで上がったのを見て、沢田が顎を引いた。
　押湯は製品にならない。だが押湯がないと、冷えるときに金属が内側から縮んで、外から見えない巣ができる。最後に切り落として、また溶かす。

　午前に十二個。午後に八個。二十個で終いだった。

　大類ミチは一時に来て、バリ取りを始めた。ヤスリの音が、いつもより長く続いた。
「社長、これで最後?」
「ああ」
「そう」
　ミチはそれきり何も言わず、手も止めなかった。

　グエンは検査台にいた。ノギスを当てて、記録用紙に数字を書き込む。三時過ぎに顔を上げた。
「社長。この用紙、いつまで取っておきますか」
「五年だ」
「五年」
　グエンは日付の欄を見た。四月二十日。書き終えて、鉛筆を置いた。

　四時四十分に、尾花製作所のトラックが来た。運転手は若い男で、いつもの人ではなかった。伝票に判を押して、二十個を積む。荷台の扉が閉まる音が、砂利の上で跳ねた。

　トラックが用水路の角を曲がって見えなくなるまで、四人とも外に立っていた。誰も何も言わなかった。沢田が先に中へ入った。

　片づけは、いつもの片づけと同じだった。砂を落とし、定盤を拭き、工具をもとの場所へ戻す。ミチが流しを洗い、グエンが記録用紙を綴じた。六時十五分に終わった。いつもより五分早かった。五分早いのは、切り粉を溜める箱を空にしなかったからである。明日も出るなら、空にする。

　三人が帰ったあと、邦夫は建屋に残った。炉の電源を落とし、集塵機を落とし、コンプレッサーの元栓を閉めた。木型棚の前を通ったとき、「三六」の桟が目の高さにあった。返すのか、焼くのか、まだ決めていない。決めるのは今日でなくていいと思った。

　分電盤を開けて、動力の主幹を下げた。
　床の唸りが消えた。
　耳の奥の音は、消えなかった。

　シャッターを下ろし、錠を掛けた。掛けてから、明日の朝これを開ける人間が居ないことに思い当たった。それでも錠は掛ける。

　用水路の道を戻る。杉村の家の二階の雨戸は、まだ閉まっていた。

　家に着くと、台所の卓に茶封筒が並べてあった。久子が出しておいたものだった。解雇予告通知書の控え、三月十八日付。取引先への廃業のご案内、二月十日付。それから、いちばん下に、開封してある古い手紙が一通。三年前に届いた、事業引継ぎの仲介会社からのものだった。返事は出していない。出さなかった理由を、邦夫はいまも言葉にできない。

「明日から、何時に起きるの」
　久子が言った。
　邦夫は答えなかった。答えは分かっていた。五時半である。

### 8-1. 体系：五倫（父子・君臣・夫婦・長幼・朋友）

**構造型**：五位置。並列で、**遷移規則を持たない。** ゆえに遷移モデルには使えず、構造モデル専用である。

**系統の宣言**：『孟子』滕文公上の五倫を採る。**別系統**：『白虎通』以降の三綱（君為臣綱・父為子綱・夫為妻綱）は、五倫から朋友と長幼を落として上下三関係へ縮約する。**相違は「朋友（対等・非支配の関係）の位置が有るか無いか」である。** 本稿が五倫側を採る理由は、**朋友の位置が空くかどうかを見たいからである。三綱を採るとその位置は最初から存在しない。**
**自己申告**：一次資料未確認。

**限界の明記**：五倫は男性・家父長・身分社会を前提とする。**雇用を「君臣」へ、外国人労働者を「長幼」へ押し込む。押し込んだ時点で対象の非対称が消える。** `09` 第12項の「非対称を対称に均さない」に触れる危険がある体系である。**均さないことを明示的に守る。**

**不採用条件（先に定義）**：五位置のうち四つ以上が埋まれば、体系が対象を分割していないので不採用。

**割当の外部規約（計数述語）**：父子＝血縁の親子と記述された対／君臣＝雇用契約が存在する対／夫婦＝婚姻関係にある対／長幼＝同一職場で年長者が年少者に技能・手順を教える記述がある対／**朋友＝上記四つに該当せず、かつ金銭・契約・利害の授受が無い対。**

**名指して分離すべき取り決め**：朋友を「利害の無い対等な相手」と定義したのは、体系からも対象からも出てこない。『孟子』は「朋友有信」としか言わない。**逆に決めた（朋友＝信頼できる相手、利害を問わない）場合、木村と銀行担当者が朋友に落ち、位置は埋まる。動きは決定的である。この結論は「利害の無さ」を条件と置いたときのものである。**

## 周回9　未試行の用途②：**一貫性モデル**（人物ではなく組織に対して）

**問い（段階：本質追及）＝なぜこの単位はこう振る舞うのか。**

`02`「一貫性モデル：人物、制度、組織など、一つの単位の振る舞いを検査する」。`03`「単一単位には一貫性検査を使う」。

### 9-1. 体系：「家」（イエ）の体系

**位置**：家長・跡目・家産・家職・家名・分家・隠居・絶家。
**系統の宣言**：**明治民法（1898年施行）の家制度**を採る。戸主・家督相続・隠居・絶家が法定の位置として置かれ、**隠居には家督相続人の存在が要件である。この要件が本稿の発見の要になる。**

**限界**：家制度は1947年に廃止されている。**現行法上、この体系の位置は存在しない。ゆえに割当を法的事実に対しては行えない。**
**自己申告**：一次資料未確認。

**E-1**「譲る相手が居ないと、引退という言葉が使えない。彼は引退したのではなく、やめただけである。そして『やめた人』を指す言葉が、この社会には無い」

**E-4**「消えたのは法人であって、家でも技能でも建屋でもない。『工場が無くなった』という言い方が指しているものは、実際には登記簿の一行である」

## 周回10　中心の言明を書き換える

**問い（段階：構想／具体策）＝旧い中心で説明できないものは何か。**

### 10-1. 動いたかどうかの判定

**旧中心（§7-5）**：「終わりの日付は選べるが、終わり方の速度は物ごとに違う。機械は六週間、法人は三か月、建屋と土地と人は一年。速度差の中に人が残される。」

周回7〜9が出したものを、旧中心に収まるかどうかで仕分ける。

| 出たもの | 旧中心に収まるか |
|---|---|
| 押湯と炉の湯が、循環先を失って物として溜まる（空19・空21） | **収まらない。** 速度の話ではなく、**消えないという話**である |
| 技能は断絶していない。沢田もグエンも続けている（E-3） | **収まらない。** これも消えない話である |
| 消えたのは登記簿の一行である（E-4／A-1） | 部分的に収まる |
| 譲る先が無いので「引退」という言葉が使えない（E-1） | **収まらない。** 言葉の話である |
| 看板は残り、外すのは誰の仕事でもない（E-2） | **収まらない。** 責任の帰属の話である |
| 実務を握っているのは代表ではない人（E-5） | **収まらない** |
| 利害のない相手が一人も居ない（D-1） | **収まらない** |
| 最も若い者が手続きを最もよく知っていた（D-2） | **収まらない** |

**八件のうち六件が旧中心に収まらない。中心の言明は動く。**

**自己検査（09 第12項の「動かすこと自体を目的にしない」に照らして）**：これは動かしたくて動かしたのか。→ **違う。** 周回7の空19（押湯が溜まる）と、周回9のE-1・E-3が、**旧中心では説明できないものとして材料の側から出た。** 材料が押した。

### 10-2. 新しい中心の言明

> **廃業で消えるのは、登記簿の一行だけである。**
> 機械は買われて別の工場で動く。技能は職人と一緒に別の会社へ行く。押湯と炉の湯はアルミの塊になって建屋に残る。看板は壁に残り、外すのは誰の仕事でもない。土地と建屋は名義を変えて残る。耳鳴りは残る。
> **消えたものを数えるより、残ったものを誰が引き受けるかのほうが難しい。そして「引き受ける」という言葉が要る位置に、誰も名前を持っていない。** 譲った相手が居ないので彼は隠居ではなく、雇い主でなくなったので社長でもなく、まだ死んでいないので故人でもない。
> **一年かけて起きたのは、消滅ではなく、名前の無い状態への移行である。**

**旧中心（速度差）は棄却しない。一段下げて含める。速度差は現象であり、名前の不在が本質である。** 本質追及の段階（周回9）が構想を動かした。

### 10-3. 結末の変更

**旧結末（§7-6）**：一年後、保留した木型を焼く日を決める。
**判定**：**焼くのは「消す」動作である。新しい中心は「消えないものを引き受ける」である。ずれる。**

**新結末**：翌年四月二十日。建屋はまだ在る。機械は無い。床にアンカー穴が十四。押湯の箱とインゴット八本は、一年前のまま隅にある。耳鳴りはまだある。
**邦夫は木型を焼かない。反ったまま残す。そのかわり、看板を外す。**
外すのは誰の仕事でもない。だから自分の仕事にする。**それが、名前の無い位置に自分で名前をつける唯一の動作である。**

- **A-8（差戻し辺）は保持される。** 一年前に決めきれなかったものが一年後に出てくる、という構造は変わらない。**変わるのは「決める」の中身である。「焼く」から「残すと決める」へ。決めないことと、残すと決めることは違う。**
- **§7-8の体癖検査の着地になる。** 「邦夫は決めたら動かさないのではなく、決めないまま動かさない」。一年かけて彼は「決めないまま」から「決めて残す」へ移る。**それが唯一の変化である。**

## 15. 次の対象へ持ち越せる問題パターン（技術的課題で索引する）

題材名（廃業／工場）ではなく、技術的課題で索引する（08-governance の要求）。

1. **「終端が一つに見える対象に、終端が複数あることを検出する」**——起点を持つ一方向の暦を格子として敷き、当事者ごとに終端がずれることを可視化する。閉院、閉校、解散、離婚、移住に転用できる。
2. **「消滅の物語で、実際には何が消えていないかを数える」**——組織を単位とする一貫性検査。位置ごとに「残る／消える」を判定すると、消滅の語が指す範囲が縮む。
3. **「後継位置の不在が、当人を呼ぶ言葉を奪う」**——譲渡先を要件とする位置（隠居・引退・卒業）が空くと、当人の状態を指す語彙が消える。
4. **「循環していたものが、循環先を失って物として溜まる」**——再利用の輪の中にあった中間生成物は、輪が止まると廃棄物にも製品にもならないまま残る。
5. **「対等・非利害の関係の位置が空いているかを、関係の体系で測る」**——ただし地縁の層を測らないと、対象の性質か記述の不足かが判別できない。
6. **失敗パターン**：不採用条件を「N個以上埋まれば不採用」と設計すると、位置が一つ空いた場合に条件が誤発火する。**「全位置が埋まれば不採用」と設計すべきである**（周回8で実際に踏んだ）。
7. **失敗パターン**：保持事項を列挙しただけで照合しないと、**保持事項の側の記述誤り**（根拠のない数値）が最後まで残る（周回11で実際に検出した）。
