# 事例3の一次資料

[適用事例](../examples.md)の事例3で使った、三つのエージェントの生出力です。加工していません。

| ファイル | 内容 |
|---|---|
| `novel-control.md` | 対照群。お題のみを渡した。方法論の存在を知らない |
| `novel-treatment.md` | 処置群。同一のお題＋方法論の全体適用。基準線、体系選定、遷移試行、空白の列挙、除去検査、最終構想、冒頭本文を含む |
| `blind-verdict.md` | 盲検判定。両案を無名化・形式を揃えて提示。方法論の存在を知らない |

三者は文脈を共有していません。処置群は最終周回の途中でセッション上限により停止しており、未試行の用途が二つ残っています。
