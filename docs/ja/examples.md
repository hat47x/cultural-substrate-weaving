# 適用事例

実際に本方法論を適用した記録です。**成功例の陳列ではなく、基準線と増分を並べた測定記録**として書いています。各事例は、通常手法だけで得られる内容（基準線）を先に置き、そこへ何が加わったかを示します。

**現在の事例数は3件です。1件は誤用の記録、1件は境界的、前提条件を満たすのは3件目のみです。方法論の有効性を立証する量ではありません。**

**件数を成果の尺度にしないでください。** 除去検査の件数は過剰主張を防ぐガードであり、価値の尺度ではありません（[02a](../../src/ja-JP/methods/framework-application.md)）。以下の各事例に件数表を置いていますが、これは「零なら主張を取り下げる」という一方向の使い方のためのものです。

**適用対象は開かれた問題空間です。** 正解が確定でき候補を列挙し尽くせる対象では、通常手法で足ります。この方法論の目的は、同じ手を繰り返すだけでは頭打ちになる地点を越えることであり、同一トークン量での効率ではありません。突破には通常手法より多くの往復を要します。

## 事例1：検査群の構造分析（**誤用の記録**）

> **この事例は適用対象外です。** `00-activation`の第一条件「問題空間が開いている」を満たしません。検査スイートは閉じた問題空間——正解が確定でき、検査項目は列挙可能で、検証すれば決着がつく——であり、通常手法で足ります。
>
> **当時の本文はこの誤用を許容していました。** 発動条件は構造性・次元の相互作用・検証可能性・増分の見込みの四つで、問題空間の開放性を問うていませんでした。この事例が第一条件を追加させたので、失敗の記録として残します。
>
> 以下の記述は、当時の判断のまま保存しています。**得られた所見は有効ですが、それは方法論の価値を示すものではありません。** 実際、代替検査で「体系固有ではない」と判定されています。閉じた問題空間では、その結果になるのが当然です。

**対象**：本リポジトリの`scripts/validate.py`。10個の検査関数を持つ検証スイート。

**保持事項**：`make check`は1秒台で完了すること、ネットワーク不要、プラグインのインストール不要。

**主要な変化構造**：「ソースの変更が、生成物を経て利用者の環境へ伝わる。検査群がその伝播を止める。」

### 基準線（通常のコードレビュー）

1. `check_translation_hashes`は英訳ファイルの**存在**しか見ない。空ファイルでも通る。
2. `check_semantics`は全ファイルを連結した文字列を検索する。必須句が誤ったファイルへ移動しても通る。
3. `check_modules`はバイト比較を行うが、対象は`dist/`のOpenAI版のみ。**利用者が実際に入れる`plugins/`の中身は比較されない。**
4. `check_versions`は`pyproject.toml`を部分文字列検索する。同じバージョン文字列の依存関係があれば誤って通る。
5. `check_budgets`は`plugins/`のSKILL.mdを**サイズだけ**読む。内容は読まない。

### 体系適用

**体系**：易の六爻。**用途**：構造モデル。

**同種性**：六爻の単位は「順序を持つ位置」、対象の単位は「順序を持つ段階のパイプライン」。単位の種類が同じで、分類原理（進行における位置）も一致するため、位置の層で同種。

**外部規約**：各検査を、**それが読み込むファイルの層**で位置へ割り当てる。コードが開くパスから機械的に決まるため計数述語。

| 位置 | 層 | 検査 |
|---|---|---|
| 初 | ソース | `check_json_files`, `check_locale_parity` |
| 二 | 翻訳 | `check_translation_hashes` |
| 三 | 意味内容 | `check_semantics` |
| 四 | 生成物 | `check_modules`, `check_budgets` |
| 五 | 配布パッケージ | `check_claude_marketplace`, `check_codex_marketplace`, `check_m365` |
| 上 | — | **空** |

**停止規約の感度**：「読み込む層」ではなく「守る層」で割り当てると`check_budgets`が四と五の境界へ動く。**しかし上は空のまま。** 空位置は規約の取り決めに依存しない。

**空位置の種類**：候補は存在する（成果物は現に消費される）が、関係が名指されていない。つまり**記述の不足**であり、次に取りに行くものがある。

### 所見

**利用者が受け取った状態を検査するものが一つもない。** SKILL.mdのフロントマターが解釈可能か、参照ファイル内の相互リンクがインストール後のレイアウトで解決するか、プラグインが読み込めるか——いずれも検査されていない。

### 四つの検査

- **反転検査**：`check_m365`や`check_claude_marketplace`が上を覆っていないか。いずれもパッケージの検査であり、消費された状態ではない。上を覆う道具（`claude plugin validate`）は存在するが`make check`に組み込まれていない。**反証されず、むしろ補強された。**
- **代替検査**：単純なパイプライン模型（source→build→package→ship）でも同じ欠落が出る。**この欠落について、六爻でなければならない理由は無い。** 所見自体は有効。
- **不適合の記録**：六爻は相応（初-四、二-五、三-上）と中（二・五の中心性）を持つが、検査パイプラインには対応物が無い。ただしこれは対象を見る前に列挙できる被覆外なので差し引く。差し引き後、追加の不適合は出なかった。**体系がほとんど検査されていないことを意味する。**
- **除去検査**：六爻の語彙を全削除。「`make check`には、利用者が受け取る形で成果物を読む検査が一つも無い」は対象についての言明として成立する。**生存所見1件。**

### 検証

所見が実在することを、実際の障害で確認しました。このセッションで参照ファイル内に`[02a-framework-application.md](methods/framework-application.md)`と書いたとき、`make check`は通過しましたが、ビルドは参照ファイル内のリンクを書き換えないため、配布物ではリンク切れになる状態でした。発見したのは`build.py`を読んだからで、検査ではありません。

所見に基づき`check_reference_links`を追加し、同じバグを注入して検出を確認しました。

```text
ERROR: Unresolvable link in installed layout:
  plugins/cultural-substrate-weaving-ja/skills/weave/references/02-system-selection.md
  -> methods/framework-application.md
```

### 増分の正直な評価

| | 件数 |
|---|---|
| 基準線 | 5 |
| 体系適用後の生存所見 | 1 |
| そのうち体系固有 | **0**（代替検査で単純模型でも出る） |

体系が行ったのは、**「最後の位置の次に位置があるか」という問いを強制したこと**です。基準線の検査ごとの読み方はこの問いを立てませんでした。所見は体系に依存しませんが、問いの発生は依存しています。

> 注：`AGENTS.md`は本方法論をリポジトリの定常保守へ自動適用することを禁じています。本事例は検証目的の意図的な適用であり、定常保守への自動適用ではありません。

## 事例2：運用規程の構造分析（既存文章の解析）

**対象**：問い合わせ一次対応の当番運用規程（15行）。当番は日替わり、エスカレーション後も窓口は当番が維持、対応記録は1行で月末に件数集計。

**保持事項**：30分の一次応答、単一窓口、当番日に実装タスクを入れないこと。

### 基準線（通常のレビュー）

時間外の扱いが無い／「判断できない」の基準が無い／エスカレーション後の期限が無い／急な交代の不合意時の規定が無い／月末集計が件数のみで用途が無い／月中の欠員に対応が無い／「原則」の例外条件が無い（7件）。

### 体系適用

**体系**：五倫（君臣・父子・夫婦・長幼・朋友）。**用途**：構造モデル。**外部規約**：各関係に対応する主体対が規程内に明示されているかを計数述語で判定。

| 位置 | 割当 | 状態 |
|---|---|---|
| 君臣 | 管理者・当番 | 明示あり |
| 夫婦 | 当番・担当開発者 | 明示あり |
| 朋友 | 当番同士 | 部分的（当日交代の合意のみ） |
| 長幼 | 前後の当番 | **空**（記述の不足） |
| 父子 | 継承・育成 | **空**（記述の不足） |

### 所見と除去検査

1. **日替わり当番と単一窓口の約束が構造的に衝突する。** エスカレーション中の案件を担当する当番は翌日には別人で、引き継ぎが定義されていない。
2. **判断が次の当番へ渡る経路が存在しない。** 線引きは人によって違い、記録は1行、集計は件数のみ。

五倫の語彙を全削除しても、両方とも規程についての言明として成立する。**生存所見2件。**

所見2は基準線の「判定基準が無い」と「集計が件数のみ」の**接続**として現れています。基準線は両方を挙げていましたが、繋がりは指摘していません。

### 増分の正直な評価

| | 件数 |
|---|---|
| 基準線 | 7 |
| 体系適用後の生存所見 | 2 |

## 事例3：短編小説の構想（開かれた問題空間・対照実験）

> **三腕すべてが収束し、三者盲検判定を経ています。**
>
> 経緯を残します。処置群は当初、材料が尽きてではなく**セッション利用上限**で停止していました。私はその中断点で評価し、否定的な結論を出して記録しました。**これは`00-activation`が名指している自己成就的判定です。** 再開すると、**中心の言明が動いたのは中断点の直後（周回9〜10）**でした。この誤りが方法論への修正を一件生んでいます（観察7）。
>
> また当初の対照群は一度しか書いていませんでした。仮説が「単純反復の頭打ちを超える」ことである以上、**正しい対照は方法論なしの反復**です。第三の腕を追加しました（観察8）。
>
> 末尾の付録は未収束時の判定です。**上書きせず、誤った判定がどう見えたかの記録として残します。**

**これが現時点で唯一、前提条件を満たした事例です。** 小説の構想は、正解が確定せず、候補を列挙し尽くせず、到達点そのものを決めることが作業の一部です。

### 実験計画

独立性を確保するため、**文脈を共有しない三つのエージェント**を使いました。

| 役 | 条件 |
|---|---|
| 対照群 | お題のみ。方法論の存在を知らない |
| 処置群 | 同一のお題＋方法論の全体適用 |
| 判定者 | 両案を無名化・要約形式を揃えて提示。方法論の存在を知らない |

お題：**「地方都市の小さな工場が廃業する。その一年を描く短編小説」**（構想＋冒頭2000字）

### 観察1：両案が同じ場所に着地した

**独立した二つのエージェントが、どちらも題を「押湯」とし、中心隠喩に据えました。** 押湯とは、鋳物で鉄の収縮を補うために製品の上に付ける余分な湯だまりで、凝固後に切り落として溶かし直します。

さらに重要なのは、**処置群が自ら書いた基準線が、対照群の構想とほぼ同型だった**ことです——四季四章、決断→通知→最後の仕事→撤去、床の痕跡で終わる結び。処置群はこれを自己評価でこう書いています。

> この構想は成立する。だが構造は既知である。（中略）**探索が一つの筋へ固まっている。** どの場面も「終わりに向かっている」ことだけを担当しており、二つ以上の働きを持つ場面が無い。

**局所最適が実在し、独立した試行が同じ点へ収束することが観察されました。** これは方法論の前提そのものです。

### 観察2：体系適用で中心の言明が動いた

処置群は忌日・中陰の体系を**遷移モデル**として採用しました（十三仏信仰の系統を宣言し、浄土真宗を別系統として挙げ、相違を「審判があるか」と特定。**一次資料に当たっていないことを自己申告と明記**）。

**停止規約の感度を実測しています。** 「命日」をどこに置くかは体系からも対象からも出てこない取り決めです。

| 命日の置き方 | 結果 |
|---|---|
| 解散決議日 | 忌日と法定期限が重複しすぎ、格子が識別力を失う |
| 明渡し日 | 九位置中七位置が空 |
| **最終操業日** | **九位置中八位置が埋まる** |

> 取り決めが結果を大きく動かす。したがって以後の結論は「対象について」ではなく「**最終操業日を命日と置いたときの対象について**」である。この限定を落とさない。

基準線から動いた点：

| | 基準線 | 最終構想 |
|---|---|---|
| 一年の窓 | 四月〜翌三月（無自覚に選択） | 最後の製品が出た日から一年後の同日まで（自覚的に選択） |
| 構造 | 決断→通知→最後の仕事→撤去 | **廃業が第一章。残り十一か月が「終わった後」** |
| 主題 | 手仕事の終わり／継承の断絶 | **終わりの日付は選べるが、終わり方の速度は物ごとに違う** |
| 対立の極 | **無し** | 四十年苦情を出し続けた隣人が、静かになった工場の前に立つ |

### 観察3：二つの操作が独立に同じ空白を指した

遷移試行で、位置「二七日」（命日から十四日目）が**到達しない状態**として出ました。同時に、KJ法の断片統合で**どの束にも入らなかった孤立札**が一枚ありました——「廃業を待っている人」。

> **断片統合と遷移モデルが独立に同じ場所を指した唯一の箇所である。**

これが対立の極（隣人）になりました。**状態の格子と断片の積み上げが、別々の経路から同一の欠落を指した**わけで、ご指摘の価値仮説が働いた形です。

格子の被覆は50%でした。落ちなかった半分（月次の家賃、四半期申告、盆、正月、雪、隣人）は「日数の格子では測れない時間」として、後半を月単位の疎な断章にする根拠に転用されています。**不適合を捨てずに使った例です。**

### 観察4：体系の置き場所と、正直な自己申告

| 体系 | 置き場所 |
|---|---|
| 忌日・中陰 | 内部足場（成果物に体系名は一切現れない） |
| 二十四節気 | 内部足場 |
| 五行 | **棄却**（反転検査で全辺が支持証拠に吸収された） |
| 式年遷宮 | 補助模型 |

処置群は自ら次を書いています。

> **反映は空である。**（中略）**これを厳しく検査した証拠として出さない。二つの規定が接する形であって、判断の質ではない。**

> **徴候ゼロは、成果物が対象のどこを説明しているかを測ってから読む。** 本作が説明していない領域（金額・沢田の内面・一年より先）には、徴候も出ない。

### 観察5：収束（周回7〜12）

再開後6周、処置群の総消費は212Kトークン。

|---|---|---|

**中断点は周回6でした。中心が動いたのは、その直後の周回9〜10です。**

新しい中心：

> **廃業で消えるのは、登記簿の一行だけである。** 機械は買われて別の工場で動く。技能は職人と一緒に別の会社へ行く。（中略）**一年かけて起きたのは、消滅ではなく、名前の無い状態への移行である。**

**停止条件**：「出てくる増分が、既にある内容と重複している」（主）／「体系を通しても同じ結果しか出ない」（従）。**新しいカード自体はまだ起きるので第一条件には該当しません。** `02`の四用途を使い切っています。**コストではなく材料の側で判定されました。**

### 観察6：保持事項の照合が3件を検出した

前回、盲検判定を受けて`09`第12項に追加した「一件ずつ照合する」が、**次の実行で即座に機能しました。**

- ②従業員「六名」に根拠が無く、本文には四人しか出ていない → 五名へ訂正。**これは保持事項の側の記述誤り**であり、成果物が満たしたのではない
- ⑧「季節は作業条件として使う」に対し「花の終わった桜」は日付の指標にすぎない → **宣言違反1件**
- ⑨記録用紙の保存年限「五年」が確定できず → 未確定として残し、反証条件を付記

> **照合しなければこの3件は最後まで見つからなかった。**

### 観察7：撤回した結論

私は中断点の出力に対して「**両群とも同じ当事者（技能実習生）を落としており、方法論は共通の盲点を破れていない**」と書きました。**これを撤回します。** 収束後の出力では、

- D-2「最も若い者が、やめる手続きを最もよく知っていた」
- E-3「技能は断絶していない。沢田もグエンも続けている」

グエンは装飾から構造上の位置へ移っています。**未収束点での否定的判定が、実際に誤りだったことが確認されました。**

### 観察8：第三の腕（方法論なしの反復）

対照群が一度しか書いていないことに気づき、腕を追加しました。**ご提示の仮説は「単純反復の頭打ちを超える」ことなので、正しい対照は方法論なしの反復です。** 単発対照との比較では、反復そのものの効果と方法論の効果が分離できません。

| | 単発対照 | 反復対照 | 処置群 |
|---|---:|---:|---:|
| 周回 | 1 | 10 | 12 |
| トークン | 57K | **163K** | 212K |
| 主題が動いた回数 | — | 2 / 10 | 2 / 12 |
| 停止理由 | 依頼完了 | 改訂案が言い換えに | 増分が既存と重複 |

**局所最適が三度目、独立に確認されました。** 反復対照の自己報告：

> 周回1で書いた最初の構想が、既存の`novel-control.md`とほぼ同一でした（有能な女性事務員の視点、二代目社長、老職人、ベトナム人実習生、十二か月構成、減っていく数字、年齢まで数歳差）。**これは私の「意外な選択」がこの課題の既定の引力だったという証拠で、器ごと捨てる根拠になりました。**

**そして反復対照も局所最適を脱出しました。** 舞台を鋳造所からオフセット印刷所へ丸ごと替え、「正確さには向きがない」——39年分の偽タイムカードと真の機械日報が隣の棚に並んでいた——という主題に到達しています。**処置群より少ないトークンで。**

脱出の由来が違います。反復対照：

> 主題が動いた2回とも、主題を練り直そうとして動いたのではなく、**技術的破綻の修理から出てきました。**

処置群のほうは、周回9で「停止前に未試行の段階を一つ試す」という規定に従って一貫性モデルを適用した結果です。**偶発と手続きの違いです。** ただしn=1ずつなので、再現性は主張できません。

### 観察9：三者盲検判定

三案を無名化し、方法論の存在を知らない新しい判定者に渡しました（前の判定者は未収束版を見ているため再利用していません）。

**共通の引力について**、判定者は実験の設計を知らないまま、決定的な証拠を自分で見つけています。

> **BとCは互いを知らないまま、同じ鋳造工場を選び、同じ「押湯」を主題比喩に選んだ。** 独立二案が到達した比喩は発見ではなく既定解であり、それに主題を賭けたCが損をしている。

**脱出の種類について**：

| | 判定 |
|---|---|
| 反復対照 | 器を保ったまま**倫理の座標**で離れた（視点人物が、最も未払いの多い男にゼロを配分する） |
| 処置群 | **形式**で離れた（廃業の日を第一章に置き、残り十一か月を「終わった後」にする時間構造） |
| 単発対照 | **離れていない** |

> **Bは形式で離れ、Aは倫理で離れた。Cは離れていない。**

**冒頭の文章について**：反復対照が最高密度だが上手さが露出。**処置群は「物だけで語る規律が最も徹底」**（「五分早いのは、切り粉の箱を空にしなかったから」を白眉と評価）、ただし木型の空洞の一段落は視点の外。単発対照は説明比率が高く、**三案で唯一、視点人物が情報運搬装置になる箇所が複数ある**。

**一年後の到達点**：反復対照は命題が残る（読者を加害者側に立たせる）。処置群は状態が残る（語彙の欠落の手触り。**上限最高・失敗確率最高**）。単発対照は像が残る（最も好かれ、最も早く忘れられる）。

**明言された優劣**：単発対照が一段弱い。**反復対照と処置群は弱くなく、依存先が違うだけ**（抑制 vs 持久力）。

### 観察10：三案が揃って落としたもの — これは利用側コンテキストの所見である

> 標準解は器や中心よりも深いところ、**お題への態度**にある。（中略）**三案とも、この工場が終わることを損失として前提している。**

落ちたもの：廃業が誰かの受注増であるというゼロサム、会社が存続しなかったのは正しかったかもしれないという問い、若い側の視点、身体の損壊、個人保証と自宅。処置群も、12周・212Kトークン・四つの用途を使い切って、ここには届いていません。

**ただしこれは方法論の欠陥ではありません。** 「廃業する。その一年を描く」という**依頼文が既に喪失という態度を含意していた**という所見であり、依頼の立て方の話です。三案が揃って落ちたのは、三案とも同じ依頼文を受け取ったからです。

**スキル本体の役割は、文化的体系が構造を供給し、それを対象へ返して検証することです。** 依頼文が何を前提しているか、モデルが既定で何をしがちかは、**スキルを呼ぶ側のコンテキストが扱う領域**です。この境界は[AGENTS.md](../../AGENTS.md)に明文化しました。

一度この所見から`01-scope-and-facts`に「依頼文が含意する姿勢を判定する」を追加しましたが、**役割の混同なので撤回しました。** 実験から出た所見が、そのままスキルへの変更になるとは限りません。この事例では、**同じ実験から出た三つの所見のうち、スキル側は二件（保持事項の照合、中断の扱い）、コンテキスト側は一件でした。**

### 付録：中断点で下した誤った判定（記録として保存）

観察5で述べた通り、処置群を周回6の中断点で評価し、二腕（対照群・処置群）だけで判定者にかけた結果が以下です。**内容は上書きしていません。** 「文章の質では対照群が上」「共通の盲点を破れていない」という結論は、この時点ではまだ後の観察7・観察9で覆っていませんでした。

技能実習生を装飾として使っている点への指摘（両案が揃って落としたもの）は、この段階では方法論の欠陥として処理していました。その後、観察5〜7で処置群が収束し、実習生が構造上の位置へ移ったこと、観察10でこの種の所見が本来コンテキスト側に属することが分かったため、**現在の結論は当時と異なります。** 詳細は観察7・観察10を参照してください。

### 限界
