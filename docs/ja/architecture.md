# アーキテクチャ

## 四層

1. **意味上の正本**: `src/ja-JP/`
2. **翻訳**: 正本と同じ相対パスを持つ`src/<locale>/`
3. **アダプター**: `adapters/`にある、プラットフォーム・言語固有のテンプレート
4. **動的層**: 個別プロジェクトで作る仮説、対応関係、棄却案、判断記録

## ビルドの流れ

```text
src/<locale>/ + adapters/<locale>/
             |
             v
       scripts/build.py
             |
             +-- OpenAI Skill
             +-- Claude Code plugin
             +-- ChatGPT GPT更新パック
             +-- Microsoft 365 Copilot Agent
             +-- 正本文書パック
```

## 翻訳の同期

`i18n/translation-manifest.json`には、日本語正本の各ファイルを英語版がどのハッシュ時点で翻訳したかを記録します。正本だけが更新された場合、検証は翻訳を「古い」と判定して失敗します。

## なぜ生成するのか

同じ規則を各言語・各プラットフォームで手作業すると、版が分岐します。生成により、一つの言語資源から各プラットフォーム向け成果物を再現できます。
