# バージョニング

方法論、翻訳、全アダプターは同じ基準バージョンを使います。言語はファイル名の`ja-JP`／`en-US`で区別し、言語ごとに別の意味バージョンを付けません。

`develop/vX.Y.Z`の`X.Y.Z`は、その開発線が目指す**予定リリース版**です。開発中は`VERSION`、`src/manifest.json`、`pyproject.toml`もその予定版へ揃えて構いませんが、GitHub上で公開済みの版になるのは、`main`へ統合したcommitに`vX.Y.Z`タグを付けた時点です。

リリース対象の版を変更する場合は、公開タグを作る前にdevelop/release branch名と版情報を一緒に変更し、曖昧な状態を残しません。

翻訳修正でも公開成果物が変わるため、少なくともpatch版を更新します。同じタグの配布物を後から置換しません。
