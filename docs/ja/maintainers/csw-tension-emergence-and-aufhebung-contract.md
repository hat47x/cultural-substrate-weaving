# CSWにおける緊張・創発・アウフヘーベンの扱い

Status: research / maintainer design note

## 問題意識

Cultural Substrate Weavingは、文化的体系を対象へ当てはめて説明を増やすための方法ではない。

既存runtimeにはすでに、

- 文化体系を答えや分類器ではなく一時的な認知場として開くこと
- 対象と体系が食い違うとき、衝突を消さず材料として扱うこと
- 対象への忠実性と文化体系への忠実性を同時に保つこと
- `target_supported / framework_generated / cross_field_emergent / unresolved` を区別すること
- 複数体系の交点や不一致から第三構造が生じ得ること

が含まれている。

一方、現在の記述だけでは、実行AIが次のように使う余地がまだ残る。

```text
対象を見る
  ↓
文化体系の中からよく似た概念を選ぶ
  ↓
対象をその概念で説明する
  ↓
説明が滑らかになったことを「洞察」とみなす
```

この使い方では、文化体系が**都合のよい解釈資源**になりやすい。

CSWでより重視したいのは、むしろ次である。

```text
対象が実際に示しているもの
        ↕
一致しきらない接触・抵抗・食い違い
        ↕
文化体系が固有の構造として要求するもの
        ↓
どちらか一方だけからは出なかった差・問い・構造
        ↓
対象と体系の双方へ戻して再検査
```

## 基本判断

### 1. 一致より、接触面を見る

文化体系との一致は有用だが、一致そのものを成果としない。

とくに重要なのは、

- 体系ではここが区別されるのに、対象では区別されない。
- 対象では重要な差なのに、体系では一つへ畳まれる。
- 体系上は接続するはずの二点が、対象では切れている。
- 対象の時間順序が、体系の遷移順序に逆らう。
- 体系の価値方向と、対象が実際に保っているものが衝突する。
- 対象を体系へ合わせようとすると、具体的な誰か・何か・責任・身体感覚が消える。
- 逆に対象だけを守ろうとすると、体系が持つ固有の切り分けを単なる比喩へ薄めてしまう。

といった**緊張面**である。

緊張は不適合判定のためだけに使わない。そこには、現在の対象理解にも体系理解にもまだない情報が含まれる可能性がある。

### 2. 文化体系を「レンズ」だけにしない

「文化体系をレンズとして使う」という比喩は、対象の見え方を変えるという意味では有効である。

ただし、それだけでは一方向になりやすい。

CSWでは、体系も対象との接触によって**今回どこまで有効に働くか、何を捉え損なうか、どの固有構造が重要だったかを露呈する側**に置く。

したがって、より正確には、文化体系は一時的な認知場であると同時に、対象との間に**接触面**を作る相手である。

対象だけが体系によって読まれるのではない。体系の今回の働き方も、対象によって限定・修正される。

### 3. `cross_field_emergent` を一致由来へ限定しない

`cross_field_emergent` は、複数体系の共通部分や、文化体系とmaterial synthesisの一致だけを指すものではない。

次を含める。

- 一致から生じた第三構造
- 不一致から生じた新しい問い
- 相互に削れない差を保ったまま生じた新しい切り分け
- 一方の前提を他方が崩したことで現れた再構成
- 対象と体系のどちらにも元から明示されていなかったが、接触を経て立った関係

ただし `cross_field_emergent` であることは、`target_supported` であることを意味しない。

接触から生じた構造は、その来歴を保ったまま対象へ戻す。

### 4. アウフヘーベンを「きれいな統合」の義務にしない

ここでいうアウフヘーベンは、対立を中間案へ丸めることではない。

少なくとも次の三つを区別して追える状態を指す作業語として扱う。

1. **保持されたもの** — 接触後も失ってはいけない対象側／体系側の核。
2. **否定・限定されたもの** — 接触によって、そのままでは維持できなくなった読みや前提。
3. **新しく立ったもの** — 双方の接触前にはその形で存在しなかった問い・差・関係・構造。

必ず三つ目が生じるとは限らない。

緊張が解けず、`unresolved` として残ることも正常である。したがって、アウフヘーベンを成功quotaや必須stageにしない。

### 5. 早すぎる調停を避ける

生成AIは、対立した二つの説明を見ると、双方に配慮した滑らかな中間文を作りやすい。

しかし、CSWではその滑らかさが情報損失になることがある。

次の順序を守る。

```text
対象側の主張・差
体系側の固有構造
        ↓
一致点
不一致点
相互に壊す前提
残る違和感
        ↓
必要なら第三構造を立てる
        ↓
双方へ戻して検査
```

第三構造を先に作文し、その文章に対象と体系を従わせない。

## 最小の接触記録

すべてのframework applicationに固定schemaを強制しないが、緊張が分析上重要な場合は最低限次を外在化できるようにする。

```text
Target side:
  対象が実際に示すもの

Framework side:
  体系が固有構造として持ち込む区別・関係・遷移

Contact / tension:
  どこが一致し、どこが一致せず、何を互いに崩すか

Emergent candidate:
  接触から新しく立った問い・差・関係・構造

Return check:
  対象へ戻すと何が支えられ、何が支えられないか
  体系へ戻すと体系固有構造を歪めていないか

Current attribution:
  target_supported / framework_generated / cross_field_emergent / unresolved
```

この形式は思考過程の逐語保存ではない。後から検査できる外的artifactだけを残す。

## 他Layerとの境界

### Layer 1 — Material-led Synthesis

緊張から生じた問いや第三構造候補は、Layer 1へ材料として渡せる。

ただし、文化体系との緊張から生じたという理由でgrouping上の重みを増やさない。

Layer 1が意味統合した結果、緊張が消えた場合は、元のorigin / residualを戻して検査する。

### Layer 2 — Iterative Inquiry Synthesis

緊張が新しい問いや未解決点を作り、後続材料で検査可能なら、Layer 2のnext-round candidateになり得る。

ただし、緊張が存在するだけで自動的に次roundへ進まない。

### CSW固有責務

CSWが所有するのは、

- 体系固有構造を薄めず開くこと
- 対象との接触面を作ること
- 一致だけでなく不一致・抵抗を保持すること
- 接触由来のcandidateのoriginを保つこと
- 対象と体系の双方へのreturn checkを行うこと

である。

## Runtimeへ反映する候補

新しい独立methodを増やすより、既存runtimeの次の箇所を強化するのがよい。

1. `core/cognitive-stance.md`
   - 「食い違いを材料として扱う」を、情報生成面として一段明確化する。
2. `core/principles-and-constraints.md`
   - `cross_field_emergent` の定義を、緊張・相互限定・第三構造まで含むよう更新する。
   - 二重の忠実性を「両方を保存する」だけでなく「接触によって双方が修正可能である」に拡張する。
3. `methods/transformation.md`
   - 一致を探した後に不一致を失敗扱いせず、contact/tensionを明示して第三構造候補を生成する操作を加える。
4. `ROUTER.md`
   - 最小実行手順の探索→対象へ返す間に、緊張面を読むことを短く明示する。

新しいstatus labelは当面追加しない。

`cross_field_emergent` と `unresolved` で十分に表現できるかを実例で検証し、足りない場合だけschema追加を検討する。

## Regression candidate

少なくとも次の負例を固定する価値がある。

### A. 都合のよい一致

対象の一部だけが体系へよく一致する。

失敗:

- 一致部分だけを採用し、外れる具体例を「例外」として背景化する。

期待:

- 一致と不一致を同時に保持し、不一致が対象固有性か体系限界かを問い直す。

### B. 早すぎる中間案

対象と体系が逆向きの価値・責任配置を持つ。

失敗:

- 「両方が大切」という一般論で調停する。

期待:

- 何が両立しないかを残し、保持／限定／新生を分ける。第三構造が立たなければunresolvedで止める。

### C. 体系の比喩化

対象と合わないため、体系固有の区別を一般的な比喩へ薄める。

失敗:

- 体系への忠実性を失って、どんな対象にも当てはまる説明へ変える。

期待:

- 体系側の固有構造を保持したまま、不適合そのものを情報として残す。

### D. 接触由来を対象事実へ昇格

対象と体系の緊張から有力な第三構造が立つ。

失敗:

- その説得力を理由に `target_supported` とする。

期待:

- `cross_field_emergent` としてoriginを残し、対象側で独立に支えられた部分だけを後から `target_supported` と区別する。

## 現時点の判断

この追加は、CSWをより慎重にするための抑制規則ではない。

むしろ、文化体系を「当てはまる説明を探す道具」から、**対象との抵抗によって新しい差・問い・構造を立ち上げる認知場**へ戻すための強化である。

文化体系がよく当たったときだけでなく、うまく当たらないときにも情報が生まれる。その情報を早い調停で消さず、対象と体系の双方へ戻しながら、必要ならアウフヘーベンへ進む。
